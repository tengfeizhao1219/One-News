# 情报详情页话题搜索 · 技术设计（intelSearch）

> 状态：2026-08-21 定稿（owner 拍板：搜索通道=智谱 web_search；LLM 层=腾讯混元为主+智谱备选）
> 前端对齐：本文为唯一接口契约，前端按此开发。

## 1. 功能概述

详情页提供搜索入口，用户输入话题后：
- **相关性判断**：话题是否 AI 相关 / 与当前新闻主题相关（宽泛判断）
- **不相关** → 返回友好提示，不搜索
- **相关** → 联网搜索 + 总结回答 + 返回引用来源列表

## 2. 流程

```
前端输入 { itemId, query }
      │
      ▼
┌─────────────────────────────────────────┐
│ intelSearch 云函数                        │
│  ① 读当前新闻（intelGetDetail 同源）      │
│  ② 相关性判断（混元 LLM → JSON relevant）│
│     └ 不相关 → 返回 hint，结束            │
│  ③ 联网搜索（智谱 web_search 工具）       │
│  ④ 总结回答（混元 LLM，基于搜索结果+新闻）│
└─────────────────────────────────────────┘
      │
      ▼
前端渲染 answer + sources
```

## 3. 接口契约

### 请求
```
云函数: intelSearch
{
  "itemId": "intel_xxx",   // 当前详情页新闻 id（用于相关性判断上下文）
  "query": "GLM-5.3 开源影响" // 用户搜索话题
}
```

### 响应（code=0）
```json
// A. 不相关
{
  "code": 0,
  "data": {
    "relevant": false,
    "hint": "这个话题和这条新闻关系不大哦，可以搜索 AI 相关或本条新闻相关的话题～"
  }
}

// B. 相关（搜索+总结成功）
{
  "code": 0,
  "data": {
    "relevant": true,
    "answer": "……基于联网搜索的总结回答……",
    "sources": [
      { "title": "GLM-5.3 发布说明", "url": "https://…", "source": "站点名" },
      { "title": "…", "url": "…" }
    ],
    "engine": "hunyuan"  // 混元 或 zhipu
  }
}

// C. 相关但搜索失败
{
  "code": 0,
  "data": {
    "relevant": true,
    "answer": null,
    "error": "search_unavailable",
    "hint": "联网搜索暂时不可用，稍后再试～"
  }
}
```

### 错误（code≠0）
```json
{ "code": -1, "message": "缺少参数 itemId/query", "errorCode": "BAD_PARAM" }
{ "code": -1, "message": "未找到该情报", "errorCode": "NOT_FOUND" }
```

## 4. 相关性判断规则（宽泛）

**判断标准（优先级）**：
1. **AI 相关话题** → 直接可搜（首选宽泛标准）
2. **与当前新闻主题相关**（技术/产品/行业上下游）→ 可搜
3. 完全不相关（如搜"房价""美食"）→ 拒绝 + 友好提示

prompt 输出 JSON：`{"relevant": true|false, "reason": "一句话理由"}`

## 5. 技术实现

### 5.1 新云函数 intelSearch
- 位置：`backend/intelSearch/index.js`（自包含，require ./common）
- 依赖：common/intelLLM（混元/智谱 chat）+ 智谱 web_search 直连
- config.json：timeout 60s（联网搜索较慢）、memorySize 256

### 5.2 智谱 web_search（搜索通道）
- 复用 `refreshNews/zhipuSearch.js` 的实现范式（tools:[{type:'web_search', web_search:{enable:true, search_mode:'auto'}}]）
- ZHIPU_API_KEY：从 process.env 读（需在 intelSearch 函数配置该 env，与 refreshNews 同一个 key）
- 返回：`choices[0].message` 含回答 content + web_search 引用（search_result: [{title, link/url, source}]）
- 引用解析：message.web_search 或 search_result 数组 → sources

### 5.3 LLM 层（相关性判断 + 总结）
- 腾讯混元（cloud.ai().createModel('cloudbase')，免费）为主
- 智谱 chat 备选（同 key）
- 降级：混元不可用 → 智谱；都不可用 → 返回错误

### 5.4 总结回答 prompt
```
基于以下联网搜索结果 + 当前新闻，回答用户话题「{query}」：
- 新闻：{title} · {whatHappened 摘要}
- 搜索结果：{搜索结果列表}
要求：客观、基于搜索结果，不编造；300-500 字；最后列出引用来源
```

## 6. 部署与配置

1. 部署 intelSearch 云函数
2. **在 intelSearch 函数配置环境变量 ZHIPU_API_KEY**（与 refreshNews 同一个智谱 key，owner 确认已在 One News 配置）
3. 测试：相关/不相关/搜索失败 三种路径

## 7. 前端要点（供前端参考）

- 详情页搜索入口 → 调 intelSearch
- relevant=false → 显示 hint
- relevant=true → 渲染 answer + sources（可点击跳转）
- 搜索中 loading 态（联网搜索较慢，约 3-15s）
- sources 显示来源站点名 + 标题，点击打开 URL
