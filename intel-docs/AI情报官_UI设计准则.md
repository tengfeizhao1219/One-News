# AI 情报官 · UI 设计准则（v1 · 所有 AI 必读）

> **状态**：owner 拍板（2026-08-21），**项目级长期约束**。任何 AI 在任何会话/任何页面做 UI 相关改动（设计、实现、评审、重构）都必须遵守。
> **优先级**：本准则 > 单次需求表述。若单次需求与准则冲突，按准则执行并提示 owner。
> **必读链**：CONTEXT.md（第一必读）→ 本文件 → AI情报官_UI规范_v1.md。

---

## 一、简洁，用 UI 形态引导，不堆重复设计

- **删掉对用户无意义的元素**。反例：「🟢 情报官已完成情报收集」这类状态条——用户根本不关心"谁干的活"，只关心内容本身。这类信息不展示，或降级为不可见。
- **用视觉形态引导操作**：卡片层级、主次字号、留白、箭头/展开提示——让用户"一看就知道能点什么、下一步做什么"，而不是靠文字说明。
- **不做重复设计**：同屏不出现两个表达同一信息的元素（标题+副标题重复、区块标题+说明重复）。
- **文案极简**：按钮/提示一句话，能省则省；不给用户"读说明书"的负担。

## 二、禁止系统表情 / 系统图标作为 UI 元素

- **禁止**：emoji（🔍✨🟢⚠️ 等）、系统默认图标、第三方免费图标库图标——一律不作为界面设计的一部分。
- **替代**：要么**不显示图标**（纯文字/排版表达），要么**重新设计专属图标**（SVG 资源，遵循本产品风格）。
- 例外：数据语义本身需要符号时（如状态勾选、星级），用**自绘极简图形**，不用系统 emoji。

## 三、交互优雅，符合大众操作习惯

- 手势与反馈遵循微信小程序/移动端**大众认知**：点击有反馈（active/hover）、返回用左上、列表可点有箭头、表单有明确提交。
- 不用反直觉交互（如双击才触发、隐藏入口、长按作为主操作）。
- 动效克制：过渡 0.2-0.3s，不炫技；无必要的动画不加。
- 每个可交互元素要有"可点感"（视觉可识别 + 触感反馈），不可点元素不伪装可点。

## 四、在设备形态与原生系统前提下设计

- **这是微信小程序 = 手机端应用**：设计以手机竖屏为主，考虑**单手持握**（拇指热区在屏幕下半部、主要操作放中下部）、**一屏信息密度**（不要 PC 思维）。
- **寄生于原生设计框架**：
  - 右上角**原生胶囊**不可遮挡，顶部导航/返回按钮与胶囊**垂直居中对齐**（menu-top/menu-height 机制）。
  - 状态栏（时间/电量）颜色跟随主题（亮色黑字/暗色白字），不破坏系统区域。
  - 底部安全区（iOS 手势条）正确避让（safe-area）。
  - 字号用 rpx 适配，深浅色完整双套。
- 元素尺寸/间距遵循移动端基准（可点区域 ≥ 88rpx 等），不做桌面端式的大留白/小字号。

## 五、遵守整体风格（一致性）

- 全项目统一设计语言：**卡片流 + 轻高亮 + 少装饰**（见 UI 规范 v1）。
- 色值只用 theme.json token（禁止新增 hex）；圆角/间距/字号体系统一。
- 新页面/新组件先对照既有页面（首页/详情/我的），形态一致再谈差异化。
- 深浅色两种模式下都要完整验证。
