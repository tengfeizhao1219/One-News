# 情报详情页话题搜索 · 前端 UI/UX 交互设计

> 版本：v1.0（2026-08-21，真机多轮迭代定稿）
> 范围：AI 情报官 · 情报详情页「深入了解/话题搜索」前端交互与展示
> 后端契约见《情报详情页话题搜索_技术设计.md》；本文件为前端 UI/UX 唯一确认源，多 AI 协作以本文件为准。
> 关联页面：`pages/intel/detail/`（wxml/wxss/js）+ `assets/icons/search*.svg`

---

## 0. 设计原则（对齐《AI情报官_UI设计准则》）

1. **同页过渡，不切页**：搜索面板与详情正文是同一页面的推上/推下关系，视觉是「把正文顶上去/落回来」，不是跳转新页面。
2. **标题常驻**：展开搜索时新闻标题保留在顶部（不透明底色），只有标题以下内容被推上去。
3. **自绘图标，禁系统图标/emoji**：放大镜、深浅色、蓝色态均为自绘 SVG。
4. **极简输入**：搜索输入不是「输入框」，而是一条横线（无边框容器），弱化工具感。
5. **数据驱动分层**：结果按「分组（话题）→ 条目（每次深挖）→ 内容（sections 段落）→ 来源（折叠）」四层组织。

## 1. 入口：搜索悬浮按钮（FAB）

| 项 | 规格 |
|---|---|
| 位置 | 详情页右下角，`right: 40rpx; bottom: calc(48rpx + safe-bottom)` |
| 形态 | 96rpx 圆形（对齐首页 floating-more），tag-bg 浅灰底，floatY 浮动动画（3.2s） |
| 图标 | 自绘放大镜 `search.svg`（亮色黑描边）/ `search-dark.svg`（暗色白描边），56rpx |
| 交互 | 单击展开搜索面板；面板已开时单击收起 |

**状态**：默认灰；面板展开时 `.on`（主色底 + 白图标）。

---

## 2. 展开交互（点击 FAB）

**动画**（0.65s cubic-bezier(0.22,0.61,0.36,1)）：
- `.rest`（来源/正文/深挖历史/页脚）整体 `translateY(-100%)` 推出可视区——「把正文顶上去」
- 搜索面板从屏幕底部升起，**top 停在标题正下方 + 18rpx 呼吸间距**（标题保留）
- 面板升起同时，搜索横线作为**进度条从左侧以系统蓝加载**（width 0→100%，0.65s 与 top 过渡同步，仅展开动画时一次）

**边界条件**：
- 详情未就绪（loading/empty）时点击 → toast「详情加载中，请稍后再试」，不展开（防标题未渲染导致面板顶到屏幕最上方）。
- 标题测量兜底：量不到标题时用 nav 底部 + 标题估算高，保证面板贴标题下不越界。

## 3. 搜索输入区

```
[ 围绕「新闻标题」继续深挖 ]        ← deep-quick 卡片（点击=按标题搜）
[ 输入你感兴趣的话题…____________]  ← 极简横线输入（无边框）
[ 🔍 ]                              ← 放大镜 icon 按钮（无圆形边框）
```

| 元素 | 规格 |
|---|---|
| deep-quick 卡片 | bg-card + divider 边框，28rpx 圆角；主行「围绕「标题」继续深挖」+ 副行「AI 联网搜索更多资料 · 生成更详细介绍」 |
| 横线距深挖卡 | **28rpx**（间距 1.4 倍） |
| 输入 | 横线式（divider 基线 + 下方细线），**高度 1.5 倍**（padding 12rpx + 行高 2.1），文字在线上方 |
| 放大镜按钮 | 纯 icon 无圆形边框，48rpx；默认灰（亮黑/暗白） |

**输入态**：
- 首次输入 → 正常主色文字
- **提交搜索后** → 搜索词以**提示词灰**（text-tertiary）显示
- **再次聚焦输入** → 自动清空已有词，可直接输入新词（无需先删除）

**搜索中态**：
- 放大镜 icon 切换为**系统蓝版**（`search-blue.svg` #007AFF 亮 / `search-blue-dark.svg` #0A84FF 暗）
- 放大镜**扫动动画** `searchSweep`（-18°↔18° 摆动 + 1.08 缩放，1.1s 循环）
- 放大镜扫动动画持续至结果返回（横线进度条为展开动画一次性加载）

## 4. 搜索结果展示

### 4.1 整体组织（四层）

```
搜索面板（可滚动 scroll-view）
├── 搜索输入区（sticky 顶部）
├── 深挖历史分组列表（互斥展开）
│   ├── 分组「话题A」（点击展开/收起）
│   │   ├── 条目1（某次深挖，含时间戳）
│   │   │   ├── sections：小标题/段落/列表（结构化排版）
│   │   │   └── 参考来源（折叠，默认收起）
│   │   └── 条目2 …
│   └── 分组「话题B」…
```

### 4.2 深挖历史分组（dig-groups）

- **同话题合并**：同一查询词多次深挖归入一个分组，组内条目按时间倒序（最新在前）
- **折叠/展开时机**：
  - 展开面板时 → 所有分组默认收起
  - **搜索完成 → 当前话题分组自动展开**（展示本次结果），其它分组折叠
  - 收起面板 / 滚到面板顶 / 退出页面 → 全部折叠
- **互斥展开**：点击展开某分组，其它分组自动折叠
- **置顶**：展开某分组时，页面自动滚动使该分组位于面板顶部（当前话题在顶部）
- **持久化**：历史存本地 storage（`intel_dig_history_<itemId>`），退出详情页再进保留；上限 10 话题 × 10 条目
- 分组头：`「话题」N 次深挖 · 最近 HH:MM` + ▸/▾ 箭头

### 4.3 条目内容（sections 结构化排版）

后端 LLM 返回结构化 sections（heading/para/bullet），前端按类型排版：
- **heading（小标题）**：主色左侧竖线 + 加粗
- **para（段落）**：正文两端对齐、行距 1.75、留白
- **bullet（列表）**：主色圆点 + 文本

> 兼容：后端无 sections 时前端解析 answer 段落兜底；LLM 输出统一清洗 markdown 标记（**粗体**/斜体/`代码`/#标题/-列表/[链接] 只留纯文本）。

### 4.4 参考来源

- **内置在每条搜索结果（条目）内**，位于 sections 之后
- **默认折叠**：仅显示「参考来源（N）展开 ›」头，点击展开列出各来源（标题 + URL）
- 点击来源：复制链接（个人主体无 web-view，复用复制方案）

## 5. 收起交互（离开搜索区）

三种收起途径，**收起时深挖历史自动折叠**：

| 途径 | 触发 |
|---|---|
| 点击 FAB | 再次点击搜索按钮收起 |
| 下滑手势 | 面板**内容超出可滚** + 已滚到顶部 + 继续下滑（24px+）才收起——不足一屏时永不因滑动收起（防误触） |
| 滚到面板顶部 | 面板内部滚到顶部时历史自动折叠 |

**退出页面**（onHide / 返回首页）：折叠全部历史 + 收起面板，再进详情页不保持展开。

## 6. 场景清单

| 场景 | 行为 |
|---|---|
| 首次进入详情页，点 FAB | 详情加载中 → toast 等待；就绪 → 面板升起 + 正文顶上去 + 横线进度条 |
| 点「围绕标题继续深挖」 | 按标题搜索，面板保持展开 |
| 输入话题点放大镜 | 放大镜变系统蓝 + 扫动动画；搜索词变提示词灰 |
| 搜索完成 | 当前话题分组自动展开（其它折叠），结果展示；来源默认折叠 |
| 再搜新话题 | 新分组加入列表顶部并展开；来源默认折叠 |
| 点开历史分组 A | A 展开，其它分组折叠；A 滚到面板顶部 |
| 面板内上滑看结果 | 自然滚动浏览 |
| 下滑到面板顶部 | 历史折叠；内容不足一屏则不收起 |
| 下滑到顶继续下滑 | 面板收起，正文落回 |
| 点 FAB / 返回首页 | 收起面板 + 历史折叠 |
| 退出详情页再进 | 历史保留但全部折叠 |

## 7. 设计 Token（全部引用 theme.json，零新增 hex）

- 系统蓝：`--primary`（#007AFF 亮 / #0A84FF 暗）——进度条、放大镜蓝色态、分组查询词、小标题竖线、列表圆点
- 背景：`--bg-page`（面板/标题底色）、`--bg-card`（卡片）、`--bg-subtle`（hover/序号底）
- 文本：`--text-primary` / `--text-body` / `--text-secondary` / `--text-tertiary`（提示词灰）
- 描边：`--divider`（横线基线、分隔线、卡片边框）
- 高亮：`--primary-subtle`（搜索中放大镜底色）
