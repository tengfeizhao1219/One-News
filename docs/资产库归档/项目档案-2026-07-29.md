## 一、项目概述

## 四、核心数据流

```
用户上滑 → WXS touch 实时渲染 → JS 回调切换卡片
   └─ 触达边界 → loadMoreNews / refreshCurrentCategory

getNewsList 数据流：
  L1 内存缓存(5min) → L2 news_cache 云数据库 → L3 AI 静态缓存 → L4 天行分类路由
   └─ 失败 → 聚合降级 (juhe)

refreshNews 数据流：
  定时触发 → 百炼 DeepSeek 联网搜索(8分类) → 校验去重 → 写入 news_cache

详情页翻页：
  首页 onCardTap → globalData.detailContext{list} → 详情页按索引加载 → 上下滑动/按钮翻页
  返回 → globalData._detailReturnState → 首页定位
```
