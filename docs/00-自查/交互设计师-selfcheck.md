## ① 不完善（Incomplete）—— 现有交互资产的结构性缺口

### 1.1 阅读模式交互原型缺失（🔴 重点）
- 线框图与 PRD 都只画了"基础详情页"，**没有阅读模式（上下滑跨分类切换新闻）的交互原型**：无上下翻页示意、无"第 X / Y 条"位置指示、无跨分类边界（首条上滑返回 / 末条提示）、无与首页卡片流的双向定位同步。
- 尽管 `detail.js` 已存在 `onTouchStart/End`、`goPrev/goNext`、`isFirst/isLast`、`readingIndex` 回写等脚手架，但**设计层未定义该模式的交互规范**，实现与设计脱节。

### 1.2 搜索交互原型缺失
- 线框图三视图未含搜索；`app.json` 无 `pages/search`，`home.wxml` 仅注释"刷新+搜索"但**实际无搜索入口/结果页**。搜索的完整交互（入口、关键词输入、结果列表、分类筛选、空/错态）无任何原型。

### 1.3 缺少统一「交互设计规范」文档
- `docs/02-产品设计/` 有设计规范文档，但偏组件/视觉；**缺少一份交互专属规范**，至少应含：
  - 手势阈值表（上滑切新闻 >50rpx、左滑唤侧栏 >60rpx、下拉刷新 >80rpx、方向判定死区）；
  - 与 **WXS 红线**的对齐说明（纯 ES5 / 禁 `return false` 阻断子 `bindtap`）；
  - 全局状态清单：加载 / 错误 / 空 / 网络异常 / 边界 的交互规范；
  - 暗色模式**行为**规范（跟随系统 vs 手动切换的触发与时序），现有仅列色彩映射。

### 1.4 线框图与代码/PRD 不同步（多处）
- 线框图 4.x 画了底部 `🤍收藏 / ↗分享` 操作栏 + 分享面板，但 `detail.wxml/detail.js` **无收藏/分享实现**。
- 线框图 2.5 首屏引导"3 秒后消失且之后不再显示"，但**未定义如何再次唤起**（帮助中心/手势提示入口缺失）。
- 侧边栏"分类切换不关闭面板 + 当前项高亮联动卡片流"在代码已实现（home.wxml），线框图未体现。
