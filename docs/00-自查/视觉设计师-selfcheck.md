## 二、不完善 / 口径冲突（发现的问题）

### ① 配色基准三处不一致（🔴 高优）
| 维度 | 视觉风格与配色方案.md | 设计走查清单.md | theme.json（唯一真值） |
|------|------|------|------|
| 浅色页面 | `#F2F2F7` | `#F5F3F0` | **`#F5F3F0`** |
| 暗色页面 | `#000000` | `#1A1A1C` | **`#000000`** |
| 暗色卡片 | `#1C1C1E` | `#252527` | **`#0D0D0D`** |
| 暗色主文字 | `#F2F2F7` | `#E5E5E7` | **`#FFFFFF`** |

- 视觉走查报告.md 用 `#F5F3F0`（= theme.json）判 ✅；设计走查清单.md 用 `#1A1A1C/#252527`（≠ theme.json）也判 ✅ → **两份走查文档基准互相矛盾**，且后者基准与真值不符。
- 规范文档与走查文档须统一到 `theme.json` 为唯一可信源。

### ② 字体规范滞后于实现（🟡 中）
- 设计规范文档.md §3：卡片标题 **36rpx**、摘要 **28rpx**、行高 1.8。
- 实际 `home.wxss` `.card-title` **52rpx**、`.summary-p` **32rpx** 衬线 / 行高 1.9；视觉走查报告也按 52/32rpx 判 ✅。
- → 设计规范文档（v1.0）未随实现更新；若以规范文档为基准，实现存在"偏差"，而走查用了不同基准掩盖了该问题。

### ③ 设计规范文档 §5.1 theme.json 示例变量名过时（🟡 中）
- 文档示例：`--bgColor / --cardBg / --textPrimary / --textSecondary / --textTertiary…`
- 实际 `theme.json`：`--bg-page / --bg-card / --text-primary / --text-secondary / --text-body / --divider / --tag-bg / --tag-text / --overlay`
- 变量命名完全不同，前端若照文档对接会取不到值。

### ④ 分类强调色 / 无图渐变 未在实现中落地（🟡 中）
- 规范 §2.3 定义 5 分类强调色、§2.4 定义无图卡片分类渐变背景。
- 实际 `home.wxss` `.category-tag` 用中性 `--tag-bg/--tag-text`，卡片背景为纯 `--bg-card`，**未使用分类色与渐变**。需确认是有意简化还是遗漏。

### ⑤ 底部操作栏（BottomBar）规范有、代码无（🟢 低）
- 设计规范文档 §2.5 定义收藏/分享底栏；`home.wxss` / `detail.wxss` 未见对应实现（detail 仅有 `pager-hint` 上下翻页按钮）。需确认落地位置。

### ⑥ 暗色模式双机制并存（🟢 低）
- `theme.json`（darkmode + CSS 变量）与 `app.wxss` `@media(prefers-color-scheme: dark)` `!important` 硬编码覆盖并存。
- 部分硬编码值（如 `.swipe-hint` 暗色 `#666666`）未纳入 `theme.json`，存在漂移风险。建议统一变量驱动，明确 `!important` 仅作真机兜底。

### ⑦ 图标规范未严格落地（🟢 低）
- 设计规范文档 §7：线性图标 描边 2rpx、操作图标 40×40rpx。
- 实际多用 emoji（🔤 ↗️ 🤍）或字体图标，未严格按线性图标规范；搜索页/详情页图标在 wxss 中未完整定义视觉参数。
