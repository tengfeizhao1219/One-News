# 新会话启动指南

> **给用户的**：如何开一个新会话来干活。

---

## 一句话版

新会话第一句话：

```
先 git pull，然后读 CONTEXT.md、TASK_BOARD.md 了解项目状态，认领一个 📋 任务开始工作。
```

## 会话结束后

新会话交付后，回到主会话（当前这个），说：

```
审查 feature/xxx 分支，合并到 main。
```

主会话会：
1. 审查代码变更
2. 运行回归测试
3. 合并到 main
4. 更新 TASK_BOARD.md
5. 推送到远程

---

## 并行多会话示例

```
会话 A（主会话）：项目管理 + 代码审查 + 合并
会话 B（dev）：   开发阅读模式（feature/reading-mode）
会话 C（dev）：   开发真实数据（feature/real-data）
会话 D（test）：  编写测试用例

流程：
1. B 和 C 并行开发，各自在独立分支
2. B 完成后 → 主会话审查合并 → main 更新
3. C rebase main → 继续开发 → 完成后合并
4. 主会话创建 release/v8 → D 执行集成测试
5. 测试通过 → 上线
```
