## 变更详情

### CHG-004：设计方向大改

**变更前**：传统新闻 App 布局（TabBar + 分类 Tab + 大图 Banner + 图文列表）

**变更后**：抖音式沉浸卡片流（全屏卡片 + 上下滑动 + 左滑侧边栏 + 点击详情）

**影响范围**：
- PRD v1.0 → v2.0 全面重写
- 设计规范文档全面重写
- 线框图全面重做
- 技术方案中组件树重新设计
- 已有代码（11个组件、9个页面）全部废弃重建

**影响分析**：此变更属于产品方向级调整，工作量增加约40%，但用户确认这是核心产品理念，不可妥协。

---

### CHG-005：首页去掉配图

**变更前**：卡片上半部分为配图（50%高度），下半部分为文字

**变更后**：纯文字卡片，无配图

**影响范围**：
- 设计规范文档更新
- Demo HTML 更新
- 卡片组件简化（无需图片懒加载）
- Mock 数据中的 image 字段不再使用

**影响分析**：减少了开发复杂度（图片加载、懒加载、占位图等不再需要），性能天然提升。
