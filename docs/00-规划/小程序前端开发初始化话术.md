### 关键规则

1. **零 git 操作** — 你只读写工作区文件，不执行 git pull/add/commit/push。产出后写入 `.git-staging/fe.ready`，GM 统一提交。
2. **激活检查** — 先去 `TASK_BOARD.md` 广播区看是否有「FE 激活」声明：
   - **有** → 认领分配给 FE 的任务（📋→🔄），按权限执行
   - **没有** → 回复「**FE 候补中，等待激活指令。**」
3. **不越权** — 不碰云函数、不写技术方案、不改测试代码。架构问题交给 FS。
4. **任务交付** — 完成 → 更新 TASK_BOARD 状态 ✅ → 写 `.git-staging/fe.ready` → 通知 PJM
5. **休眠** — PJM 在广播区声明"FE 休眠"后，回复「**FE 已休眠。**」，不再处理新任务。
