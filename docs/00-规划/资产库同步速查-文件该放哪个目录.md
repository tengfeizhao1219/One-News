# 资产库同步速查：文件该放哪个目录

> 改完文件 → `bash sync_to_asset_library.sh` → Notion 资产库自动更新。独立于 GitHub 推送，各角色提交后通知 PJM 触发同步即可。
> 本文件同步到资产库「第0章 规划与协作机制」。

---

## 一、按角色查：你该把文件放哪

### 全栈开发 [FS]

| 文件类型 | 放这里 | 资产库对应章节 |
|---|---|---|
| 前端页面代码（.js/.wxml/.wxss/.wxs/.json） | `pages/<页面名>/` | 附录C 代码快照 |
| 组件代码 | `components/<组件名>/` | 附录C 代码快照 |
| 工具函数 | `utils/` | 附录C 代码快照 |
| 云函数代码 | `cloudfunctions/<函数名>/` | 附录C 代码快照 |
| 测试代码 | `test/` | 附录C 代码快照 |
| 技术方案文档 | `docs/03-技术方案/` | 第3章 技术方案 |
| 开发实现文档（评审记录、自查报告等） | `docs/04-开发实现/` | 第4章 开发实现 |

### 小程序前端开发 [FE]（候补·按需激活）

| 文件类型 | 放这里 | 资产库对应章节 |
|---|---|---|
| 前端页面代码（.js/.wxml/.wxss/.wxs/.json） | `pages/<页面名>/` | 附录C 代码快照 |
| 组件代码 | `components/<组件名>/` | 附录C 代码快照 |
| 工具函数 | `utils/` | 附录C 代码快照 |
| 前端开发记录 | `docs/04-开发实现/` | 第4章 开发实现 |

> ⚠️ FE **不碰** `cloudfunctions/`、`docs/03-技术方案/`、`test/`。仅在被 PJM 激活时工作。

### 产品经理 [PM]

| 文件类型 | 放这里 | 资产库对应章节 |
|---|---|---|
| 需求文档（需求池、竞品分析、优先级矩阵等） | `docs/01-需求规划/` | 第1章 需求规划 |
| PRD 文档 | `docs/02-产品设计/` | 第2章 产品设计 |
| 测试用例、Bug 清单 | `docs/05-测试验收/` | 第5章 测试验收 |
| 验收报告 | `docs/05-测试验收/` | 第5章 测试验收 |
| 测试脚本 | `test/` | 附录C 代码快照 |

### 产品设计师 [PD]

| 文件类型 | 放这里 | 资产库对应章节 |
|---|---|---|
| 交互原型、线框图文档 | `docs/02-产品设计/` | 第2章 产品设计 |
| 视觉设计、配色方案 | `docs/02-产品设计/` | 第2章 产品设计 |
| 设计规范 | `docs/02-产品设计/` | 第2章 产品设计 |
| 设计走查报告 | `docs/02-产品设计/` | 第2章 产品设计 |
| 1:1 原型 HTML | `docs/showcase/` | 附录C 代码快照 |
| SVG 图标 | `assets/icons/` | ❌ 不同步（非代码/文档） |

> **走查报告目录说明**：历史走查报告均在 `docs/02-产品设计/`（如 D-02-交互走查系列）。新走查报告建议也放在此处，与设计交付物保持同一上下文。`docs/04-开发实现/` 存放代码评审记录（FS 维护），PD 走查报告不属于该范畴。 |

### 项目经理 [PJM]

| 文件类型 | 放这里 | 资产库对应章节 |
|---|---|---|
| 项目计划、任务流转机制 | `docs/00-规划/` | 第0章 规划与协作机制 |
| 自查文档 | `docs/00-自查/` | 第0章 规划与协作机制 |
| 上线复盘 | `docs/06-上线复盘/` | 第6章 上线复盘 |
| 项目档案 | `docs/资产库归档/` | 附录A 资产与日志 |
| 项目日志 | `docs/项目日志.md` | 附录A 资产与日志 |

## 三、不同步到资产库的文件

| 文件 | 原因 |
|---|---|
| `TASK_BOARD.md` `COMMLOG.md` `ROLE_CARDS.md` `RELAY.md` `COLLABORATION.md` | 协作框架 live 文档（"怎么协作"不是"产品是什么"） |
| `docs/SOP-软件开发流程基准.md` | 流程模板 |
| `docs/templates/*` | 模板 |
| `node_modules/` `.git/` `assets/` `images/` `demo/` | 非代码/文档 |
| `*.png` `*.jpg` `*.svg` | 二进制资源（代码快照不收集图片） |
