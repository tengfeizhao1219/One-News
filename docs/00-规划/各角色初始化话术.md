## ⚠️ 关键前提（务必先读）

**每个 AI 角色是独立的沙箱会话**，PM 会话里已有的 `/root/one-news` **默认不存在于其他角色会话中**。所以其他角色打开会话后，**第一件事不是 `git pull`，而是先确认有没有仓库、没有就 clone**。

- 仓库地址：`https://github.com/tengfeizhao1219/One-News.git`
- TOKEN：向 PM（我）索取当前有效的 GitHub Personal Access Token，粘贴到下面命令的 `YOUR_GITHUB_TOKEN` 位置。**不要**把明文 token 写进任何会被 git 跟踪的文件（GitHub 会拦截）。

**标准初始化流程（所有角色通用）**：

```bash
# ① 确认会话里是否已有仓库
ls /root/one-news 2>/dev/null && echo "已有仓库" || echo "需要clone"

# ② 没有仓库 → clone（用 token 注入避免 TLS 问题）
TOKEN="YOUR_GITHUB_TOKEN"
git config --global "url.https://${TOKEN}:${TOKEN}@github.com/.insteadOf" "https://github.com/"
cd /root && git clone https://github.com/tengfeizhao1219/One-News.git
git config --global --unset "url.https://${TOKEN}:${TOKEN}@github.com/.insteadOf"

# ③ 已有仓库 → 直接拉最新
cd /root/one-news && git pull origin main

# ④ 读取任务看板，认领自己的任务
cat TASK_BOARD.md
```

## ⚠️ 红线提醒（转发时一并告知各角色）

1. **token 只在终端命令里用**，不要写进代码文件、不要 commit 到仓库（GitHub 会拦截）。
2. **不要 `git add -A` 乱加文件**，只加你自己改的。
3. **不要改别人的职责文件**（前端改 pages/、后端改 cloudfunctions/、PM 改 TASK_BOARD）。
4. **push 前先 pull**，避免覆盖别人（之前前端会话没 pull 最新 TASK_BOARD 导致 v4.9 被回退，已修复）。
5. **改完在 TASK_BOARD 更新自己任务状态**（📋→🔄→✅），并按交接机制激活下游。
