### 3.2 GitHub 推送令牌（PAT）—— 存放在【共享保险库】，不进仓库

- 仓库本身是**公开仓库**：`git clone` / `git pull` **不需要**任何 token。
- 仅 `git push`（写）需要 GitHub PAT。
- PAT 获取位置（详见 `docs/共享保险库使用指南.md`）：
  1. 直接找**项目经理**索要；
  2. tdrive 云盘 `vault/github_pat`（用 `file_download` 下载，文件内容即 token）；
  3. PM 会话本地保险库 `/root/.secrets/github_pat`（PM 用 `secret_get github_pat`）。
- 当前 `origin` remote **已固化该 PAT**（GM 可直接 push）；该 token 具备 `workflow` scope。
- 🔒 **安全提示**：PAT 已明文嵌入 `git remote` URL，属凭据泄漏风险。**你（FS）不需要也不应处理 git**——git 全由 GM 代理。如需重置 token，由 PM/GM 操作。

### 3.3 沙箱 / 代理框架令牌（非项目密钥，仅平台内部用）

如 `ACC_PRODUCT_CONFIG_V2/V3`、`X_IDE_AUTH_PROXY=auth.proxy`、`CODEBUDDY_SANDBOX_WEBHOOK_SECRET` 等是 CodeBuddy 沙箱运行环境变量，**与 One-News 项目无关**，由平台注入。你无需关心、不要写入项目代码。（其他角色此前遇到的 `auth.proxy` ENOTFOUND 502，即此类平台基础设施瞬时故障，非项目 bug。）

## 4. 关键开发红线（踩过坑，必看）

1. **WXS 必须纯 ES5** — 不支持 `try/catch`、`let`、`const`、箭头函数、模板字符串（`pages/home/touch.wxs` 尤其注意）。
2. **WXS 不要 `return false`** — 会阻止子元素 `bindtap` 事件。
3. **`scroll-view` 在 flex 容器** — 用 `flex:1 + min-height:0`，不用 `height:100%`。
4. **`getApp()` 不能放模块顶层** — 必须在方法内部调用并做 null 检查。
5. **云函数已平铺自包含** — 无 `common/` 目录，`require('./X')` 而非 `require('../common/X')`。
6. **零 git 操作** — 不 pull/commit/push；产出后写 `.git-staging/fs.ready`。
