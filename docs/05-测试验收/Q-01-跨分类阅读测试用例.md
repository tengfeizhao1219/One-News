## 一、测试范围

| 维度 | 覆盖内容 |
|------|----------|
| 引擎初始化 | 并行拉取 7 分类、mergedList 构建、去重、入口定位（id / category+index） |
| 翻页逻辑 | goNext / goPrev / 跨分类检测 / 边界检测 / 位置计算 |

| WXS 兼容 | 手势不阻断子元素 tap（纯 ES5 红线） |

## 二、测试用例

### 🔴 P0-01：从首页卡片进入详情 → 显示正确的进度指示

| 项 | 内容 |
|----|------|
| **前置条件** | 首页卡片流正常加载，有 ≥3 条新闻 |
| **测试步骤** | 1. 点击首页某分类卡片（如「科技」第 2 条）<br>2. 观察详情页顶部进度指示 |
| **期望结果** | 进度指示显示如「2 / N · 科技」，N = mergedList 总条数 |
| **验证点** | `positionText` 格式正确；`categoryName` 为入口分类中文名 |

### 🔴 P0-02：同分类内向下翻页（goNext，非跨分类）

| 项 | 内容 |
|----|------|
| **前置条件** | 进入详情页，当前不在本分类末条 |
| **测试步骤** | 1. 在详情页上滑触发翻页<br>2. 观察内容变化和进度指示 |
| **期望结果** | 加载下一篇新闻；进度指示 +1；无闪烁条；动画为 out-up/in-up |
| **验证点** | `goNext()` 返回 `isCrossing: false`；位置正确递增 |

### 🔴 P0-03：同分类内向上翻页（goPrev，非跨分类）

| 项 | 内容 |
|----|------|
| **前置条件** | 进入详情页，当前不在本分类首条 |
| **测试步骤** | 1. 在详情页下滑触发翻页<br>2. 观察内容变化 |
| **期望结果** | 加载上一篇新闻；进度指示 -1；无闪烁条 |
| **验证点** | `goPrev()` 返回 `isCrossing: false`；位置正确递减 |

### 🔴 P0-04：跨分类向下衔接（goNext 触发跨分类）

| 项 | 内容 |
|----|------|
| **前置条件** | 当前为某分类末条（如「科技」最后一条） |
| **测试步骤** | 1. 上滑触发翻页<br>2. 观察过渡效果和进度指示 |
| **期望结果** | ① 出现跨分类闪烁条（分类主题色，200ms）<br>② 进度指示更新为「1 / N · 国际」（下一分类名）<br>③ 内容切换为下一分类首条 |
| **验证点** | `goNext()` 返回 `isCrossing: true` + `crossingCategory`；闪烁条颜色正确；分类名更新 |

### 🔴 P0-05：跨分类向上回溯（goPrev 触发跨分类）

| 项 | 内容 |
|----|------|
| **前置条件** | 当前为某分类首条（非第一分类），如「国际」第 1 条 |
| **测试步骤** | 1. 下滑触发向上翻页<br>2. 观察过渡效果 |
| **期望结果** | ① 跨分类闪烁条（上一分类主题色）<br>② 进度指示更新为上一分类末条<br>③ 内容切换 |
| **验证点** | `goPrev()` 返回 `isCrossing: true`；位置指向上一分类末条 |

### 🔴 P0-06：末条边界 → Toast "已经是最后一条"

| 项 | 内容 |
|----|------|
| **前置条件** | 当前在 mergedList 最后一条（最后一分类末条） |
| **测试步骤** | 1. 上滑尝试继续翻页 |
| **期望结果** | ① `goNext()` 返回 `{ canGo: false, reason: 'last' }`<br>② 显示 Chip/Toast "已经是最后一条"（2s 自动消失）<br>③ 停留在当前内容，不切换 |
| **验证点** | 不出现空白页；Toast 文案正确；2s 后自动消失 |

### 🔴 P0-07：首条边界 → Toast "已经是第一条"

| 项 | 内容 |
|----|------|
| **前置条件** | 当前在 mergedList 第一条（第一分类首条） |
| **测试步骤** | 1. 下滑尝试向上翻页 |
| **期望结果** | ① `goPrev()` 返回 `{ canGo: false, reason: 'first' }`<br>② 显示 Chip/Toast "已经是第一条"<br>③ 停留在当前内容 |
| **验证点** | 不出现空白页；Toast 文案正确 |

### 🟡 P0-08：全部分类串联完整性

| 项 | 内容 |
|----|------|
| **前置条件** | 进入详情页 |
| **测试步骤** | 1. 从第一条连续向下翻页到最后一条<br>2. 记录每次翻页的分类变化 |
| **期望结果** | ① 按 CATEGORIES 顺序遍历全部 7 个分类（recommend→tech→international→sports→life→agriculture→science）<br>② 每个分类切换时出现闪烁条<br>③ 同一分类内不闪烁<br>④ 无重复新闻（去重生效） |
| **验证点** | mergedList 去重正确（seen map）；分类顺序与 constants.CATEGORIES 一致 |

### 🟡 P0-09：入口定位 — 按 newsId 精确匹配

| 项 | 内容 |
|----|------|
| **前置条件** | 首页某条新闻 id 已知 |
| **测试步骤** | 1. 构造入口参数 `{ entryCategory, entryIndex, entryNewsId }`<br>2. 初始化 ReadingEngine<br>3. 检查 `getCurrent()` |
| **期望结果** | `getCurrent().id === entryNewsId`；进度指示正确 |
| **验证点** | id 精确匹配优先于 category+index 定位 |

### 🟡 P0-10：入口定位 — 按 category+index 回退

| 项 | 内容 |
|----|------|
| **前置条件** | entryNewsId 为空或不匹配 |
| **测试步骤** | 1. 构造参数 `{ entryCategory: 'sports', entryIndex: 3, entryNewsId: '' }`<br>2. 初始化<br>3. 检查 `getCurrent()` |
| **期望结果** | 定位到 sports 分类 mergedList 中偏移 3 的位置 |
| **验证点** | category+index 回退定位生效；不越界（min 保护） |

### 🟡 P0-11：详情缓存命中（B-06 localCache，二次进入）

| 项 | 内容 |
|----|------|
| **前置条件** | 已进入过某新闻详情（localCache 有缓存） |
| **测试步骤** | 1. 退出详情页<br>2. 再次进入同一新闻<br>3. 观察网络请求 |
| **期望结果** | ① `loadCurrentDetail()` 从缓存读取（`fromCache: true`）<br>② 网络请求减少（同一新闻不重复请求）<br>③ 内容与首次一致 |
| **验证点** | 缓存 key `newsDetail:{id}`；TTL 30min |

### 🟡 P0-12：分类列表缓存命中（B-06，二次初始化）

| 项 | 内容 |
|----|------|
| **前置条件** | 已初始化过一次 ReadingEngine（10min 内） |
| **测试步骤** | 1. 再次进入详情页<br>2. 观察初始化速度 |
| **期望结果** | `_fetchCategoryWithCache` 命中缓存（`fromCache: true`）；初始化更快 |
| **验证点** | 缓存 key `newsList:{category}`；TTL 10min |

### 🟡 P0-13：详情加载失败 → 摘要降级

| 项 | 内容 |
|----|------|
| **前置条件** | 网络不可用或 getNewsDetail 返回错误 |
| **测试步骤** | 1. 断网后触发翻页<br>2. 观察内容展示 |
| **期望结果** | ① 不白屏、不崩溃<br>② 使用列表摘要（cur.summary）渲染<br>③ `onError` 不触发（降级成功视为正常） |
| **验证点** | fallback 对象包含 title/summary/category 等字段 |

### 🟡 P0-14：分类拉取失败 → 空列表处理

| 项 | 内容 |
|----|------|
| **前置条件** | 某个分类 `getNewsList` 返回 error |
| **测试步骤** | 1. 模拟某分类接口失败<br>2. 初始化 ReadingEngine |
| **期望结果** | ① 该分类 list 为空数组，不阻塞其他分类<br>② mergedList 不含该分类条目<br>③ 跨分类翻页跳过该分类（静默） |
| **验证点** | `_fetchCategoryWithCache` catch 返回 `{ list: [], error: true }` |

### 🟡 P0-15：预取窗口 ±2 不阻塞主流程

| 项 | 内容 |
|----|------|
| **前置条件** | 正常网络环境 |
| **测试步骤** | 1. 翻到第 5 条<br>2. 检查预取状态 `_prefetched` |
| **期望结果** | ① 第 3/4/6/7 条已标记预取<br>② 预取请求静默，不影响当前页渲染速度<br>③ 预取失败不抛异常 |
| **验证点** | `_prefetchWindow` 不触发 `onError` |

### 🟡 P0-16：返回定位 — 跨分类索引（B-07）

| 项 | 内容 |
|----|------|
| **前置条件** | 在详情页跨分类翻页到「国际」分类第 3 条 |
| **测试步骤** | 1. 点击返回<br>2. 检查 `_detailReturnState` |
| **期望结果** | ① `_detailReturnState = { category: 'international', categoryIndex: N, newsId: 'xxx' }`<br>② 首页收到后定位到「国际」分类正确位置<br>③ 侧边栏同步切换 |
| **验证点** | category 正确；newsId 精确匹配首页列表 |

### 🟡 P0-17：WXS 手势不阻断子元素 tap

| 项 | 内容 |
|----|------|
| **前置条件** | 详情页正常显示 |
| **测试步骤** | 1. 点击详情页内链接/按钮（如来源链接）<br>2. 观察是否正常响应 |
| **期望结果** | 子元素 tap 事件正常触发；不被 WXS touch 拦截 |
| **验证点** | WXS 层无 `return false`；`touch.wxs` 纯 ES5 |

### 🟡 P0-18：去重 — 同一新闻跨分类不重复

| 项 | 内容 |
|----|------|
| **前置条件** | 某新闻同时出现在两个分类（边界情况） |
| **测试步骤** | 1. 构造数据：同一 id 出现在两个分类<br>2. 初始化 ReadingEngine |
| **期望结果** | mergedList 中该 id 只出现一次（首次出现的位置） |
| **验证点** | `seen` map 去重生效 |

### 🟡 P1-01：跨分类阅读中网络不可用 → 展示"网络开小差，下拉重试"（口径审查偏差 #2 补充）

| 项 | 内容 |
|----|------|
| **前置条件** | ① 已进入详情页，正在跨分类阅读中<br>② 目标分类无本地缓存 |
| **测试步骤** | 1. 断开网络<br>2. 翻页到下一个分类（触发 getNewsDetail 请求）<br>3. 观察 UI 反馈 |
| **期望结果** | ① 显示黄色 Toast "网络开小差，下拉重试"（3s 自动消失）<br>② 停留在当前最后一条，不白屏、不崩溃<br>③ 不静默降级到摘要（需显式告知用户网络异常） |
| **验证点** | Toast 颜色为黄色（区别于绿色成功/红色失败）；文案与 PRD §5.1 一致；不出现空白页 |
| **PRD 对照** | PRD §5.1："网络不可用且目标分类本地无缓存时 → 展示'网络开小差，下拉重试'提示，停在最后一条" |
