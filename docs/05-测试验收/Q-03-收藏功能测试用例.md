## 一、测试用例

### 🔴 P1-01：详情页收藏按钮 — ♡ → ♥ 切换

| 项 | 内容 |
|----|------|
| **前置条件** | 进入详情页，当前新闻未收藏 |
| **测试步骤** | 1. 查看底部操作栏收藏按钮<br>2. 点击收藏按钮 |
| **期望结果** | ① 按钮从 ♡ 变为 ♥（heartBeat 动画 350ms）<br>② Toast "已收藏"<br>③ localCache 写入成功 |
| **验证点** | `toggleFavorite` 正确调用；`_cache.set('favorites', ...)` |

### 🔴 P1-02：取消收藏 — ♥ → ♡

| 项 | 内容 |
|----|------|
| **前置条件** | 当前新闻已收藏（♥ 状态） |
| **测试步骤** | 1. 点击 ♥ 按钮 |
| **期望结果** | ① 按钮从 ♥ 变回 ♡<br>② Toast "已取消收藏"<br>③ localCache 中该条目移除 |
| **验证点** | `favorites.filter` 正确移除 |

### 🔴 P1-03：退出重进后收藏状态保持

| 项 | 内容 |
|----|------|
| **前置条件** | 某新闻已收藏 |
| **测试步骤** | 1. 退出详情页<br>2. 重新进入同一新闻 |
| **期望结果** | 按钮显示为 ♥（已收藏状态） |
| **验证点** | `_checkIsFavorited` 从 localCache 正确读取 |

### 🔴 P1-04：侧边栏「❤️ 收藏」Tab — 列表渲染

| 项 | 内容 |
|----|------|
| **前置条件** | 已收藏 ≥2 条新闻 |
| **测试步骤** | 1. 左滑打开侧边栏<br>2. 滑到最右侧「❤️ 收藏」Tab<br>3. 点击 |
| **期望结果** | ① 展示收藏列表，按时间倒序排列<br>② 每条显示标题 + 分类名 + 收藏时间<br>③ 点击条目可跳转详情页 |
| **验证点** | `_loadFavorites` 正确读取 + 排序；条目点击跳转 |

### 🔴 P1-05：收藏空态展示

| 项 | 内容 |
|----|------|
| **前置条件** | 无收藏记录 |
| **测试步骤** | 1. 切换到「❤️ 收藏」Tab |
| **期望结果** | 展示空态：♡ 图标 + "还没有收藏任何新闻" + 引导文案 |
| **验证点** | 空态布局正确；不出现空白页 |

### 🟡 P1-06：收藏容量上限 200 条

| 项 | 内容 |
|----|------|
| **前置条件** | 已收藏 200 条新闻 |
| **测试步骤** | 1. 尝试收藏第 201 条 |
| **期望结果** | Toast "收藏已满，请清理后重试"；不添加；列表仍为 200 条 |
| **验证点** | `favorites.length >= 200` 判断生效 |

### 🟡 P1-07：重复收藏幂等保护

| 项 | 内容 |
|----|------|
| **前置条件** | 某新闻已收藏 |
| **测试步骤** | 1. 再次点击收藏（模拟快速双击/重复操作） |
| **期望结果** | 不产生重复条目；列表仍为 1 条该新闻 |
| **验证点** | `favorites.some(f => f.id === news.id)` 幂等检查 |

### 🟡 P1-08：弱网/断网下收藏列表可读

| 项 | 内容 |
|----|------|
| **前置条件** | 已收藏 ≥2 条，localCache 有数据 |
| **测试步骤** | 1. 开启飞行模式<br>2. 进入「❤️ 收藏」Tab<br>3. 点击收藏条目 |
| **期望结果** | ① 列表完整显示（从 localCache 读取）<br>② 点击条目可进入详情（本地缓存内容） |
| **验证点** | 收藏数据不依赖网络；localCache 持久化到 Storage |

### 🟡 P1-09：收藏后反复切换（收藏→取消→收藏）

| 项 | 内容 |
|----|------|
| **前置条件** | 进入详情页 |
| **测试步骤** | 1. 收藏 → 取消 → 收藏 → 取消（交替 5 次） |
| **期望结果** | 每次状态正确切换；无残留数据；localCache 最终状态与 UI 一致 |
| **验证点** | 快速连续点击无竞态问题 |

### 🟡 P1-10：收藏条目内容变更后仍可读

| 项 | 内容 |
|----|------|
| **前置条件** | 某新闻已收藏，其源内容可能已更新 |
| **测试步骤** | 1. 从收藏列表进入详情<br>2. 观察内容 |
| **期望结果** | 显示收藏时的快照内容（或最新内容）；不报错不崩溃 |
| **验证点** | 收藏列表条目含基本字段（id/title/category），详情走正常加载流程 |
