## 一、测试范围

### 1.1 测试范围边界

| 维度 | 范围内（本次测试） | 范围外（本次不测试） |
|------|-------------------|---------------------|
| **数据获取** | 云函数 getNewsList 通过天行/聚合 API 获取新闻列表 | 云数据库 news 集合的查询功能（已废弃） |
| **搜索功能** | 云函数 searchNews 通过天行 API 搜索及降级过滤 | 云数据库模糊正则搜索（已废弃） |
| **缓存机制** | 内存缓存 + 云数据库缓存的命中、过期、刷新 | 离线缓存（不在本次迭代范围） |
| **降级方案** | 主API→备API→缓存兜底的逐级降级 | 其他非新闻接口的降级 |
| **前端适配** | 加载/错误/空数据状态、分类切换刷新、数据格式兼容 | 新闻详情页、收藏/点赞、用户系统 |
| **UI回归** | 首页卡片流、侧边栏分类切换、搜索页面交互正常 | UI样式变更、动效优化 |
| **兼容性** | iOS/Android 微信小程序网络场景 | PC端、其他平台 |
| **性能** | 首屏加载、翻页、搜索响应时间 | 内存占用、包体积 |

### 1.2 测试环境

| 项目 | 环境 |
|------|------|
| 微信版本 | iOS 微信 8.0.50+ / Android 微信 8.0.50+ |
| 基础库版本 | 3.0.0+ |
| 云函数环境 | CloudBase 测试环境 |
| API 服务 | 天行数据（主）+ 聚合数据（备） |
| 网络条件 | WiFi / 4G / 弱网（模拟） |

### 1.3 测试策略

- **接口测试**：通过云函数测试控制台直接调用，验证返回数据结构与错误处理
- **端到端测试**：微信开发者工具 + 真机测试，验证完整链路
- **异常模拟**：通过修改云函数代码、网络代理、API Key 等手段模拟异常场景
- **性能测试**：使用微信开发者工具的性能面板记录加载耗时
