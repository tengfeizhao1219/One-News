## 二、🔴 阻断级发现

### RQ-10 内容安全审核 — 零覆盖

PRD §5.2 明确 RQ-10 为 **P0**。当前 Q-01~Q-05 全部为前端功能测试，**无任何内容安全 API 相关测试用例**。

| AC-RQ10 要求 | 期望测试 | 现状 |
|-------------|---------|:---:|
| IF 命中 msgSecCheck THEN 该条不入库且有日志 | 云函数层用例：构造敏感文本 → 验证不入库 + sync_logs 写入 | ❌ 无 |
| WHERE 含图片 THEN 对图片做 imgSecCheck | 云函数层用例：含图新闻 → 验证 imgSecCheck 调用 | ❌ 无 |
| API 不可用时保守暂缓入库并告警 | 云函数层用例：模拟 API 超时 → 验证保守策略（不直接放行） | ❌ 无 |

> 测试工程师在 Q-06 §4 已意识到此缺口，建议新增 `v9-regression-content-safety.js`，但标记为「可在阶段五完成后补」。**P0 功能不应在上线后补测。**
>
> **阻塞判定**：RQ-10 是本迭代唯二的 P0 之一（另一个是 RQ-01 跨分类），合规功能无测试即上线存在小程序下架风险。
>
> **建议**：要求测试工程师在 Q-03 回归测试完成前，至少补充 3 条内容安全测试用例。

## 三、🟡 需关注偏差

### 偏差 1：Q-01 P0-13 网络不可用场景期望与 PRD 不一致

| 对比维度 | PRD §5.1 | Q-01 P0-13 |
|---------|------|------|
| **触发条件** | 网络不可用 **且** 目标分类本地无缓存 | 网络不可用 **或** getNewsDetail 返回错误 |
| **期望行为** | 展示「网络开小差，下拉重试」提示，**停在最后一条** | 使用列表摘要渲染（`cur.summary`），降级成功视为正常 |
| **交互差异** | 显式错误 UI + 重试入口 | 静默降级到摘要，用户无感知 |

> 两种策略不互斥，但 PRD 明确要求的「网络开小差，下拉重试」场景在 Q-01 中无对应验证。建议新增一条用例覆盖此场景。

### 偏差 2：Q-04 P1-02 分享标题截断未覆盖 UX-FIX05 修复点

UX-FIX05 修复逻辑为「先加 `一页 | ` 前缀 → 再截断至 29 字符」。P1-02 仅验证了「标题截断为 ≤30 字符 + ...」，**未专门验证前缀不会被截掉**。

> 边界场景：标题恰好 29 字 → `一页 | ` + 标题 = 34 字 → 截断到 29 → 前缀被部分截断。建议新增一条边界验证。
