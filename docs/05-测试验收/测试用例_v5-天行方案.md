# 测试用例 — v5.0 天行 API 轻量列表缓存方案

> **版本**：v5.0
> **测试对象**：`refreshNews` + `getNewsList` + `getNewsDetail`
> **测试目标**：验证 3 秒超时约束下，天行 API 列表缓存 + 详情页按需抓取正文方案可用
> **前置条件**：
>   1. 云函数 `refreshNews` / `getNewsList` / `getNewsDetail` 已部署 v5.0 代码
>   2. 环境变量 `TIAN_API_KEY` 已配置
>   3. `news_cache` 和 `news` 集合已清空（或已知旧数据状态）
>   4. 小程序首页、详情页代码未改动（兼容 v5.0 数据结构）

---

## 一、功能测试

### TC-F01 refreshNews 手动触发

| 项 | 内容 |
|---|---|
| **测试目的** | 验证手动触发 refreshNews 能在 3 秒内完成并写入数据 |
| **前置条件** | 云函数已部署，环境变量已配置，数据库已清空 |
| **测试步骤** | 1. 在云函数控制台选择 `refreshNews` → 测试 → 参数 `{}` → 运行 |
