## 一、验收标准逐条可测试性评估

基于 D-01 PRD §7 的 7 条 AC（AC-RQ01~AC-RQ07），逐条评估：

### AC-RQ01：跨分类衔接（P0）

| 维度 | 评估 |
|------|------|
| **可测试性** | ✅ 可测。需确认技术方案（方案 A/B），不同方案测试方式不同 |
| **现有覆盖** | ❌ 零覆盖。v7 回归仅静态架构检查（37 条），当前 detail.js 仅同分类翻页 |
| **测试缺口** | 核心功能用例完全缺失：跨分类首条衔接、末分类 Toast、进度指示更新、子元素 tap 不阻断、返回定位跨分类 |

**关键测试场景**：
- 正向：科技末条上滑 → 国际首条；国际末条上滑 → 体育首条；… → 生活末条 Toast"已是最后一条"
- 边界：当前分类仅 1 条；所有分类均空；跨分类中途网络失败
- 回归：同分类翻页不受影响（`pageTo`）、返回定位 `_detailReturnState` 含跨分类索引

**待确认**：Q-D1（方案 A vs B）决定衔接数据来源——是预拉全量串联列表（方案 A），还是实时请求下一分类（方案 B），将直接影响测试环境准备和性能验证方式。

---

### AC-RQ10：内容合规审核（P0）

| 维度 | 评估 |
|------|------|
| **可测试性** | ⚠️ 需后端配合。需可注入合规/不合规测试内容，需可模拟 API 不可用 |
| **现有覆盖** | ❌ 零覆盖。无内容安全 API 测试用例 |
| **测试缺口** | 合规命中不入库、日志记录、API 不可用→暂缓入库+告警、批量混合处理 |

**关键测试场景**：
- 正向：含违规词内容 → API 命中 → 不入库 + 日志记录
- 异常：API 超时/5xx → 保守暂缓 + 告警；API 限流 → 排队重试
- 边界：单条命中/未命中混合批次；空内容；极端长文本
- 回归：已有 178 用例中的 L1 天行/L4 聚合数据流程不受合规阻断影响

**待确认**：Q-D3（API 调用方式与配额评估）决定合规检测是同步/异步、在数据流水线哪个环节介入。

---

### AC-RQ04：字体大小调节（P1）

| 维度 | 评估 |
|------|------|
| **可测试性** | ✅ 可测。前端 UI 功能，开发者工具可验证 |
| **现有覆盖** | ❌ 零覆盖。无字体调节测试用例 |
| **测试缺口** | 3-4 档字号全局生效、持久化记忆、首入跟随系统、切换无闪烁 |

**关键测试场景**：
- 正向：小→中→大→特大 逐档切换，详情页正文/标题均生效
- 状态：关闭小程序重开 → 字体保持上次设置
- 首入：未设置过 → 跟随系统字体（iOS 辅助功能/Android 字体缩放）
- 边界：暗色模式下字体可读性；极端字号在小屏设备不溢出
- 回归：首页卡片、侧边栏、搜索页字号不受详情页字体影响（仅详情页生效）

---

### AC-RQ03：收藏功能（P1）

| 维度 | 评估 |
|------|------|
| **可测试性** | ✅ 可测。本地存储功能，开发者工具+真机均可验证 |
| **现有覆盖** | ❌ 零覆盖。无收藏功能测试用例 |
| **测试缺口** | 收藏/取消本地持久化、按钮态变更、弱网可读、收藏列表、重复操作 |

**关键测试场景**：
- 正向：详情页点收藏 → 按钮变为"已收藏"→ 退出重进仍为已收藏
- 取消：已收藏项再点 → 取消 → 按钮恢复
- 弱网：断网状态下查看收藏列表 → 内容可读（本地存储）
- 边界：收藏后又取消再收藏（反复切换）；收藏大量条目（50+）；存储空间不足
- 回归：收藏不应影响现有 `detail.js` 的 `loadDetail` 和 `goBack` 逻辑

## 二、178 用例基线复用评估

| 模块 | 覆盖 | 与阶段二关联 |

## 五、风险提示

| 风险 | 等级 | 说明 |
|------|:----:|------|

## 六、预审结论

1. PRD §7 7 条 AC 均可测试，但 AC-RQ01（跨分类）和 AC-RQ10（合规）依赖 T-01 技术方案锁定后才能细化测试用例
2. 178 用例基线仅覆盖 ≈14%（1/7），阶段二需全新增 6 项 AC 测试用例
3. A-12a/b/c 评审已全部就绪，T-01 技术方案可立即启动
4. 建议 T-01 锁定后，测试工程师立即补 3 份功能测试用例（跨分类/合规/收藏），同步建设 v8/v9/v10 回归脚本
