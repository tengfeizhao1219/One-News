## 一、测试范围

### 1.1 测试范围边界

| 维度 | 范围内（本次测试） | 范围外（本次不测试） |
|------|-------------------|---------------------|
| **refreshNews 云函数** | 从 GitHub 拉取 news.json、JSON 解析、数据校验、写入云数据库、错误处理、日志记录 | WorkBuddy 生成 news.json 的质量、GitHub Actions 自动化推送 |
| **getNewsList 云函数** | 缓存层级调整（DB 缓存提升为第2层）、降级兜底、数据一致性 | 外部 API（天行/聚合）的稳定性（已有覆盖） |
| **searchNews 云函数** | DB 全量搜索层（新增）、降级静态缓存搜索、无匹配场景 | 外部 API 搜索的稳定性（已有覆盖） |
| **定时触发器** | 触发时机、幂等性、重复触发不产生重复数据、手动触发 | CloudBase 触发器平台的 SLA |
| **数据一致性** | refreshNews 与 getNewsList/searchNews 之间的数据切换、新旧数据切换时的无缝体验 | 跨环境数据同步 |
| **性能** | refreshNews 执行耗时、getNewsList 响应时间、searchNews 响应时间 | 云数据库扩展性、高并发场景 |
| **前端适配** | 数据切换过程中用户体验（加载/错误/空状态）、分类筛选、分页加载 | UI 样式变更、动画优化 |

### 1.2 测试环境

| 项目 | 环境 |
|------|------|
| 微信版本 | iOS 微信 8.0.50+ / Android 微信 8.0.50+ |
| 基础库版本 | 3.0.0+ |
| 云函数环境 | CloudBase 测试环境 |
| 数据源 | GitHub Raw URL（测试仓库 `data/news.json`） |
| 云数据库 | `news_cache` 测试集合 |
| 网络条件 | WiFi / 4G / 弱网（模拟） |

### 1.3 测试策略

- **云函数测试**：通过 CloudBase 控制台直接调用云函数，验证返回数据结构与错误处理
- **Mock 测试**：通过修改云函数代码、网络代理、模拟 GitHub 不可用等手段模拟异常场景
- **端到端测试**：微信开发者工具 + 真机测试，验证完整链路
- **性能测试**：使用云函数调用日志记录执行耗时，微信开发者工具 Performance 面板
- **数据一致性测试**：对比 GitHub `news.json` 与云数据库 `news_cache` 集合中的数据

## 附录 A：错误码参考

| 错误码 | 说明 | 触发场景 |
|--------|------|---------|
| `GITHUB_TIMEOUT` | GitHub 连接超时 | 网络不通或 GitHub 响应慢 |
| `GITHUB_ERROR` | GitHub 返回非 200 | Raw URL 无效或文件不存在 |
| `JSON_PARSE_ERROR` | JSON 解析失败 | news.json 格式损坏 |
| `DATA_VALIDATION_ERROR` | 数据校验失败 | news 数组为空或字段缺失 |
| `DB_WRITE_ERROR` | 数据库写入失败 | 配额耗尽或权限问题 |
| `ALL_DOWN` | 所有数据源不可用 | 全部降级链路失败 |
| `UNKNOWN_ERROR` | 未知错误 | 其他未分类异常 |
