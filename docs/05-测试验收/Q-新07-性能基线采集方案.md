## 一、背景

现有一份 `性能测试报告.md`（2026-07-27）基于 Mock 模式采集，指标远优于真实环境。阶段二新增跨分类阅读引擎（方案 A：7 分类并行预拉 ≈50 条）、字体面板（CSS calc 实时计算）、收藏（localCache 读写）、分享（Canvas→静态图预生成）等均引入了新的性能开销。**本次采集建立真实数据下的性能基线**，作为后续性能回归的参照。

## 二、采集指标

### 2.1 核心指标（必采集）

| 指标 | 口径 | P50 目标 | P95 目标 |
|------|------|:------:|:------:|
| **首页首屏时间** | `home.onLoad` → 第一张卡片渲染完成 | < 1.5s | < 3s |
| **详情页打开时间** | 点击卡片 → `detail.onReady` + 内容渲染 | < 800ms | < 2s |
| **同分类翻页耗时** | 上滑手势 → 下一篇内容渲染完成 | < 300ms | < 500ms |
| **跨分类切换耗时** | 跨分类 goNext → 内容渲染 + 闪烁条完成 | < 500ms | < 1s |
| **ReadingEngine 初始化** | `engine.init()` 并行拉取 7 分类 → mergedList 就绪 | < 2s | < 5s |
| **字体切换延迟** | 点击档位 → CSS 变量生效 + 页面重绘 | < 100ms | < 200ms |
| **收藏读写耗时** | `toggleFavorite` 读写 localCache | < 50ms | < 100ms |

### 2.2 辅助指标

| 指标 | 说明 |
|------|------|
| **内存占用** | 首页加载后 / 连续翻页 30 条后 / 收藏 200 条后 |
| **网络请求数** | 首页加载 / 详情进入 / 预取窗口 |
| **缓存命中率** | 二次进入详情 / 二次初始化 ReadingEngine |
| **setData 调用频率** | 翻页时 setData 次数与数据量 |

## 四、采集步骤

### 步骤 1：打点埋码

在关键路径插入 `console.time` / `console.timeEnd`（采集完后需清理）：

```javascript
// detail.js — ReadingEngine 初始化
console.time('engine.init')
engine.init().then(function() { console.timeEnd('engine.init') })

// detail.js — 翻页
console.time('detail.pageNext')
// ... goNext + loadCurrentDetail
console.timeEnd('detail.pageNext')

// detail.js — 字体切换
console.time('font.switch')
app.setFontScale(tier)
console.timeEnd('font.switch')

// detail.js — 收藏
console.time('fav.toggle')
toggleFavorite()
console.timeEnd('fav.toggle')
```

### 步骤 2：逐项采集

| # | 操作 | 采集指标 | 重复次数 |
|:--|------|----------|:------:|
| 1 | 冷启动 → 首页 | 首屏时间 + 网络请求数 | 5 次 |
| 2 | 点击卡片 → 详情 | 详情打开时间 + engine.init | 5 次 |
| 3 | 同分类连续翻页 10 条 | 每次 pageTo 耗时 | 3 轮 |
| 4 | 跨分类连续翻页（遍历 7 分类） | 每次跨分类切换耗时 | 2 轮 |
| 5 | 字体 4 档循环切换 | 每次切换延迟 | 3 轮 |
| 6 | 收藏/取消 10 次 | 每次 toggle 耗时 | 3 轮 |
| 7 | 连续翻页 30 条 → 查内存 | 内存峰值 | 2 次 |
| 8 | 二次进入详情（缓存命中） | engine.init 耗时 / loadCurrentDetail 耗时 | 3 次 |

### 步骤 3：数据分析

- 剔除首次冷启动（云函数冷启动）的最大值
- 计算 P50 / P95 / Max
- 与 Mock 基线对比，评估增量开销
