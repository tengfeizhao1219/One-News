## 一、测试用例

### 🔴 P1-01：字体面板入口 → 底部半屏面板弹出

| 项 | 内容 |
|----|------|
| **前置条件** | 首页正常加载 |
| **测试步骤** | 1. 点击首页 ⚙️ 设置图标<br>2. 观察面板弹出 |
| **期望结果** | 底部半屏面板从下弹出，展示 4 档字号选项（标准/大/特大/超大）+ 当前选中高亮 |
| **验证点** | 面板动画流畅；遮罩层可点击关闭 |

### 🔴 P1-02：4 档字号即时切换生效

| 项 | 内容 |
|----|------|
| **前置条件** | 字体面板打开，当前「标准」 |
| **测试步骤** | 1. 依次点击「大」→「特大」→「超大」<br>2. 每次点击后观察首页卡片和详情页文字 |
| **期望结果** | 每次点击即时生效：card-title / summary-p / card-meta 等文字逐档变大；详情页正文同步变化 |
| **验证点** | 无需确认按钮；无闪烁/白屏；`--font-scale` CSS 变量正确更新（1 → 1.15 → 1.3 → 1.5） |

### 🔴 P1-03：关闭面板后字号保持

| 项 | 内容 |
|----|------|
| **前置条件** | 设置为「大」档 |
| **测试步骤** | 1. 点击遮罩关闭面板<br>2. 再次打开面板 |
| **期望结果** | 文字保持「大」档；面板再次打开时「大」档高亮 |
| **验证点** | 关闭不重置字号 |

### 🔴 P1-04：关闭小程序重开后字号记忆

| 项 | 内容 |
|----|------|
| **前置条件** | 设置为「特大」档 |
| **测试步骤** | 1. 完全关闭小程序<br>2. 重新打开<br>3. 检查首页和详情页字号 |
| **期望结果** | 文字保持「特大」档；无需重新设置 |
| **验证点** | `wx.setStorageSync('fontScale', tier)` 持久化生效；`app._initFontScale()` 启动时正确读取 |

### 🟡 P1-05：首入跟随系统字号

| 项 | 内容 |
|----|------|
| **前置条件** | 首次安装/清除缓存后首次启动 |
| **测试步骤** | 1. 系统设置大字体（iOS 辅助功能 / Android 字体缩放）<br>2. 首次打开小程序 |
| **期望结果** | 初始档位匹配系统设置；不强制覆盖为「标准」 |
| **验证点** | `wx.getSystemInfoSync().fontSizeSetting` 映射到 fontScale 档位 |

### 🟡 P1-06：暗色模式下字体面板配色正确

| 项 | 内容 |
|----|------|
| **前置条件** | 系统暗色模式开启 |
| **测试步骤** | 1. 打开字体面板<br>2. 检查面板背景、文字颜色、选中态 |
| **期望结果** | 面板背景适配暗色；文字与背景对比度 ≥ 4.5:1（WCAG AA）；选中态清晰可辨 |
| **验证点** | 无"白底白字"或"黑底黑字"问题 |

### 🟡 P1-07：极端字号小屏不溢出

| 项 | 内容 |
|----|------|
| **前置条件** | 小屏设备（iPhone SE 4.7" 或等同），设为「超大」 |
| **测试步骤** | 1. 查看首页卡片标题<br>2. 查看详情页正文 |
| **期望结果** | 标题截断（...）+ 行高保护；正文正常换行不溢出；按钮/图标不被挤出可视区 |
| **验证点** | `word-break: break-word` / `overflow-wrap: break-word` 生效；无横向滚动条 |

### 🟡 P1-08：字体不影响非详情页元素

| 项 | 内容 |
|----|------|
| **前置条件** | 设为「超大」档 |
| **测试步骤** | 1. 检查侧边栏分类列表<br>2. 检查设置图标大小 |
| **期望结果** | 侧边栏 panel-item-title 跟随字号变化（按设计规范）；设置图标保持固定大小（不缩放） |
| **验证点** | 不缩放元素（图标/装饰）不受 `--font-scale` 影响 |
