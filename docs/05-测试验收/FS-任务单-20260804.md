| # | 问题 | 级别 | 现象 | 修复方向 |
|---|------|:---:|------|------|
| ⑥ | **正文末尾串入其他新闻正文** | **P0** | IT之家来源详情页，正文后混入完全无关的「延伸阅读」新闻（如"车扫老人"末尾出现"电动车充电摔倒""地库积水"） | 方案 A（推荐）：`extractContentFromHtml` 严格限定容器范围，避免延伸到页脚延伸阅读区。方案 B：启发式识别主题切换（新人物+新地点+无指代）。方案 C：优先使用聚合内容接口（juhe），网页抓取仅兜底 |

| ③ | 「广告声明」噪音未过滤 | P1 | IT之家文末「广告声明：文内含有的对外跳转链接…」 | `newsCleaner.js` `removeNoiseLines` 增加 `/^(广告声明)[：:]/` 规则 |
| ④ | 图片说明残留 | P1 | 「购卡凭证（央广网发 受访者供图）」等图说被当正文 | `removeNoiseLines` 增加：`/[（(]?\s*(受访者供图|央广网发|新华社发|图源|图片来源|视觉中国)\s*[）)]?/i`；单独成段且含「图」「摄」「供」+「图/发/摄」类词的短行 |
| ⑤ | 微信扫码分享引导覆盖不全 | P1 | 「用微信扫描二维码」+「分享至好友和朋友圈」两行未命中现有规则 | 增强规则：`/用微信(扫描|扫一扫)?二维码|扫一扫.*分享|分享.*好友.*圈/`；合并"扫二维码"和"分享至"为同一噪音组 |
| ② | `remove()` 不支持 limit | P2 | `gradedCleanup` `.limit(BATCH).remove()` 未生效（removed=0） | `refreshNews/index.js` 改分批 `where` + `remove`，每批 ≤100 条 |
