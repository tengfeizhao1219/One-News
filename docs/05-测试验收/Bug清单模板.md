# Bug 清单

> **用途**：记录测试过程中发现的所有缺陷，跟踪修复状态。

---

## 填写规范

| 字段 | 说明 | 必填 |
|------|------|:----:|
| Bug ID | 格式 `BUG-YYYYMMDD-序号` | ✅ |
| 标题 | 一句话描述问题现象 | ✅ |
| 优先级 | P0 阻断 / P1 严重 / P2 一般 / P3 轻微 | ✅ |
| 模块 | 首页 / 详情页 / 搜索页 / 侧边栏 / 云函数 / 数据层 / 阅读模式 / 其他 | ✅ |
| 状态 | 新建 / 修复中 / 待验证 / 已关闭 / 重开 / 拒绝 | ✅ |
| 指派给 | 开发负责人 | ✅ |
