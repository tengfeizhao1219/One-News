### BUG-20260731-001：reading-engine.js 空分类回退定位越界

**基本信息**
- 优先级：🟡 P1
- 模块：阅读模式
- 状态：已关闭
- 指派给：@前端开发
- 发现版本：v1.0（阶段四）

**复现步骤**
1. 进入详情页，入口分类的所有 getNewsList 均失败（返回空 list）
2. entryNewsId 也未匹配到任何条目
3. 触发 `_buildMergedList` 的 category+index 回退定位

**实际结果**
`entryGlobalIndex = catStart + Math.min(entryIndex, merged.length - catStart - 1)` 中 `merged.length - catStart - 1` 为 -1，导致定位到上一分类末条而非预期位置。

**期望结果**
空分类时兜底到首条或相邻分类首条。

**影响范围**
- 影响模块：阅读模式
- 是否阻断核心流程：否（需该分类全部接口失败才触发）

**修复记录**（开发填写）
- 修复版本：commit 618ce73 / 修复说明：`_buildMergedList` 增加 `catSize <= 0` 检查，空分类兜底到 index 0 / 关联 PR：—（直推 main）

**验证结论**（测试填写）
- 验证版本：commit 618ce73 / 验证结果：✅ 通过 / 验证人：QA / 关闭时间：2026-07-31

### BUG-20260731-003：分享标题截断可能拆分 emoji

**基本信息**
- 优先级：🟢 P2
- 模块：详情页
- 状态：已关闭
- 指派给：@前端开发
- 发现版本：v1.0（UX-FIX05 修复后）

**复现步骤**
1. 新闻标题含多字节 emoji（如 👨‍👩‍👧‍👦），且 "一页 | " + title 总长 > 30
2. 点击分享

**实际结果**
`title.slice(0, 29)` 按 UTF-16 码元切割，可能从 emoji 中间截断，产生 � 乱码。

**期望结果**
使用 `Array.from(title)` 按 codepoint 安全截断。

**影响范围**
- 影响模块：分享功能
- 是否阻断核心流程：否（emoji 在新闻标题中出现概率极低）

**修复记录**（开发填写）
- 修复版本：commit 618ce73 / 修复说明：`Array.from(title).slice(0, 29).join('')` 按 codepoint 安全截断 / 关联 PR：—

**验证结论**（测试填写）
- 验证版本：commit 618ce73 / 验证结果：✅ 通过 / 验证人：QA / 关闭时间：2026-07-31

- 模块：详情页
- 状态：新建

1. 打开任意新闻详情页
2. 观察底部翻页按钮（↑↓ 箭头）与底部操作栏（🤍收藏 / ↗️分享）的视觉关系

**期望结果**
翻页按钮与操作栏有明确间距（≥ 40rpx），视觉上完全分离，z-index 合理。

- 影响模块：详情页翻页交互
- 是否阻断核心流程：否（核心阅读功能正常，但影响可用性——可能误触）

**修复建议**
- `.pager-hint bottom` 从 `140rpx` 提高到 `220rpx`
