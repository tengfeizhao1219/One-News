### BUG-20260801-007：首页刷新后卡片更新、侧边栏列表不更新（_panelCache 永不失效）

**基本信息**
- 优先级：🟡 P1
- 模块：侧边栏/首页
- 状态：待验证（QA 已提交补丁，commit `01a52ab`）
- 指派给：@前端开发
- 发现版本：v1.0（阶段五 实测）
- 发现人：QA（用户反馈「卡片和列表内容不一致」后复现）
- 环境：真机 / 微信 8.x / 基础库 3.x / 正常网络

**复现步骤**
1. 冷启动首页，首页卡片（`newsList`）与侧边栏列表（`filteredNewsList`）均为第一批数据。
2. 触发刷新：下拉刷新（`onPullDownRefresh` → `loadNews`）或点「手动刷新」（`onRefreshNews` → `refreshNews` 云函数 → `loadNews`）。
3. 首页卡片更新为新数据；左滑呼出侧边栏查看「全部新闻」列表。

**实际结果**
> 侧边栏列表仍展示**刷新前**的旧新闻，与首页当前卡片内容不一致；且只要不切换分类，侧边栏永远停留在首次加载的快照，任何刷新都不会让其更新。

**期望结果**
> 首页卡片与侧边栏列表都来自同一份数据源；任一处刷新后，另一处也应同步反映最新数据（或至少侧边栏在打开时拉取最新）。

**根因定位**
- `pages/home/home.js` 第 166 行 `this._panelCache = {}` 定义侧边栏内存缓存；
- 第 169–198 行 `loadPanelNews(category)`：命中 `_panelCache[cat]` 时直接 `return`（第 179 行），**永不重新拉取、永不失效**；
- 第 141–163 行 `loadNews()`：仅 `setData({ newsList })`（第 153 行）+ `renderCards(list)`（第 154 行），**全程不触碰 `_panelCache`**；
- 第 201–205 行 `onPullDownRefresh`、第 213–243 行 `onRefreshNews` 都只调 `loadNews()`，同样不清理 `_panelCache`。

**影响范围**
- 影响模块：首页卡片、侧边栏「全部新闻」列表
- 是否阻断核心流程：否（卡片阅读正常），但属于用户可见的**数据正确性**问题，正是用户反馈的「卡片和列表内容不一致」主因。

**修复建议**
- 方案 A（最小改动）：`onRefreshNews` / `onPullDownRefresh` 刷新成功后执行 `this._panelCache = {}`，使下次侧边栏打开重新拉取；
- 方案 B（更彻底）：侧边栏与主列表共用同一份 `newsList`，去掉独立 `_panelCache`，避免双数据源；
