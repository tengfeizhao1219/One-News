### BUG-20260731-001：reading-engine.js 空分类回退定位越界

**基本信息**
- 优先级：🟡 P1
- 模块：阅读模式
- 状态：已关闭
- 指派给：@前端开发
- 发现版本：v1.0（阶段四）

**复现步骤**
1. 进入详情页，入口分类的所有 getNewsList 均失败（返回空 list）

**影响范围**
- 影响模块：阅读模式
- 是否阻断核心流程：否（需该分类全部接口失败才触发）

**修复记录**（开发填写）
- 修复版本：commit 618ce73 / 修复说明：`_buildMergedList` 增加 `catSize <= 0` 检查，空分类兜底到 index 0 / 关联 PR：—（直推 main）

**验证结论**（测试填写）
- 验证版本：commit 618ce73 / 验证结果：✅ 通过 / 验证人：QA / 关闭时间：2026-07-31
