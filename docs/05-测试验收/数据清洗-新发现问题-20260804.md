## 问题 1：图片说明（图片已去，图说留存）

**截图 1（沃尔玛购物卡新闻，5/24）**：

正文片段（原 HTML 抓取后去标签）：
```
黄先生介绍，因个人需求，2024年10月，他在沃尔玛厦门SM分店购买了35张面值1000元的购物卡……

**购卡凭证（央广网发 受访者供图）**

今年5月，黄先生持部分卡片到沃尔玛消费时，被告知有6张卡"失效"了……
```

**问题**：「购卡凭证（央广网发 受访者供图）」是图片说明，原文该位置有一张图（购卡凭证照片），我们抓正文时去掉了图片，但图片说明文字残留。

**根因**：`extractParagraphs` / `cleanNewsContent` 不识别图说模式（"X图"、"图源X"、"XX供图"、"受访者供图"、"央广网发"等），导致图说被当正文保留。

**修复方向（给 FS）**：
- 识别「图说模式」特征：`X X 发`/`受访者供图`/`图源`/`来源：`+图片说明性短语，`removeNoiseLines` 增加规则
- 建议规则（草案，需 FS 验证）：
  - `/[（(]?\s*(受访者供图|央广网发|新华社发|图源|图片来源|视觉中国|IC\s*photo)\s*[）)]?/i`
  - 单独成段且含「图」「摄」「供」+「图/发/摄」类词的短行
  - 行内括号包裹的图说 → `removeInlineBracketedMeta` 扩展

## 问题 2：广告/分享引导（追加新模式）

**截图 2（无人机新闻，6/24）**：
```
……成为多军种目标获取、态势感知、火力打击支撑的关键节点。

广告声明：文内含有的对外跳转链接（包括不限于超链接、二维码、口令等形式），
用于传递更多信息，节省甄选时间，结果仅供参考，IT之家所有文章均包含本声明。
```
→ IT之家网站固定「广告声明」模板。**已建单 V5-FS-02**（`/^(广告声明)[：:]/`）。

**截图 3（车扫老人新闻，15/24 上半）**：
```
……所幸车速较慢，未造成事故。

用微信扫描二维码  分享至好友和朋友[圈]

车灯扫过地库通道坚了一排老人！三伏天，户外酷暑难耐……
```

**问题**：「用微信扫描二维码  分享至好友和朋友圈」—— **「扫一扫分享」类引导**。已存在的 `removeNoiseLines` 规则：
- `/^(扫码|长按|点击|打开|分享)[\s\S]{0,30}(朋友圈|微信|群|好友|分享)/i` —— 命中"扫码...朋友圈"类
- 但当前文本是「用微信扫描二维码」+「分享至好友和朋友圈」**两行**，第一行未匹配（没有"扫码"开头，是"用微信"）

**修复方向**：
- 增强规则：`/用微信(扫描|扫一扫)?二维码|扫一扫.*分享|分享.*好友.*圈/`
- 合并"扫二维码"和"分享至"为同一噪音组

## 问题 3：新闻末尾串入其他新闻（最严重）

**截图 4（车扫老人新闻，15/24 下半）**：

该新闻在「车扫老人」主题下，末尾突然出现完全无关的另外两篇新闻内容：

```
[前段：车扫老人新闻]

王女士住在宁波慈溪中凯华庭小区。她说电动自行车要去充电需要经过小区地库，
前几天她载着女儿经过这里时，因为地面湿滑，导致摔倒受伤。

北京丰台区世华水岸小区C区地库自8月起持续出现大量积水，严重影响了居民的生活。
尽管物业安排人员不间断扫水，但积水问题仍未得到缓解……
```

**问题**：
- 同一篇详情页，混入 2 篇完全无关的新闻（电动车充电摔倒 + 地库积水）
- 都属于「小区地库」类，是 IT之家或同源网站的「延伸阅读」「相关推荐」
- 这些内容应该全部在「推荐阅读」模块，而不是混入正文

**根因**：
- 网页抓取时，`extractContentFromHtml` 找到正文容器后提取所有 `<p>`，但容器可能包含正文 + 延伸阅读两段
- 清洗规则只删"推荐阅读[：:]"开头行，但这些新闻段落**没有"推荐阅读"标签**，直接是 `<p> 地点 + 主题` 段落
- 启发式识别困难：需要识别"主题切换"（如"车扫老人"突然出现"王女士住在..."，是新地点+新人物+新事件）

**修复方向**：
- 方案 A（容器边界）：更严格的容器选择，限定在 `paragraph`/`article-content` 等核心容器，不扩展到页脚
- 方案 B（启发式）：识别"主题切换信号"——同一段落出现全新人物名+全新地点，且与前文无指代关系
- 方案 C（结构标记）：聚合内容接口（juhe）通常不会混入；问题主要在网页抓取。**优先检查 IT之家网页结构**，找到正文与延伸阅读的边界 DOM 节点

**建议优先方案 A**：在 `extractContentFromHtml` 阶段就严格限制容器范围，避免噪声段落进入清洗流水线。
