## 四、PM 口径裁定（2026-08-05）

**问题**：PRD F-07 原措辞「云端已删移除」与 F-06（离线收藏云端失败 → 本地保留 + 待同步角标）存在逻辑张力——若云端缺失即从本地移除，则离线收藏条目会全部消失，与 F-06 验收冲突。

**裁定**：
1. **离线未上云条目**（本地有、云端无、队列有该条收藏操作）→ 保留 + 标「☁️ 待同步」角标（F-06/UI-13）
2. **云端已删条目**（本地有、云端无、队列无该条，即已同步过但云端不再存在）→ 本地**保留展示**、不标角标（本地收藏是用户主动资产，不应默默消失；不标角标避免误导"未上云"）
3. PRD F-07 措辞已同步修订（`docs/02-产品设计/PRD-下迭代-浏览记录与数据保留策略.md` §12.2），实现与标准现已一致，**无需代码改动**。
