## 一、测试用例

### 🔴 P1-01：详情页分享按钮 → 调起转发面板

| 项 | 内容 |
|----|------|
| **前置条件** | 进入详情页 |
| **测试步骤** | 1. 点击底部操作栏 ↗ 分享按钮 |
| **期望结果** | 调起微信原生分享面板；可发送给朋友 |
| **验证点** | `onShareAppMessage` 触发 |

### 🔴 P1-02：转发卡片标题截断 ≤30 中文字符

| 项 | 内容 |
|----|------|
| **前置条件** | 当前新闻标题 >30 中文字符 |
| **测试步骤** | 1. 点击分享<br>2. 检查转发卡片标题 |
| **期望结果** | 标题截断为 ≤30 字符 + "…"，格式如「一页 | xxx…」 |
| **验证点** | 截断逻辑正确；不截断到半个字符 |

### 🟢 P2-01：分享标题前缀截断边界 — 前缀不被截掉（口径审查偏差 #3 补充）

| 项 | 内容 |
|----|------|
| **前置条件** | 构造标题长度边界场景 |
| **测试步骤** | 1. 标题恰好 26 字（"一页 | "4字 + 26字 = 30字，不触发截断）<br>2. 标题 27 字（"一页 | "4字 + 27字 = 31字，触发截断）<br>3. 标题 29 字（"一页 | "4字 + 29字 = 33字，截断到 29 chars）<br>4. 逐条点击分享，检查转发卡片标题 |
| **期望结果** | ① 26 字标题：显示完整「一页 | 完整标题」，共 30 字<br>② 27~29 字标题：显示「一页 | 标题前25字…」，前缀「一页 | 」始终完整<br>③ 任何情况下前缀「一页 | 」不被截断或残缺 |
| **验证点** | `Array.from(title)` 按 codepoint 截断；前缀 4 个字符始终在结果开头；无 `一页` 或 `一页` 被切半的情况 |
