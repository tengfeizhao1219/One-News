## 一、Bug1：滑到某条突然卡死，滑两条又恢复

### 根因
`pages/home/touch.wxs` 的 `handleTouchEnd` 此前在 `ownerInstance.callMethod('onWxsTouchEnd', ...)` **之后**才重置 `touchState.isDragging = false`。
一旦 JS 回调 `onWxsTouchEnd` 内部抛错（任何未捕获异常），重置代码不会执行，`isDragging` 永久卡在 `true`：
卡片停在拖拽偏移位、且禁用 transition —— 表现为"滑到某条突然滑不动，往上滑两条再往下滑又好了"。

### 修复（全局最优 / 举一反三）
1. **WXS 手势层异常安全（先重置再回调）**：`handleTouchStart / Move / End` 三个 handler 中，把 `touchState.isDragging=false` 等状态重置**移到 `callMethod` 之前**无条件执行。
   ⚠ **关键约束**：WXS 仅支持 ES5 子集，**禁止 `try/catch` 等语法**，一旦使用整模块编译失败（这正是 191ba57 推送后“侧边栏打不开 + 新闻不能滑动”的根因）。因此手势层的异常安全只能靠**「先无条件重置、再回调」的顺序**保证——即便 JS 回调抛错，WXS 手势状态也已提前归位、永不楔死；真正的异常隔离由 JS 层 `onWxsTouchEnd` 内的 `try/catch` 完成。
2. **JS 层动画兜底**：`_animateSwipeNext / _animateSwipePrev / _animateBounceBack` 的 `setTimeout` 回调统一用 `try/catch/finally`，无论成败都重置 `this._isAnimating = false`，杜绝动画锁死。
3. **渲染加固**：`renderCards` / `buildCard` 对空列表、空 item、非数组输入做 null-safe 处理，单条坏数据不再让整页渲染崩溃。

### 架构不变量（已被 v6 测试锁死）
- `handleTouchEnd` 必须先重置 `isDragging` 再回调；WXS 为纯 ES5、**绝不**含 `try/catch`（否则整模块编译失败）；三个 handler 依靠「先重置再回调」保证异常安全。
- `onWxsTouchEnd` 整体被 `try/catch` 包裹；动画 `setTimeout` 用 `finally` 重置 `_isAnimating`。

## 二、Bug2：列表末/首条继续滑动无反馈

### 需求
到达当前分类列表**最后一条**仍上滑 → 触发**加载更多**；到达**第一条**仍下滑 → 触发**刷新**；全程给出 toast 反馈，避免"滑不动却没提示"的挫败感。

### 修复
1. **边界路由**（`home.js` → `onWxsTouchEnd`）：
   - 上滑越过末条 → `loadMoreNews()`（请求 `pageNum = currentPage+1`，拼接新数据，toast「加载更多…/已加载 N 条」）
   - 下滑越过首条 → `refreshCurrentCategory()`（重新拉取第 1 页，toast「刷新中…」）
   - 未达阈值 → 回弹。
2. **Mock 模式可演示**：`mock/simulator.js` 的 `simulateGetNewsList` 在请求页码**超出原始数据范围**时，循环克隆生成带「第 N 页·延伸阅读」标记的"新"新闻，使 `hasMore` 恒为 `true`，从而 Mock 下也能持续"获取新的其他新闻"。
3. **举一反三**：所有改变 `newsList` 的入口（`loadNews` / `loadMoreNews` / `refreshCurrentCategory` / `closePanel` / `onPanelItemTap`）均重置 `currentPage`，避免切换分类后 `loadMore` 用错页码。

### 架构不变量（已被 v6 测试锁死）
- `onWxsTouchEnd` 引用 `loadMoreNews` 与 `refreshCurrentCategory`；`loadMoreNews` / `refreshCurrentCategory` 各自唯一定义（无重复）。
- 切换 / 加载分类均重置 `currentPage`（≥5 处）。
- simulator 超出原始数据返回生成的延伸内容（`hasMore=true`、标题带标记、`id` 唯一），不存分类 / empty 场景仍返回空。
