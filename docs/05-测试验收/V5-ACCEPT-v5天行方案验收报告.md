## 二、本地已执行项结果

### 2.1 清洗质量验证（对应 TC-C01~C05、TC-E06）

本地加载 `getNewsDetail/utils/newsCleaner.js` 构造真实噪音样本验证：

| 用例 | 场景 | 结果 |
|------|------|:---:|
| TC-C01 | HTML 标签 / 实体（`<div>`、`&nbsp;`、`&amp;`） | ✅ 清除 + 解码 |
| TC-C02 | 独立行分享引导（"扫码关注微信公众号"、"分享到朋友圈"） | ✅ 清除 |
| TC-C03 | 推荐阅读区块（"推荐阅读：1.… 2.…"、"相关新闻"） | ✅ 清除 |
| TC-C04 | 独立行版权/编辑（"责任编辑：张三"、"版权声明："） | ✅ 清除 |
| TC-C05 | 段落结构（连续 5 空行压缩） | ✅ 压缩 |
| TC-E06 | 清洗后过短检测（`validateCleanedContent`） | ✅ 过短拒绝、正常通过 |
| — | **综合样本**（HTML + 扫码 + 括号编辑 + 推荐阅读混合） | 🟡 **发现缺口**：`（责任编辑：王五）` **括号包裹形态未被清除** |

> **缺口详情**：`removeNoiseLines` 按行匹配 `/^(责任编辑|编辑|作者)[：:]/`（锚定行首），但真实新闻（新浪/网易风格）常写作 **`（责任编辑：王五）`**——前有括号不匹配。建议全栈开发补规则：`/^[（(]?(责任编辑|编辑|作者)[：:]/` 或增加括号形态独立规则。
>
> **处置**：反馈全栈开发（见 TASK_BOARD 广播），清洗规则优化后复验。

3. **finance/entertainment 冗余产出**：天行映射保留但前端无 tab，不阻塞，随 TL-B2 清理。
