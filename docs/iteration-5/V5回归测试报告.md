# V5 回归测试报告（侧边栏卡死 + 乱码 全局修复）

> 测试日期：2026-07-28
> 测试人：WorkBuddy（架构级回归）
> 变更范围：首页触摸架构重构 + 源文件编码统一（GBK→UTF-8）
> 测试模式：Mock / 单元测试 / 架构不变量静态测试

## 一、问题根因（与表象的区分）

| 表象（用户看到） | 真实根因 | 之前错误修复（打补丁） |
|------------------|----------|------------------------|
| 首页中文乱码、且越改越乱 | 4 个源文件被以 **GBK** 编码保存，微信工具要求 UTF-8 | 把 emoji 换成 ASCII 字母（R/S/^/<-）——掩盖症状，反而更糟 |
| 打开侧边栏后整个页面卡死、列表无法滚动 | ① WXS 触摸处理绑在**根视图 `.page`**（全屏拦截）② 面板的 `catchtouchmove="preventMove"` 调 `preventDefault` **禁掉了 scroll-view 原生滚动** ③ `.card-stage.hidden` 用 `opacity:0` 未真正移除 | 在面板上继续加 `catchtouchmove`，卡死依旧 |

## 二、最优方案（架构级，一次到位）

1. **触摸手势收窄**：`bindtouchstart/move/end` 从根视图 `.page` 移到实际交互区 `.card-stage`；面板打开时卡片层 `display:none` 彻底移除，两者互不干扰。
2. **删除 catchtouchmove hack**：移除 `.slide-panel` / `.panel-overlay` 上的 `catchtouchmove="preventMove"`，让面板内 scroll-view 恢复原生滚动。
3. **编码统一**：`home.wxml / home.wxss / touch.wxs / utils/request.js` 四个 GBK 文件转码为 UTF-8（全项目扫描确认其余 99 个文件本就 UTF-8）。
4. **清理死代码**：删除从未接线的 `panelOpen`/`setPanelOpen`（touch.wxs）与 `preventMove`（home.js）。

## 三、举一反三扫描结果

- 全局 grep 确认 `catchtouchmove` / 根级 `bindtouchmove` / `panelOpen` / `preventMove` 反模式**仅存在于首页**，未扩散到其他页面。
- 编码扫描覆盖全部 `.js/.wxml/.wxss/.wxs/.json/.md`，确认仅 4 个文件异常，已全部修复。

## 五、新增锁定用例（防止同类问题复发）

`test/v5-regression-touch-architecture.js` 以"架构不变量"方式锁定以下不变量：
- 根视图 `.page` 不得绑定触摸手势
- 触摸手势必须绑在 `.card-stage`
- 首页不得出现 `catchtouchmove`
- `.card-stage.hidden` 必须用 `display:none`
- WXS / JS 不得残留 `panelOpen`/`setPanelOpen`/`preventMove` 死代码
- 关键源文件必须严格 UTF-8
