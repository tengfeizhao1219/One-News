# 元信息行统一设计规范（v7.2）

> **状态**：✅ 已确认，待前端开发实现
> **设计**：UI Designer ｜ **日期**：2026-08-01
> **适用范围**：首页卡片页（已落地）+ 详情页（待调整）

---

## 1. 背景与目标

用户反馈两个页面的元信息行（分类标签 + 来源 + 时间）视觉权重偏大，与标题、正文的层次不分明；且两个页面字号不一致（卡片页 20rpx / 详情页 22rpx），需要统一。

**目标**：
- 统一卡片页与详情页的元信息视觉规格
- 拉开「标题 → 元信息 → 正文」的视觉层次
- **保留分类标签底色**，作为用户识别新闻分类的唯一视觉提示

---

## 2. 设计 Token（实现依据）

| 元素 | 字号 | 浅色模式 | 暗色模式 | 间距 |
|:--|:--|:--|:--|:--|
| 分类标签（胶囊） | `18rpx` | 底 `--tag-bg #EEECE8` / 字 `--tag-text #7A7A7A` | 底 `#1C1C1E` / 字 `#999999` | padding `3rpx 14rpx`，圆角 `18rpx` |
| 来源 / 时间 文字 | `20rpx` | `--text-secondary #A0A0A0` | `#999999` | 元素间距 `gap: 12rpx` |
| 标题 → 元信息 | — | — | — | `20rpx`（卡片页已落，详情页待改） |
| 元信息 → 下文 | — | — | — | 卡片页 `28rpx` / 详情页 分隔线后 `20rpx` |

> 所有颜色走 CSS 变量（`--tag-bg` / `--tag-text` / `--text-secondary`），**不写死**，确保明暗模式自动适配。

## 4. 分类标签底色规范（重点保留）

- **形状**：胶囊形 `border-radius: 18rpx` + 浅灰底
- **作用**：用户识别新闻分类的**唯一视觉提示**，不可去掉底色改为纯文字
- **色值**：
  - 浅色：`background-color: var(--tag-bg)` → `#EEECE8`；文字 `var(--tag-text)` → `#7A7A7A`
  - 暗色：`background-color: #1C1C1E`；文字 `#999999`（见 `app.wxss` 暗色覆盖）
- **字号**：统一 `18rpx`（已在上轮提交中从 22rpx 缩小）
- **padding**：`3rpx 14rpx`
