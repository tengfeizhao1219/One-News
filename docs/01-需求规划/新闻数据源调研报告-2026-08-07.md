# 新闻数据源调研报告 · 天行/聚合之外的高质量国内可访问源

> **调研人**：产品经理（PM）｜**日期**：2026-08-07
> **目的**：为「一页 One-News」补充天行（tianapi）、聚合（juhe）之外的高质量新闻源，不区分海内外，**前提是国内可直接访问**。
> **方法**：网络调研 + 沙箱环境（国内腾讯云出口）**逐源实测可达性 + 内容采样**。

---

## 一、结论速览（TL;DR）

| 结论 | 说明 |
|------|------|
| ✅ **最佳补充源 = 官方媒体 RSS** | 中新网（18+ 分类）、人民网、新浪、IT之家、36氪等**稳定、免费、无需 Key、国内直连**，实测 200 |
| ✅ **RSSHub 自部署是万能扩展** | 澎湃/界面/财新/凤凰等无官方 RSS 的媒体，可用自建 RSSHub 生成订阅源 |
| ⚠️ **海外高质量中文源（纽约时报/BBC/路透/FT）国内不可直连** | 实测全部超时，**不可作为云函数数据源**（除非走代理，小程序云函数不现实） |
| ⚠️ **聚合/天行仍是唯一可用聚合 API** | 国内其余新闻 API（apiopen/腾讯 pacaio 等）实测失效/需完整参数 |
| 💡 **推荐路线**：智谱 web_search（AI 主力）＋ 官方 RSS（补充权威内容）＋ 天行/聚合（降级兜底） | 与现有降级链兼容，成本近零 |

---

## 二、现有数据源架构（背景）

当前 `refreshNews` 降级链（config.js v5.1）：

```
智谱 GLM-4-Flash web_search（AI 主力，联网搜索）
  → DeepSeek（降级兜底）
  → Qwen 通义千问（二级兜底）
  → 天行 tianapi（API 降级）
  → 聚合 juhe（API 降级）
```

> 天行/聚合是**传统聚合 API**（标题列表 + 分类），智谱 web_search 是 **AI 联网搜索**（已按需生成分类内容）。本调研聚焦「聚合 API / RSS 结构化源」的补充选项。

## 五、国内新闻 API 平台 —— 实测结论

| 平台 | 类型 | 实测 | 结论 |
|------|------|:--:|------|
| **天行 tianapi**（现有） | 聚合 API | ✅ 200 | 保留（降级层） |
| **聚合 juhe**（现有） | 聚合 API | ✅ 200 | 保留（降级层） |
| apiopen（网易新闻） | 免费 API | ⚠️ 已失效（返回前端页） | 不可用 |
| 腾讯 pacaio | 免费接口 | ⚠️ 返回空（需完整 token 参数） | 不可用 |
| alapi | 免费 API | ⚠️ 接口地址 404 | 需找对路由 |
| newsapi.org | 海外 API | ❌ 000 | 不可用 |
| RollToolsApi | 免费 API | ⚠️ 需实测（CSDN 有教程） | 待验证 |

> **结论**：国内聚合新闻 API 领域，**天行/聚合仍是仅有的稳定可用项**。补充高质量内容的最佳路径是 **RSS 直采**，而非再找聚合 API。

## 六、推荐落地建议

### 方案 A（推荐）：官方 RSS 直采，零成本零依赖

```
refreshNews 新增 RSS 数据源（可选其一或多个）：
  中新网（scroll-news 即时 + world/society/finance 分类）
  + 人民网 politics（时政补充）
  + IT之家 / 36氪（科技垂直，替代天行 sicprobe）
  解析：标准 RSS 2.0 XML → 与现有清洗链路（newsCleaner）对接
```

- **优点**：权威、免费、无需 Key、无调用限制、国内直连稳定
- **改动量**：新增一个 `sources/rss.js`（RSS 解析 ~80 行），接入降级链第 5 层
- **风险**：RSS 无正文（仅标题+摘要+链接），正文仍需走 `contentFetcher` 抓取（现有能力）

### 方案 B：自部署 RSSHub（扩展性强，需一台国内服务器）

- 可覆盖澎湃/界面/凤凰/财新（非订阅）/微博热搜/微信公众号等**数百个路由**
- **缺点**：需要一台国内服务器 + Docker 常驻（本项目云函数环境不适合跑常驻服务），维护成本
- **建议**：暂缓，等有服务器资源再考虑

### 方案 C：维持现状 + 智谱 AI 搜索强化

- 现有智谱 web_search 已能按需生成高质量内容，RSS 可作为**校验/补充源**而非替代

## 七、风险与合规提醒

| 风险 | 说明 |
|------|------|
| **版权** | 官方 RSS 允许聚合展示标题+摘要+链接（合理使用），但**不建议全文转载**；正文请跳转原文链接（本项目已移除原文链接入口，需 owner 重新评估） |
| **正文抓取** | RSS 条目正文仍需抓 sourceUrl（现有 contentFetcher），注意各站点反爬差异 |
| **内容安全** | 新增源仍需走现有 `securityCheck` 审核（微信内容安全 API），个人主体小程序受限（现有降级放行逻辑） |
| **海外源合规** | 纽约时报/BBC 等虽质量高，但国内不可直连；若未来走代理需评估合规风险 |
