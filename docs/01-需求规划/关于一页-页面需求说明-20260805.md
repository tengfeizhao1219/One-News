## 一、背景与目标

- **现状**：首页 ⚙ dock 菜单共 4 项（浏览记录 / 我的收藏 / 设置 / **扩展位**）。「扩展位」长期占位，点击仅提示「敬请期待」（`home.js` → `wx.showToast`）。
- **目标**：将 dock 第 4 项由「扩展位」改为「**关于一页**」，落地一个**产品理念与初衷介绍页**，向读者讲清楚「一页」是什么、为什么做、坚持什么。
- **性质**：纯静态内容页，无数据请求、无云函数依赖，开发量小（参照 `pages/settings` 独立页模式）。

## 二、入口改造

| 项 | 现状 | 改为 |
|----|------|------|
| dock 第 4 项文字 | 扩展位 | **关于一页** |
| dock 排列顺序 | 浏览记录 → 我的收藏 → 设置 → 扩展位 | **浏览记录 → 我的收藏 → 关于一页 → 设置**（设置挪至最末） |

## 三、页面内容结构（文案稿）

> 基调：**真诚、克制、有态度**。像朋友介绍自己做的产品，平实叙述，不浮夸、不用「最强大/领先」等词，契合产品「极简」气质。

### 1. 品牌区（顶部）
```
一页
极简沉浸式新闻阅读 · 打开即读 · 零干扰
```

### 2. 我们的初衷
> 新闻本该是「知道今天发生了什么」。
>
> 可打开任何一个新闻 App，迎接你的往往是：信息流、弹窗、算法推荐、无限下拉、视频、广告……
> 你只是想看几条新闻，却像走进了一个喧闹的集市。
>
> 所以我们做了「一页」——一个简单到近乎固执的新闻阅读器：
> **打开就是今天值得读的一条，上下滑动逐页翻看。没有信息流，没有「猜你喜欢」，没有无限刷。**

### 3. 我们的理念（五条设计原则）
| # | 原则 | 说明 |
|---|------|------|
| 1 | **一眼即得** | 打开即读，不做信息流，不设推荐算法 |
| 2 | **我的选择** | 五大分类自己选（推荐 / 科技 / 国际 / 体育 / 生活），不被算法喂养 |
| 3 | **三分钟读完** | AI 摘要提炼要点，正文去噪（自动过滤广告声明、图片说明、扫码引导等噪音） |
| 4 | **昼夜皆宜** | 暖灰纸感白天护眼，暗色模式夜间不刺眼，字号四档可调 |
| 5 | **简单到极致** | 全 App 层级不超过两层，核心路径不超过三步 |

### 4. 我们坚持的事（产品特色）
- **纯文字阅读**：无图、无视频，把注意力还给文字本身；
- **AI 为你提炼**：智谱 GLM-4-Flash + DeepSeek 双引擎生成摘要，三分钟读完一条；
- **永不空白**：多源聚合 + 五层降级链，任何时刻打开都有内容；
- **尊重你的注意力**：不打扰、无广告、不推送。

## 四、交互与视觉规范

- **页面模式**：独立全屏页，自定义导航（‹ 返回 + 标题「关于一页」），参照 `pages/settings`
- **视觉**：暖灰纸感背景 `--bg-page`、卡片 `--bg-card`、正文 `--text-body`、次级文字 `--text-secondary`、分隔线 `--divider`，全部走 theme.json token
- **适配**：暗色模式（token 自动切换）、字号缩放（`data-font-scale` / `--font-scale`）
- **滚动**：`scroll-view` 纵向滚动
- 动效：无强制要求，可选轻微 fade-in

## 六、验收标准

1. dock 菜单第 4 项显示「关于一页」，点击进入关于页，返回首页正常；
2. 页面在浅色 / 深色模式下均正常（token 生效）；
3. 字号四档缩放生效（跟随全局设置）；
4. 邮箱 / 微信点击可复制（有 toast 反馈）；
5. dock 排列为：浏览记录 → 我的收藏 → 关于一页 → 设置（设置已在最末）；
6. 无 console 报错；首页 dock / 侧边栏 / 卡片流回归不受影响。
