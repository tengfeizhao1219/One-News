## 一、需求一句话

设置页「意见反馈」落地为**留言板页面**：用户可留言/回复（多级嵌套楼中楼）、作者（owner，openid 白名单）可删除/筛选、提交自动合规审核（关键词黑名单 + AI），违规跳转「文明留言公约」页。

## 三、FE 交接要点（RQ-22-FE）

### 3.1 页面与入口

| 项 | 说明 |

### 3.2 页面结构（对齐设计文档 §2）

```
feedback（留言板主页面）
├── nav-bar：主页（左，44rpx icon）+ 标题「意见反馈」（中）+ 筛选「筛选 ▾」（右，仅作者 isAuthor 可见）
├── 管理计数条（仅作者）：「共 N 条」（Q4 ✅ 已确认）
├── 留言列表（scroll-view · 倒序）
│   └── 留言卡片（card）
│       ├── 头：昵称（微信用户+随机 / 一页君+作者角标）+ 相对时间
│       ├── 内容：纯文本（多行 · 不限字数，Q1 ✅ 已确认）
│       ├── 右下角（仅作者）：删除「🗑」按钮
│       └── 回复区（展开）
│           ├── 嵌套回复项（缩进 16rpx + 浅色底）：昵称（作者角标）+ 时间 + 内容
│           └── 回复输入框（点「回复」展开）
└── 底部固定输入区
    ├── 文本框（自适应高度 · min-height 72rpx · max-height 200rpx）
    └── 发送按钮（主题色 · disabled 态）

rules（文明留言公约页）
├── nav-bar：返回（左）+ 标题「文明留言公约」
├── 违规提示卡（进入即展示「留言未通过审核」+ 违规原因）
├── 公约文案（编号列表）
└── 返回留言板按钮
```

### 3.4 交互要点（对齐设计文档 §4）

| 场景 | 交互 |
|------|------|
| 提交留言 | 30s 限频校验（未到 → 输入区上方倒计时「请 N 秒后再试」）→ create → 成功清空 + 列表刷新置顶 + toast |
| 违规拦截 | create 返回 BLOCKED → 跳转 rules 页（携带违规原因），不入库 |
| 回复 | 点「回复」展开输入框 → 发送 → 追加到该留言回复区（正序） |
| 嵌套展示 | 同层缩进 16rpx，最深 4 级后收平 |
| 作者删除 | 卡片右下角「🗑」（仅 isAuthor 可见）→ 确认弹窗 → delete 软删除 → 普通用户不可见、作者可查看（Q3 待确认） |
| 作者筛选 | nav-bar 右侧「筛选 ▾」下拉 → 即时过滤 |
| 作者识别 | 仅根据云函数返回 `isAuthor` 渲染，前端不可伪造 |

### 3.5 状态设计（对齐设计文档 §5）

加载中（骨架 3 条）/ 空态（「还没有留言，来说两句吧」）/ 输入框聚焦上移 / 发送 disabled（空内容/冷却中）/ 删除确认 wx.showModal / 违规跳转 rules 页。

### 3.6 FE 验收自测（AC-01~12 · 详见设计文档 §7）

AC-01 入口 navigateTo（不再 openFeedback）· AC-02 列表倒序+昵称角标+时间 · AC-03 提交成功清空+刷新+toast · AC-04 30s 限频倒计时 · AC-05 楼中楼嵌套最深 4 级 · AC-06 作者昵称「一页君」+「作者」角标 · AC-07 作者右下角删除+软删除 · AC-08 作者筛选下拉 3 维度 · AC-09 违规跳公约页不入库 · AC-10 公约页 + 深浅色 token 无硬编码 · AC-11 不依赖微信 msgSecCheck · AC-12 回归 v5/v6/v7/v10/v11/v13 全绿

## 四、FS 交接要点（RQ-22-FS）

### 4.1 云函数

| 函数 | 入参 | 出参 | 说明 |
|------|------|------|------|
| `feedback/create` | `{content, parentId?}` | `{code, data}`；`BLOCKED` 时返回违规标记 | 留言 + 回复复用（parentId 区分）；黑名单 + AI 审核 |
| `feedback/list` | `{pageNum, pageSize, filter?}` | `{code, data:{list,total}}` | 每记录标记 `isAuthor` |
| `feedback/delete` | `{id}` | `{code}` | 云函数内**再次校验 isAuthor** |

### 4.2 云端集合 `feedback`

| 字段 | 类型 | 说明 |
|------|------|------|
| `_id` | string | 自动 |
| `parentId` | string | 父留言 ID；null = 顶层，非空 = 回复（支持嵌套） |
| `rootId` | string | 顶层留言 ID（楼中楼归属） |
| `content` | string | 纯文本（不限字数，Q1 ✅ 已确认） |
| `openid` | string | 提交者 openid（云函数写入） |
| `nickname` | string | 展示昵称（微信用户 + 随机 4 位 / 作者「一页君」） |
| `isAuthor` | bool | 是否作者 |
| `status` | string | `visible` / `deleted`（软删除） |
| `createdAt` / `updatedAt` | number | 时间戳（毫秒） |

查询：列表 = `where(rootId=null, status='visible')` 按 createdAt 倒序；回复 = `where(rootId=留言id, status='visible')` 正序。

### 4.3 作者识别（PRD §4.3.2 · 已确认）

- 环境变量 `AUTHOR_OPENID`（云开发控制台 → 云函数 feedback/* → 环境变量）
- 每次请求 `cloud.getWXContext().OPENID` → `isAuthor = (openid === AUTHOR_OPENID)`
- `feedback/list` 对每条记录标记 `isAuthor`；`feedback/delete` 内再次校验
- 单作者（owner）；后续扩展 `AUTHOR_OPENIDS` 数组

### 4.4 内容合规（PRD §4.4 · 已确认）

| 层 | 实现 |
|----|------|
| 关键词黑名单 | 违规词库（涉黄/涉政/暴力/辱骂/广告等）云函数内置常量（初版） |
| AI 校验 | 智谱 GLM-4-Flash 文本审核（复用 `ZHIPU_API_KEY`），失败降级 DeepSeek |
| 降级策略 | **AI 超时/失败 → 仅黑名单兜底放行**（owner 已确认） |
| 违规结果 | `BLOCKED` → 前端跳「文明留言公约」页（返回违规标记供展示原因） |

### 4.5 昵称生成（PRD §4.3.4）

首次留言生成「微信用户 + 随机 4 位」（如「微信用户 8a3f」）存入留言记录，同 openid 复用；作者昵称固定「一页君」。
