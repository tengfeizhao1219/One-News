## 三、部署步骤（解除阻塞后的操作）

```
第1步：注册百炼 API Key
  → https://bailian.aliyun.com → 开通 DeepSeek-V3 模型 → 获取 API Key

第2步：部署云函数
  → 微信开发者工具 → 云开发 → 云函数 → 上传部署
  → 需部署：getNewsList, getNewsDetail, searchNews, refreshNews

第3步：配置环境变量
  → CloudBase 控制台 → 云函数 → refreshNews → 环境变量
  → 添加：DASHSCOPE_API_KEY = <你的百炼Key>

第4步：创建数据库集合
  → CloudBase 控制台 → 数据库 → 新建集合 → news_cache

第5步：端到端冒烟测试
  → 打开小程序首页 → 验证新闻列表加载
  → 点击新闻 → 验证详情页
  → 搜索关键词 → 验证搜索功能
  → 手动刷新 → 验证 refreshNews 调用

第6步：发布上线
  → 微信开发者工具 → 上传 → 提交审核
```
