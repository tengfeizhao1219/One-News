## 设计方向指引

基于三个画像的共同需求，NewsBrief 的设计原则：

1. **"一眼即得"**：打开首页，头条Banner占据视觉焦点，3秒内抓住注意力
2. **"我的选择"**：分类Tab清晰可见，用户主动选择想看的内容
3. **"三分钟读完"**：每条新闻内容控制在3-5段，正文不超过500字
4. **"昼夜皆宜"**：暗色模式跟随系统自动切换，字体大小一键调节
5. **"简单到极致"**：页面层级不超过2层，核心路径不超过3步
