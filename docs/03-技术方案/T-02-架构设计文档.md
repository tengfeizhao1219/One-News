## 3. 核心模块设计

### 3.1 跨分类阅读引擎 (`detail/reading-engine.js`) 🆕

**职责**：管理详情页跨分类连续阅读的状态机，解耦翻页逻辑与 UI 渲染。

```
状态机：
  IDLE ──→ LOADING ──→ READY ──→ CROSSING ──→ READY
                            │                    │
                            ├─→ BOUNDARY_START   │ (第一条)
                            └─→ BOUNDARY_END     │ (最后一条)
```

**数据结构**：
```js
// globalData.detailContext (扩展现有结构)
{
  mergedList: [           // 全分类合并有序列表
    { id, category, categoryName, title, summary, picUrl, source, publishTime },
    // ... 按 constants.CATEGORIES 顺序，每分类首 pageSize 条
  ],
  cursor: 0,              // 当前在 mergedList 中的索引
  categoryIndex: 0,       // 当前所在分类的起始偏移 (用于进度计算)
  totalPerCategory: {},   // { top: 10, tech: 10, ... } 各分类条数
  preloadWindow: 2,       // ±2 条预取窗口
}

// _detailReturnState (返回定位扩展)
{
  category: 'tech',
  categoryIndex: 3,       // 在 mergedList 中的绝对索引
  newsId: 'xxx'
}
```

**关键行为**：
| 操作 | 行为 |
|------|------|
| 进入详情 | 并行 `getNewsList(cat,1,10)` × 5 → 合并 mergedList → 定位到目标 newsId |
| 上滑(下一条) | `cursor++`；若到本分类末尾 → 自动切下一分类首条 (CROSSING) |
| 下滑(上一条) | `cursor--`；若到本分类开头 → BOUNDARY_START Toast |
| 末条上滑 | BOUNDARY_END Toast "已经是最后一条 · ← 返回首页" |
| 追加加载 | 当前分类 `hasMore=true` 时 `getNewsList(cat, page+1)` 追加到 mergedList |
| 预取 | cursor ±2 条预调 `getNewsDetail` 并缓存 |
| 弱网 | 停在当前 + Toast "网络开小差，下拉重试" (黄色 3s) |

**WXS 红线遵守**：
- `reading-engine.js` 在 JS 层管理状态，WXS `touch.wxs` 仅透传手势事件（`touchstart/touchend` 方向判定）。
- WXS 不感知 `mergedList`、分类上下文、跨分类逻辑。

### 3.2 内容安全审核模块 (`common/securityCheck.js`) 🆕

**职责**：refreshNews 入库前的内容合规校验。与 `validator.js` 互补。

```
refreshNews 流程（新增 ★）
  LLM 搜索 → validator(质量/来源) → ★ securityCheck(违规) → batchInsert
                                            │
                                       命中违规 → 拦截 + sync_logs + 告警
                                       API不可用 → 该批暂缓 + 告警 + 队列重试
```

**接口**：
```js
// common/securityCheck.js
module.exports = {
  /**
   * @param {Array} newsItems - 待审核新闻列表 (已过 validator)
   * @returns {Object} { passed: [], blocked: [], stats: { total, passed, blocked, apiError } }
   */
  checkBatch: async (newsItems) => { ... },

  /**
   * 单条文本审核
   * @returns {Object} { passed: boolean, hitType?: string, hitReason?: string }
   */
  checkText: async (content) => { ... },

  /**
   * 单条图片审核 (含 downloadFile → imgSecCheck)
   * @returns {Object} { passed: boolean, hitType?: string }
   */
  checkImage: async (picUrl) => { ... }
}
```

**限频策略**：
- 单次 refreshNews 最多 ~50 条，按 10 QPS 串行调用（≤ 5s）
- 超时 5s → 降级为保守策略：该批暂缓入库 + 告警
- 单次命中率 > 20% → ERROR 级日志
- API 连续 3 次不可用 → ERROR 级日志

**日志扩展** (`sync_logs`)：
```js
{
  // 原有字段...
  securityCheck: {
    passed: true,
    hitType: null,        // 'politics' | 'porn' | 'violence' | 'illegal'
    hitReason: null,      // API 返回原因
    checkedAt: '2026-07-30T...'
  }
}
```

### 3.3 统一本地存储 (`utils/localCache.js`) 🆕

**职责**：favorites / readHistory / offline 三者共用的本地存储封装。

**接口**：
```js
const localCache = {
  get(key)                      // wx.getStorageSync(key)
  set(key, value)               // wx.setStorageSync(key, value)
  remove(key)                   // wx.removeStorageSync(key)
  getWithTTL(key)               // 读取 + TTL 校验，超时返回 null
  setWithTTL(key, value, ttlMs) // 写入 + 过期时间戳
  lruPush(key, value, maxSize)  // LRU 追加，超出 maxSize 淘汰最早项
  lruList(key)                  // 返回 LRU 列表
  lruRemove(key, predicate)     // 按条件移除
}
```

**使用方**：
| 模块 | Key | 类型 | 上限 | TTL |
|------|-----|------|:---:|-----|
| 收藏 RQ-03 | `favorites` | LRU | 200 | 无 (持久) |
| 阅读历史 RQ-06 | `readHistory` | LRU | 200 | 无 (持久) |
| 离线缓存 RQ-05 | `offline_news_{id}` | TTL | — | 24h |
| 字体设置 RQ-04 | `fontScale` | 单值 | — | 无 (持久) |

### 3.4 字体面板组件 (`components/font-panel/`) 🆕

**D-04 决策**：底部半屏面板（非侧边栏），4 档单选即时生效。

```
font-panel 行为：
  open  → 从底部滑入半屏面板 (animation: slideUp 250ms)
  选择  → 即时应用 calc(Xrpx * var(--font-scale))
          → wx.setStorageSync('fontScale', value)
          → globalData.fontScale = value
          → 页面 onShow 同步
  close → 滑出 (无确认按钮，选即生效)
```

**CSS 变量体系** (扩展 `theme.json`)：
```css
:root {
  /* 现有颜色变量 */
  --bg-primary: #FFFFFF;
  --text-primary: #1A1A1A;
  /* ... */

  /* 🆕 字号变量 */
  --font-scale: 1;           /* 默认标准 */

  --font-scale-lg: 1.15;     /* 大 */
  --font-scale-xl: 1.3;      /* 特大 */
  --font-scale-xxl: 1.5;     /* 超大 */

```

**生效范围**：
- 首页卡片标题/摘要/元信息 → `calc(28rpx * var(--font-scale))`
- 详情正文 → `calc(32rpx * var(--font-scale))`
- 侧边栏列表文字 → `calc(28rpx * var(--font-scale))`

### 3.5 收藏功能

**D-04 决策**：本地优先，200 条 LRU，侧边栏「❤️ 收藏」Tab，底部毛玻璃操作栏。

```
收藏流程：
  详情页点 🤍 → favorite-btn: 🤍→❤️ heartBeat 300ms
              → localCache.lruPush('favorites', {id, title, category, categoryName, addedAt, openid: null}, 200)
              → detail.data.isFavorited = true

  详情页点 ❤️ → favorite-btn: ❤️→🤍
              → localCache.lruRemove('favorites', item => item.id === newsId)
              → detail.data.isFavorited = false

  进入详情时 → localCache.lruList('favorites').find(id) → 判定 isFavorited

  收藏列表   → 侧边栏「❤️ 收藏」Tab → localCache.lruList('favorites') → 时间倒序
              → 点击跳转 detail?id=xxx
              → 弱网可读 (本地数据)
```

**按钮颜色**：浅色 `#FF3B30` / 暗色 `#FF453A`（D-04 定案）

## 4. 数据流

### 4.1 列表数据流（无变更）
```
用户打开首页
  → home.onLoad → request.getNewsList(category, pageNum)
  → cloud.callFunction('getNewsList')
  → L1 天行 → L2 内存 → L3 云库 → L4 聚合 → L5 AI → 返回
  → home.setData → 渲染卡片
```

### 4.2 详情 + 跨分类阅读数据流 🆕
```
用户点击卡片
  → detail.onLoad({ id, category })
  → readingEngine.init(id, category)
  → 并行 getNewsList × 5 (各分类首 pageSize)
  → 合并为 mergedList，定位 cursor
  → 预取 cursor±2 条 getNewsDetail
  → 渲染当前卡片

用户上滑
  → readingEngine.next()
  → cursor++
  → 若跨分类 → CROSSING 状态 → 进度指示更新
  → 若末条   → BOUNDARY_END Toast
  → 若需追加 → getNewsList(cat, page+1) → 追加 mergedList
  → 渲染下一卡片 (复用 out-up 动画)
```

### 4.3 内容安全数据流 🆕
```
refreshNews 定时/手动触发
  → llmSearch 百炼搜索全分类
  → validator 质量校验 + 去重
  → ★ securityCheck.checkBatch(newsItems)
    → 逐条 msgSecCheck(content)
    → 有 picUrl → downloadFile → imgSecCheck
    → 命中违规 → 拦截 + 记 sync_logs + 告警
    → API 不可用 → 保守暂缓 + 告警
  → batchInsert 写入 news_cache (仅 passed 条目)
```

## 6. 关键开发红线（不变 + 新增）

| # | 红线 | 说明 |
|---|------|------|

## 7. 风险与缓解

| 风险 | 影响 | 概率 | 缓解措施 |
|------|------|:---:|------|
| 跨分类预拉 5 分类首页耗时 > 2s | 详情打开变慢 | 中 | 并行调用、骨架屏、先渲染当前条再异步补全 |
| 内容安全 API QPS 超限 | news_cache 空窗 | 中 | L3 过期后 L4/L5 接住；保守策略下告警不丢数据 |
| 收藏 200 条 storage 超 10MB | 收藏不可用 | 低 | 每条仅存索引 (~200B)，200 条 ≈ 40KB |
| Canvas 占位图首次生成慢 | 分享卡顿 | 低 | 缓存同 id 占位图；异步预生成 |
| 跨分类状态机复杂度 | 翻页 Bug | 中 | `reading-engine.js` 独立模块，单元测试覆盖状态转换 |
