# 阅读模式技术方案（详情页上下滑跨分类切换）

> **任务**：T-06 | **负责人**：技术负责人 | **状态**：✅ 技术方案就绪（待 阶段二设计稿定稿后落地）
> **依赖**：阶段二设计稿（UI/交互）；本方案为技术实现侧先行版

---

## 1. 目标

详情页在「阅读模式」下，支持**上下滑动**在新闻间切换（同分类内顺序浏览，到末尾自动跨分类延续），实现"沉浸式连读"。对应 CONTEXT 待办 #1（原 T-01）。

## 2. 技术方案

### 2.1 页面结构
- 详情页 `pages/detail/` 改造为**纵向可滑动的新闻容器**：用 `scroll-view`（纵向，`scroll-y`）承载若干"详情卡片"，每张卡片 = 一条新闻（复用现有 `getNewsDetail` 渲染逻辑）。
- 当前卡片居中显示；上滑看上一条、下滑看下一条。
- 遵守开发红线：`scroll-view` 在 flex 容器中用 `flex:1 + min-height:0`（**红线 #3**）。

### 2.2 数据获取
- **当前条**：进入详情时按 `newsId` 调 `getNewsDetail`（L1 `news` 集合 / L2 AI 兜底）。
- **预取**：维护"阅读游标" = `{ category, pageNum, index }`。向上/下滑时：
  - 下一条 = 同 `category` 下一 `index`；若到本页末尾，则 `pageNum+1` 调 `getNewsList` 取下一页首条。
  - 跨分类：当前分类页末 + 无更多（`hasMore=false`）时，切换到下一分类（按 5 分类顺序）首条。
- **预取窗口**：当前 ±2 条提前 `getNewsDetail` 拉取并缓存，保证滑动无白屏。

### 2.3 阅读模式功能（技术可行项）
| 功能 | 技术实现 | 状态 |
|------|----------|------|
| 字号调整 | `wx.setStorageSync('readFontSize', n)` + `pages/detail/detail.wxss` 用 `var(--read-font)` 动态字号 | ✅ 可实现 |
| 主题切换 | 明/暗/护眼三套，CSS 变量切换（暗色已全局支持 `!important` 覆盖） | ✅ 可实现 |
| 目录/分段 | 若 `content` 含标题标记（如 `## `），前端切分渲染锚点 | ✅ 可实现（依赖 contentExtractor 保留结构） |
| 收藏 | `wx.setStorageSync('favorites', [...])` 本地收藏 + 可选云库 `favorites` 集合 | ✅ 可实现 |
| 阅读进度 | 顶部进度条 = 当前游标 / 分类总量 | ✅ 可实现 |

### 2.4 手势约束
- 滑动手势若需 WXS 加速，必须**纯 ES5**（**红线 #1**：禁 `let/const/箭头/模板串/try**）；复杂状态用 JS 处理。
- 内层 `scroll-view` 与卡片间滑动冲突：用 `catchtouchmove` 判定边界，到顶/底才触发翻页。

## 3. 边界与异常
- 列表末尾：跨分类或提示"已读完本分类"。
- `getNewsDetail` 返回 `NO_DATA`：跳过该条，取再下一条。
- 弱网：预取失败不阻塞当前条，下滑时实时拉取并 loading。

## 4. 待设计确认（UX，不阻塞技术落地）
- 字号档位与 UI 控件形态（底部弹层 / 顶部按钮）。
- 主题选项是否含"护眼"。
- 目录交互形态（侧边锚点 / 顶部下拉）。
- 收藏是否需云端同步（涉及新增云函数/集合，工作量上升）。

## 5. 验收要点
- 上下滑切换流畅、无白屏；跨分类衔接正确；字号/主题即时生效；收藏持久化；不触发红线。
