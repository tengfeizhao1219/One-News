## 1. getNewsList — 新闻列表

**入参**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| category | string | 否 | 分类键，默认 `all`；可选 `top`/`tech`/`finance`/`sports`/`life`（以 `adapter` 映射为准） |
| pageNum | number | 否 | 页码，默认 1，最小 1 |
| pageSize | number | 否 | 每页条数，限制 `config.pagination` 的 maxPageSize |

**返回**
```
{ code:0, data:{ list:[NewsItem], total, hasMore }, meta:{ source:'tian_api|memory_cache|db_cache|juhe_fallback|ai_cache', synced?, cacheVersion?, cacheGeneratedAt? } }
```
**降级**：L1 天行→L2 内存→L3 云库→L4 聚合→L5 AI 兜底→ 全失败 `{code:-1, errorCode:'ALL_DOWN'}`（详见降级策略文档）。

### 1.1 跨分类合并列表约定（T-02 架构设计新增）🆕

> **用途**：`reading-engine.js` 进入详情时并行调用 `getNewsList` × 5（每分类首 pageSize），合并为 `mergedList`。

**调用模式**：
```js
// 并行调用（推荐）
const categories = ['top', 'tech', 'finance', 'sports', 'life']
const results = await Promise.all(
  categories.map(cat =>
    wx.cloud.callFunction({ name: 'getNewsList', data: { category: cat, pageNum: 1, pageSize: 10 } })
  )
)
// 合并：按 CATEGORIES 顺序拼接 list，记录 totalPerCategory
const mergedList = []
const totalPerCategory = {}
results.forEach((res, i) => {
  if (res.code === 0 && res.data?.list) {
    mergedList.push(...res.data.list)
    totalPerCategory[categories[i]] = res.data.list.length
  }
})
```

**注意事项**：
- 并行 5 次调用总耗时 ≈ 最慢一次（~500ms–2s），首屏可先渲染当前条再异步补全
- 某分类返回空/失败时跳过该分类，不阻塞整体合并
- `mergedList` 仅存索引字段（id/title/summary/category/categoryName/picUrl/source/publishTime），不含 `content`（content 按需通过 `getNewsDetail` 预取）
- `totalPerCategory` 用于进度指示（如 "3 / 20 · 科技"）和边界判定

## 2. getNewsDetail — 新闻详情

**入参**
| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| newsId | string | 是 | 新闻自定义 id（非 CloudBase `_id`） |

**返回**
```
成功：{ code:0, data:NewsItem(含 content), meta:{ source:'db_news|ai_cache' } }
缺失：{ code:-1, message:'新闻不存在或已过期', errorCode:'NO_DATA' }
缺参：{ code:-1, message:'缺少 newsId 参数' }
```
**逻辑**：L1 `news` 集合 `where({id:newsId})` → 正文不足 30 字时 `contentExtractor` 抓原文兜底、失败用 `summary`；未命中则 L2 `aiNewsService.getById` 兜底；阅读数 `viewCount +1`。

## 3. refreshNews — 新闻刷新（内部/定时）

**触发**：定时触发器（6:00 / 11:00 / 20:00）+ 小程序手动调用（刷新按钮）。无对外业务入参。

**返回**
```
{ code:0, message:'刷新完成，共 N 条新闻',
  data:{ total, inserted, failed, cleared, categories, searchStats, validation,
         securityStats: {        // 🆕 T-03: 内容安全审核统计
           checked: number,      // 送审总数
           passed: number,       // 通过数
           blocked: number,      // 拦截数
           apiError: number,     // API 不可用次数
           blockedIds: string[]  // 被拦截的新闻 id 列表
         },
         elapsedMs } }
失败：{ code:-1, message, errorCode:'LLM_SEARCH_FAILED' }
```
**逻辑**：百炼 DeepSeek 联网搜索全分类 → `validator` 校验去重 → 🆕 `securityCheck` 内容安全审核（`msgSecCheck` + `imgSecCheck`，命中违规拦截、API 不可用保守暂缓）→ 按分类清旧写新到 `news_cache`（TTL 10min）。

## 4. 错误码表
| errorCode | 含义 | 触发 |
|-----------|------|------|
| `ALL_DOWN` | 全部数据源不可用 | getNewsList L1~L5 全失败/空 |
| `NO_DATA` | 新闻不存在/过期 | getNewsDetail 未命中 |
| `LLM_SEARCH_FAILED` | 大模型搜索失败 | refreshNews 百炼调用异常 |
| `API_KEY_INVALID` | API Key 未配置 | 天行/JUHE Key 缺失 |
| `SECURITY_BLOCKED` | 内容安全审核拦截 | refreshNews 安全审核命中 |
| `SECURITY_API_ERROR` | 内容安全 API 不可用 | msgSecCheck/imgSecCheck 超时/限频 |

## 5. NewsItem 数据 schema
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 新闻自定义 id |
| title | string | 标题 |
| summary | string | 摘要（空时抓正文首段兜底） |
| category | string | 分类键 |
| categoryName | string | 分类名 |
| source | string | 来源 |
| sourceUrl | string | 原文链接（详情页"查看原文"） |
| publishTime | number/string | 发布时间 |
| content | string | 正文（详情页；列表可无） |
| viewCount | number | 阅读数 |

| `SECURITY_BLOCKED` | 内容安全审核拦截 | refreshNews 安全审核命中 |
| `SECURITY_API_ERROR` | 内容安全 API 不可用 | msgSecCheck/imgSecCheck 超时/限频 |

## 6. 前端消费模式（T-03 新增）🆕

### 6.1 跨分类阅读引擎调用流
```
detail.onLoad({ id, category })
  → request.getNewsList × 5 (并行)          // §1.1 合并列表约定
  → readingEngine.init(mergedList, id)      // 定位 cursor
  → request.getNewsDetail(cursor±2) (预取)   // §2
  → 渲染当前卡片
```

### 6.2 收藏数据流（纯本地，不依赖云函数）
```
收藏: localCache.lruPush('favorites', item, 200)
取消: localCache.lruRemove('favorites', id)
列表: localCache.lruList('favorites') → 时间倒序渲染
状态: localCache.lruList('favorites').find(id) → isFavorited
```

### 6.3 字体数据流（纯本地 + CSS 变量）
```
设置: wx.setStorageSync('fontScale', value)
     → globalData.fontScale = value
     → document.documentElement.style.setProperty('--font-scale', value)
生效: calc(原字号 * var(--font-scale))
```

### 6.4 分享数据流（客户端 Canvas 兜底）
```
onShareAppMessage:
  imageUrl = item.picUrl
    || await shareCard.generate({ title, category })  // Canvas 400×300 占位图
    || ''  // 最终兜底
```
