# ADR-003 — 恢复一层兜底：news_cache 空→上次成功缓存降级

## 1. 背景与问题

### 1.1 现状

- `getNewsList` 在 v4.2 被简化为「纯 news_cache，不降级不兜底」（见 `getNewsList/index.js:94-95` 注释）。
- 当 `news_cache` 集合为空（refreshNews 拉取失败 / 外部 API 配额耗尽 / 新部署首次触发 / 清理策略误删）时，`getNewsList` 直接返回 `{ list: [], total: 0 }`（L118-124），前端展示**空白页**。
- 现有的 `stale` 兜底（L38-46）仅在**未过期无数据→放宽条件查历史**的路径生效——当集合**完全没有记录**（连过期记录都不存在）时，`stale` 兜底也被绕过。

### 1.2 裁定

> **owner 2026-08-03 裁定（PD-B5）**：恢复至少一层兜底——`news_cache` 空/拉取失败时展示「本地上次成功缓存」或「内置精选列表」（`meta.source='cache-fallback'`），**任何情况不得空白页**。

---

## 2. 决策：上次成功缓存优先（方案 A）

### 2.1 方案描述

在 `getNewsList` 主函数中，于现有「news_cache 为空→返回空列表」之前，增加一层**持久化备份查询**：

1. **备份写入**：`refreshNews` 每次成功写入 `news_cache` 后，**将当前分类的最新一批记录（≤20 条/分类）同步写入 `news_cache_backup` 集合**（按 category 覆盖，同分类只保留最新快照）。
2. **降级读取**：`getNewsList` 在 `news_cache` 查询结果为空（L118 路径）时，查询 `news_cache_backup` 集合；若有数据，返回备份内容并标注 `meta.source='cache-fallback'`。
3. **不空白页保障**：若 `news_cache_backup` 也为空（极端情况：首次部署，从未成功 refresh），返回内置精选列表（少量 curated 新闻，代码硬编码，覆盖 5 个分类），同样标注 `meta.source='cache-fallback'`。

### 2.2 不采用「仅内置精选」的理由

| 维度 | 上次成功缓存（本方案） | 仅内置精选 |
|------|----------------------|-----------|
| 数据新鲜度 | 最近一次 refresh 的真实新闻，时效性好 | 静态列表，可能数月未更新 |
| 用户感知 | 与正常列表外观一致，仅 source 不同 | 明显是占位内容，信任感差 |
| 分类覆盖 | 与正常分类一致（5 个分类均有备份） | 需手动维护 5 个分类的精选内容 |
| 实现复杂度 | 备份写入 ~20 行 + 降级查询 ~20 行 | 需维护静态 JSON 文件并随分类口径同步更新 |

### 2.3 与现有 stale 兜底的关系

```
getNewsList 数据查询优先级（从高到低）：
  ┌──────────────────────────────────────────────────────────┐
  │ 1. news_cache（未过期，cacheExpire > now）               │  ← 正常路径
  │ 2. news_cache（已过期，stale 兜底）                      │  ← 现有 stale 路径
  │ 3. news_cache_backup（上次成功快照）   ← 🆕 本方案      │  ← cache-fallback
  │ 4. 内置精选列表（极端兜底）              ← 🆕 本方案      │  ← cache-fallback
  └──────────────────────────────────────────────────────────┘
```

- 第 1-2 层不变，保持现有行为。
- 第 3 层仅在 1+2 均为空时触发（`dbCached` 为 null 或 `list.length === 0`）。
- 第 4 层仅在第 3 层也为空时触发（首次部署、从未成功 refresh）。

## 3. 技术实现

### 3.1 refreshNews — 备份写入

**位置**：`cloudfunctions/refreshNews/index.js`，在 `batchInsert()` 成功后追加。

```javascript
// ── 备份写入：将本次成功写入的新闻快照同步到 news_cache_backup ──
async function backupToCacheBackup(category, docs) {
  if (!docs || docs.length === 0) return
  try {
    const _ = db.command
    // 按分类覆盖：先删旧备份，再写新快照
    await db.collection('news_cache_backup')
      .where({ category })
      .remove()
    // 取前 20 条作为快照
    const snapshot = docs.slice(0, 20).map(doc => ({
      ...doc,
      _backupAt: Date.now(),
    }))
    // 分批写入（每批 ≤100 条，此处 ≤20 直接写）
    await db.collection('news_cache_backup').add(
      snapshot.length === 1 ? { data: snapshot[0] } : snapshot.map(d => ({ data: d }))
    )
    console.log(`[backupToCacheBackup] ${category} 备份 ${snapshot.length} 条`)
  } catch (err) {
    console.warn('[backupToCacheBackup] 备份写入失败（非阻塞）:', err.message)
    // 备份失败不影响主流程
  }
}
```

**触发点**：在 `batchInsert` 调用后，对每个成功写入的分类调用 `backupToCacheBackup(category, docs)`。

### 3.2 getNewsList — 降级读取

**位置**：`cloudfunctions/getNewsList/index.js`，在 L118「news_cache 为空」处替换。

```javascript
// 现有代码 L103-125 替换为：
const dbCached = await getFromDbCache(category, pageNum, pageSize)
if (dbCached && dbCached.list.length > 0) {
  // 正常路径不变
  return {
    code: 0,
    data: dbCached,
    meta: { source: 'news_cache', engine: 'zhipu/deepseek', stale: !!dbCached.stale },
  }
}

// ── 🆕 一层兜底：news_cache_backup（上次成功快照）──
const backupData = await getFromCacheBackup(category, pageNum, pageSize)
if (backupData && backupData.list.length > 0) {
  console.warn(`[getNewsList] news_cache 为空，降级到 cache_backup，返回 ${backupData.list.length} 条`)
  return {
    code: 0,
    data: backupData,
    meta: { source: 'cache-fallback', engine: 'cache-backup', fallback: true },
  }
}

// ── 🆕 二层兜底：内置精选列表（极端情况）──
const builtinData = getBuiltinNewsList(category, pageNum, pageSize)
if (builtinData && builtinData.list.length > 0) {
  console.warn(`[getNewsList] news_cache + backup 均为空，降级到内置精选`)
  return {
    code: 0,
    data: builtinData,
    meta: { source: 'cache-fallback', engine: 'builtin', fallback: true },
  }
}

// 三重均空 → 诚实返回空（理论上不应到达）
return {
  code: 0,
  data: { list: [], total: 0, hasMore: false },
  meta: { source: 'empty', hint: '所有数据源均无可用数据，请联系管理员' },
}
```

### 3.3 getFromCacheBackup 实现

```javascript
/**
 * 从 news_cache_backup 读取上次成功快照
 */
async function getFromCacheBackup(category, pageNum, pageSize) {
  try {
    const where = category && category !== 'all'
      ? { category }
      : {}
    const res = await db.collection('news_cache_backup')
      .where(where)
      .orderBy('publishTime', 'desc')
      .skip((pageNum - 1) * pageSize)
      .limit(pageSize)
      .get()
    if (res.data && res.data.length > 0) {
      const totalRes = await db.collection('news_cache_backup').where(where).count()
      return {
        list: res.data.map(item => ({
          id: item.id, _id: item._id,
          title: item.title, summary: item.summary,
          category: item.category,
          categoryName: item.categoryName || CATEGORY_NAMES[item.category] || '',
          source: item.source, sourceUrl: item.sourceUrl || '',
          publishTime: item.publishTime,
          isRetained: item.isRetained === true,
        })),
        total: totalRes.total,
        hasMore: (pageNum * pageSize) < totalRes.total,
      }
    }
    return null
  } catch (err) {
    console.warn('[getFromCacheBackup] 备份查询失败:', err.message)
    return null
  }
}
```

### 3.4 内置精选列表

```javascript
/**
 * 内置精选列表 — 极端兜底（首次部署、从未成功 refresh 时使用）
 * 覆盖 5 个分类，每个分类 3-5 条，标注 meta.source='cache-fallback'
 */
const BUILTIN_NEWS = {
  recommend: [
    { id: 'builtin-rec-01', title: '欢迎使用 One-News', summary: '这是一款极简新闻速览小程序，每天为你精选值得关注的新闻。', category: 'recommend', categoryName: '推荐', source: 'One-News', publishTime: Date.now() },
  ],
  tech: [
    { id: 'builtin-tech-01', title: '新闻数据加载中', summary: '当前新闻缓存尚未填充，请稍后刷新或联系管理员触发 refreshNews。', category: 'tech', categoryName: '科技', source: 'One-News', publishTime: Date.now() },
  ],
  sports: [
    { id: 'builtin-sports-01', title: '新闻数据加载中', summary: '当前新闻缓存尚未填充，请稍后刷新或联系管理员触发 refreshNews。', category: 'sports', categoryName: '科学探索', source: 'One-News', publishTime: Date.now() },
  ],
  international: [
    { id: 'builtin-intl-01', title: '新闻数据加载中', summary: '当前新闻缓存尚未填充，请稍后刷新或联系管理员触发 refreshNews。', category: 'international', categoryName: '国际', source: 'One-News', publishTime: Date.now() },
  ],
  life: [
    { id: 'builtin-life-01', title: '新闻数据加载中', summary: '当前新闻缓存尚未填充，请稍后刷新或联系管理员触发 refreshNews。', category: 'life', categoryName: '社会', source: 'One-News', publishTime: Date.now() },
  ],
}

function getBuiltinNewsList(category, pageNum, pageSize) {
  const cat = category === 'all' ? 'recommend' : category
  const items = BUILTIN_NEWS[cat] || BUILTIN_NEWS.recommend
  const start = (pageNum - 1) * pageSize
  const list = items.slice(start, start + pageSize)
  return {
    list,
    total: items.length,
    hasMore: (start + pageSize) < items.length,
  }
}
```

### 3.5 数据库集合与索引

| 集合 | 用途 | 索引 |
|------|------|------|
| `news_cache_backup`（🆕） | 上次成功 refresh 的快照 | `category` + `publishTime` desc |

- 每个分类仅保留最新快照（写入时先 `remove({category})` 再 `add`），无需 TTL 清理。
- 备份写入失败**不阻塞** refreshNews 主流程（`try/catch + console.warn`）。

## 4. 影响范围

### 4.1 代码改动

| 文件 | 改动 | 性质 |
|------|------|------|
| `cloudfunctions/getNewsList/index.js` | 新增 `getFromCacheBackup()` + `getBuiltinNewsList()` + 主函数降级分支 | 🆕 新增 ~60 行 |
| `cloudfunctions/refreshNews/index.js` | 新增 `backupToCacheBackup()` + 调用点 | 🆕 新增 ~30 行 |

### 4.2 不影响的路径

- ✅ `getNewsList` 正常路径（L1 news_cache 命中）完全不变
- ✅ `getNewsDetail` 不受影响（其兜底逻辑独立）
- ✅ `refreshNews` 主流程不变（备份为追加步骤）
- ✅ 现有 `stale` 兜底、RQ-16 分级 TTL、RQ-03 收藏上云均不受影响
- ✅ `getNewsList` 返回结构不变（仅 `meta.source` 值可能为 `'cache-fallback'`）

### 4.3 前端感知

- 前端无需任何改动。`meta.source` 从 `'news_cache'` 变为 `'cache-fallback'` 仅影响调试日志，不影响渲染逻辑。
- 若将来需要 UI 区分（如"数据可能不是最新的"提示），前端可通过 `meta.source === 'cache-fallback'` 判断。

## 5. 验收标准

| # | 验收项 | 验证方法 |
|---|--------|---------|
| AC-B8-01 | news_cache 空时 getNewsList 返回 cache_backup 数据（非空列表） | 清空 news_cache → 调用 getNewsList → 返回 list.length > 0，meta.source='cache-fallback' |
| AC-B8-02 | news_cache + backup 均空时返回内置精选（非空列表） | 清空两集合 → 调用 getNewsList → 返回内置精选，meta.source='cache-fallback' |
| AC-B8-03 | refreshNews 成功后 backup 被更新 | 触发 refreshNews → 检查 news_cache_backup 有最新数据 |
| AC-B8-04 | backup 写入失败不阻塞 refreshNews | 模拟 backup 写入异常 → refreshNews 仍返回 code: 0 |
| AC-B8-05 | 正常路径不受影响 | news_cache 有数据时 getNewsList 返回 meta.source='news_cache' |
| AC-B8-06 | 用户不会看到空白页 | 任何数据源组合下 getNewsList 返回 list.length > 0（除非所有源均故障） |
