# 新闻自动更新 v3 — 技术方案（终版）

> **版本**：v3.0 | **日期**：2026-07-28
> **决策**：采用阿里百炼 DeepSeek 联网搜索作为主力数据源

---

## 一、方案演进

| 版本 | 数据源 | 问题 |
|------|--------|------|
| v1 | WorkBuddy → GitHub JSON → 定时触发器 | 需手动 git push |
| v2 | 天行数据 API → 定时触发器 | 需注册 API Key |
| **v3（终版）** | **百炼 DeepSeek 联网搜索** → 定时触发器 + 手动刷新 | ✅ 全自动、免费、高质量 |

## 二、架构

```
┌──────────────────────────────────────────────────┐
│                                                  │
│  触发方式：                                       │
│  ├─ 定时触发器 (每天 6:00 / 11:00 / 20:00)        │
│  └─ 用户点击"刷新"按钮                             │
│       ↓                                          │
│  refreshNews 云函数                               │
│       ↓                                          │
│  llmSearch 模块                                   │
│       ↓                                          │
│  阿里百炼 DeepSeek API                            │
│     enable_search: true                           │
│     forced_search: true                           │
│     assigned_site_list: [白名单新闻源]             │
│     freshness: 1                                  │
│       ↓                                          │
│  validator 模块（质量校验）                         │
│     ├─ JSON Schema 校验                           │
│     ├─ 来源白名单过滤                              │
│     ├─ 标题去重                                   │
│     └─ 时间范围校验                                │
│       ↓                                          │
│  写入云数据库 news_cache                           │
│       ↓                                          │
│  小程序 getNewsList 自动获取                       │
│                                                  │
└──────────────────────────────────────────────────┘
```

## 三、新闻来源白名单

### 国内
新华社(xinhuanet.com)、人民日报(people.com.cn)、央视新闻(cctv.com)、中新网(chinanews.com)、澎湃新闻(thepaper.cn)、36氪(36kr.com)、虎嗅(huxiu.com)、环球时报(huanqiu.com)

### 海外
Reuters(reuters.com)、BBC(bbc.com)、AP(apnews.com)、TechCrunch(techcrunch.com)

## 四、定时触发

每天三个时间点，cron 表达式：

| 时间 | cron | 说明 |
|------|------|------|
| 06:00 | `0 0 6 * * * *` | 早间新闻 |
| 11:00 | `0 0 11 * * * *` | 午间新闻 |
| 20:00 | `0 0 20 * * * *` | 晚间新闻 |
