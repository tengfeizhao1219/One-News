# 共享保险库 — GitHub Token 使用指南

> **谁该读**：One-News 项目所有角色（产品经理 / 交互设计师 / 视觉设计师 / 技术负责人 / 前端开发 / 后端开发 / 测试工程师 / 项目经理）
> **最后更新**：2026-07-30

---

## 一句话总结

`One-News` 仓库是**公开仓库**——`git pull` / `git clone` 不需要任何 token。**只有 `git push`（写）** 才需要 GitHub 令牌。

---

## Token 获取方式

> ⚠️ Token **不存储在本文件中**（GitHub 推送保护会拦截明文密钥）。通过以下任一途径获取 token 后，按下方「使用方法」操作即可。

| 途径 | 位置 | 说明 |
|------|------|------|
| 📋 **项目经理** | 直接索要 | 最直接：找 PM 复制 |
| ☁️ **tdrive 云盘** | 项目盘 `vault/github_pat` | 用 tdrive `file_download` 下载，文件内容即为 token |
| 🔐 **本地保险库** | PM 会话 `/root/.secrets/github_pat` | PM 专用 `secret_get github_pat` |

> 此 token 已配置 `workflow` scope，可推送代码和 GitHub Actions。

---

## 使用方法（复制 → 粘贴 → 运行）

第 1 步：拉取最新代码（不需要 token）

```bash
git pull origin main
```

第 2 步：push 时临时注入 token（用你的实际 token 替换下面 `<token>` 部分）

```bash
git remote set-url origin "https://<token>@github.com/tengfeizhao1219/One-News.git"
git push origin main
git remote set-url origin "https://github.com/tengfeizhao1219/One-News.git"
```

第 3 步（可选）：确认 remote 已还原

```bash
git remote -v
# 应该显示：https://github.com/tengfeizhao1219/One-News.git（不含 token）
```

## 安全须知

1. **不要**把 token 明文写在代码、commit message、PR 评论或截图里
2. **不要**把包含 token 的 git remote URL 提交到仓库（每次 push 后必须还原）
3. token **仅供 One-News 项目使用**，不要用于其他仓库或服务
4. 一旦怀疑 token 泄露 → 立即到 GitHub Settings → Developer settings → Personal access tokens → **撤销并重建**
5. 重建后告诉项目经理，更新本文件 + tdrive vault + 本地保险库三处

## Notion Token（资产库同步用）

> 用于 `notion_sync.py` 将文档+代码同步到 Notion 资产库。与 GitHub Token 无关。

| 途径 | 位置 | 说明 |
|------|------|------|
| 📋 **项目经理** | 直接索要 | 找 PJM 复制 Notion integration token |
| 📁 **仓库本地** | `/root/one-news/.notion_token` | 已 gitignore，不进仓库。写入 `ntn_xxx...` 即可 |
| 🌐 **环境变量** | `export NOTION_TOKEN=ntn_xxx...` | 临时注入，会话关闭即失效 |

> 用法：`bash sync_to_asset_library.sh`（自动读取 token → merge 文档+代码快照 → 同步 Notion）
> 详见 `docs/00-规划/资产库同步速查-文件该放哪个目录.md`、`COLLABORATION.md` §九。

## GitHub Actions 自动巡检

仓库已配置 `relay-watch` 工作流（`.github/workflows/relay-watch.yml`）：

- **触发**：每次 push 到 main（且 TASK_BOARD.md 或 RELAY.md 有变更）
- **行为**：解析任务看板，生成状态摘要，创建/更新 "Relay Status" Issue
- **查看**：GitHub 仓库 → Actions 标签 → Relay Watch
