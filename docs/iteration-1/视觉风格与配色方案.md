# 视觉风格定义与配色方案

> **产品**：「一页」 | **版本**：v1.0 | **日期**：2026-07-27
> **负责**：🎨 UI/UX设计师

---

## 1. 设计理念

### 1.1 设计关键词

| 关键词 | 说明 |
|--------|------|
| **沉浸** | 全屏内容展示，无干扰元素，让用户完全沉浸在阅读中 |
| **呼吸** | 大量留白，舒适的字间距和行间距，给眼睛喘息空间 |
| **克制** | 去掉一切非必要元素，没有TabBar、没有Banner、没有复杂导航 |
| **质感** | 细腻的阴影、圆角、半透明毛玻璃，营造高级感 |
| **节奏** | 上下滑动的流畅过渡，像翻书一样自然 |

### 1.2 设计参考

| 参考来源 | 借鉴要点 |
|----------|---------|
| 抖音/快手 | 全屏沉浸、上下滑动切换、无干扰设计 |
| Apple News | 大图+文字叠加、卡片质感、字体排版 |
| Kindle | 阅读舒适度、字距行距、专注感 |
| Instagram Stories | 全屏内容、轻量交互提示、自动播放节奏 |

## 2. 配色方案

### 2.1 浅色模式

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面底色 | `#F2F2F7` | 极浅灰，比纯白柔和 |
| 卡片背景 | `#FFFFFF` | 纯白卡片 |
| 主文字 | `#1A1A1A` | 近黑，高对比度阅读 |
| 辅助文字 | `#8E8E93` | 灰色，元信息 |
| 弱化文字 | `#C7C7CC` | 浅灰，提示性文字 |
| 分割线 | `#E5E5EA` | 极浅灰分割 |
| 毛玻璃背景 | `rgba(255,255,255,0.72)` | 导航/列表背景 |
| 遮罩层 | `rgba(0,0,0,0.4)` | 列表打开时的遮罩 |

### 2.2 暗色模式

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面底色 | `#000000` | 纯黑底 |
| 卡片背景 | `#1C1C1E` | 深灰卡片 |
| 主文字 | `#F2F2F7` | 浅色文字 |
| 辅助文字 | `#8E8E93` | 灰色 |
| 弱化文字 | `#545458` | 深灰 |
| 分割线 | `#38383A` | 深灰分割 |
| 毛玻璃背景 | `rgba(28,28,30,0.85)` | 深色毛玻璃 |

### 2.3 5大分类强调色

| 分类 | 色值 | 色块 | 用途 |
|------|------|------|------|
| 推荐 | `#FF3B30` | 🟥 | 热门标记、推荐标签 |
| 科技 | `#007AFF` | 🟦 | 科技标签 |
| 国际 | `#5856D6` | 🟪 | 国际标签 |
| 体育 | `#FF9500` | 🟧 | 体育标签 |
| 生活 | `#34C759` | 🟩 | 生活标签 |

每个分类强调色用于：
- 卡片底部分类标签
- 列表页分类Tab选中态
- 详情页分类标记

### 2.4 无图卡片背景渐变

当新闻没有配图时，卡片使用分类对应的渐变背景：

| 分类 | 渐变 |
|------|------|
| 推荐 | `linear-gradient(135deg, #FF3B30, #FF6B6B)` |
| 科技 | `linear-gradient(135deg, #007AFF, #5AC8FA)` |
| 国际 | `linear-gradient(135deg, #5856D6, #9B59B6)` |
| 体育 | `linear-gradient(135deg, #FF9500, #FFB84D)` |
| 生活 | `linear-gradient(135deg, #34C759, #7ED321)` |

## 4. 间距体系

基准单位：**8rpx**

| 名称 | 值 | 用途 |
|------|------|------|
| xs | 8rpx | 紧凑间距 |
| sm | 16rpx | 小间距 |
| md | 24rpx | 标准间距 |
| lg | 32rpx | 大间距 |
| xl | 48rpx | 超大间距 |

### 全屏卡片内间距

```
┌─────────────────────────────┐
│         48rpx (xl)          │  ← 顶部留白
│                             │
│         [内容区域]           │
│                             │
│  ── 左右边距 32rpx(lg) ──   │
│                             │
│         48rpx (xl)          │  ← 底部留白
└─────────────────────────────┘
```

## 6. 动效规格

| 动效 | 时长 | 缓动函数 | 说明 |
|------|------|---------|------|
| 卡片切换（上下滑） | 350ms | `cubic-bezier(0.25, 0.46, 0.45, 0.94)` | 类似抖音翻页 |
| 列表侧滑进入 | 300ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 从右侧滑入 |
| 列表侧滑退出 | 250ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 向右滑出 |
| 遮罩淡入/淡出 | 300ms | `ease` | 列表打开时背景变暗 |
| 卡片点击反馈 | 150ms | `ease` | scale(0.98) |
| 分类Tab切换 | 250ms | `ease` | 指示器滑动 |

### 上下滑动切换动画详解

```
当前卡片：
  transform: translateY(0) → translateY(-100%)
  opacity: 1 → 0.3
  时长: 350ms

下一张卡片：
  transform: translateY(100%) → translateY(0)
  opacity: 0.3 → 1
  时长: 350ms

两张卡片同时动画，形成连续翻页效果。
```

## 7. 图标规范

- 风格：线性图标，描边 2rpx
- 尺寸：操作图标 40×40rpx，提示图标 32×32rpx
- 颜色：继承当前文字颜色
- 暗色模式：自动适配

| 图标 | 用途 |
|------|------|
| ← | 返回 |
| ✕ | 关闭列表 |
| 🤍/❤️ | 收藏(未/已) |
| ↗️ | 分享 |
| 🔤 | 字号 |
