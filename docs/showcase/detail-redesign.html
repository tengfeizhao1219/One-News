量子计算机首次实现千比特纠错运算
科技科技日报·2小时前

研究团队宣布在超导量子芯片上实现了千比特级别的实时纠错，错误率降至十万分之一以下。该成果被认为是通用量子计算走向工程化的关键一步。

与以往的演示性实验不同，此次系统在不牺牲算力的前提下，持续维持了纠错后的逻辑比特稳定性，验证了表面码纠错方案在大规模阵列上的可行性。

多位独立学者指出，尽管距离实用化仍有距离，但这一跨越意味着「噪声中等规模量子」阶段的核心瓶颈已被触及，后续工程化路径更加清晰。

团队同时开源了部分控制固件与标定流程，希望借助社区力量加速迭代。业内预计，相关方法将在未来三年内外溢至加密、材料模拟与优化调度等领域。

值得注意的是，能耗与制冷成本仍是绕不开的约束。如何在保持纠错增益的同时压低温室级别的系统开销，将决定这项技术能否真正走出实验室。

3 · 落地规格（FS 照此实现）
维度现状优化后
阅读进度仅有 nav 文字「3/7」nav 下 2px 进度细条，宽度 = scrollTop/(scrollHeight-clientHeight)，onContentScroll 实时更新，色 --primary
滑动提示常驻不消失进入显示，3.5s 后淡出（transition .4s）；或用户首次滚动即消失，不再占视觉
收藏态仅图标变色，label「收藏」已收藏：label→「已收藏」+ 按钮微高亮(--color-favorite-tint) + 图标填充，保留 heartBeat
收藏反馈收藏成功顶部轻 toast「已加入收藏」；异步双写不阻塞阅读
触发位置进度条仅 ready 态显示；翻页动画与进度更新不冲突
token 来源全部取自 theme.json；新增仅 --color-favorite-tint（收藏高亮底）一处
交互边界：① 进度条只在 ready 态渲染，错误/加载态不显示；② 滑动提示消失后不再占用任何像素与事件；③ 收藏态切换乐观更新，翻页/滚动不受影响。
验收点：进度条随滚动平滑更新不卡顿 · 滑动提示 3.5s 或首次滚动后消失 · 已收藏态 label/背景/图标三者一致可辨 · 暗色模式进度条与提示色正确。
