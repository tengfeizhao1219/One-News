UI-B7 v4 修订（owner 2026-08-04 反馈：图标统一设计）

#反馈改动
1左滑进入列表，不要按钮首页无列表按钮；左滑手势滑出列表页（跟手位移），右滑或 × 关闭
2列表极简，只显示标题列表项仅标题（15px weight 600，2 行截断），无来源/时间
3高亮圆角当前项圆角边框 border-radius:10px + 淡色底，不用直角
4滑动提示固定底部首页卡片流 + 详情页底部各一条固定提示条
5dock 浮层更轻毛玻璃透明度 .92 → .78
6图标统一设计全部改为描边式（stroke）SVG（齿轮/时钟/心形/加号/房子/关闭），去掉 emoji 与填充图标，与图标规范文档完全一致

演示：① 首页卡片流左滑打开列表页；② 列表页左侧滚轮切分类（选中项圆角高亮）；③ 列表项仅标题，当前项圆角高亮；④ 点列表项定位回首页；⑤ 卡片上滑切下条；⑥ 首页/详情底部固定提示条；⑦ ⚙ dock（描边图标）；⑧ 暗色。
