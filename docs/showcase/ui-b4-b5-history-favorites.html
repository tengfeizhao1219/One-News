📐 UI-B4 浏览记录页（UI-01~08）

项规格
UI-01 框架导航栏「浏览记录」+ 列表/空态/加载态三态齐备（入口经 ⚙ dock 菜单，非侧边栏）
UI-02 列表项标题 2 行截断（28rpx）+ 次行「来源 · 相对时间」（22rpx），无缩略图
UI-03 相对时间今天→HH:mm；昨天→昨天；2~7天→N 天前；>7天不展示
UI-04 空态🕘 64rpx + 「暂无浏览记录」+ 引导按钮「去首页看看」
UI-05 加载骨架屏 3~5 条（亮/暗各一套）
UI-06 回看点列表项→详情定位；返回回原位置
UI-07 按压浅色遮罩，热区 ≥ 88rpx

📐 UI-B5 收藏云同步展示（UI-11~17）

项规格
UI-11 合并中列表打开时顶部细进度条（云端合并 ≤2s），静默完成
UI-12 空态「暂无收藏」
UI-13 待同步角标未上云条目右下角「☁️ 待同步」角标（12 号字，次级色），点按重试
UI-14 同步失败顶部轻提示条「收藏同步失败，点击重试」（非阻断）
UI-15 收藏反馈成功 ♥ 心跳；云端失败 toast「已收藏（待同步）」
UI-17 失效兜底回看已清理新闻 → 详情 error 态「新闻详情暂不可用，请返回重试」

✅ 本原型可验证：UI-01~08（浏览记录三态/相对时间/回看/暗色）+ UI-11~17（合并进度/待同步角标/失败条/失效兜底）。点击「浏览记录」第三条可体验 UI-17 失效兜底；「我的收藏」第一条带 UI-13 角标。
