## 一、项目概述

### 1.1 产品定位

「一页」是一款微信小程序端的极简新闻阅读器。核心体验是**卡片式沉浸阅读**——用户通过上下滑动卡片切换新闻，左滑呼出侧边栏切换分类，点击卡片进入详情阅读全文。

### 1.2 目标用户

- 通勤碎片时间阅读者
- 偏好简洁无干扰阅读体验的用户
- 每天只需快速浏览重要新闻的用户

### 1.3 核心功能

| 功能 | 状态 | 说明 |
|------|------|------|
| 卡片式上下滑浏览 | ✅ 已上线 | WXS 手势层 + JS 动画，3 张卡片池渲染 |
| 侧边栏分类切换 | ✅ 已上线 | 左滑呼出，5 个分类（推荐/科技/国际/体育/生活） |
| 详情页阅读 | ✅ 已上线 | 点击卡片跳转，展示标题+来源+正文 |

### 2.3 数据流

```
用户操作 → WXS 手势层 → JS onWxsTouchEnd → 切换/回弹/加载更多
                                              ↓
点击卡片 → onCardTap → wx.navigateTo → detail 页 → getNewsDetail
                                              ↓
侧边栏 → loadPanelNews → filteredNewsList → 切换分类 → loadNews
```

### 2.4 核心设计模式

- **3 张卡片池**：始终只渲染 prev/current/next 三张卡片，大幅减少 setData
- **WXS + JS 分层**：WXS 处理高频触摸跟手（不经过 setData），JS 处理低频业务逻辑和动画
- **Mock/Cloud 双通道**：`USE_MOCK` 开关一键切换数据源，开发阶段用 Mock 独立运行
- **架构不变量测试**：每个 Bug 修复后，用静态检查脚本锁死关键架构约束，防止同类回归

### 5.2 经验教训

1. **WXS 是 ES5 子集，禁止 try/catch/let/const/箭头/模板字符串/解构**——一旦使用整模块编译失败，所有触摸回调全部失效。提交前必须校验。
2. **WXS return false 可能阻止子元素 bindtap**——微信不同版本行为不一致，建议去掉所有 return false。
3. **scroll-view 在 flex 容器中用 height:100% 不可靠**——用 flex:1 + min-height:0。
4. **整体重写对象字面量方法时必须 grep 验证**——node --check 不检测重复/丢失的方法名。
5. **不要在聊天中贴 token**——敏感信息应通过 secrets 保险箱传递。
