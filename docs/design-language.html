设计原则

Design Principles
少即是多

每一个像素的存在都必须有充分的理由。去掉一切装饰性UI元素，让新闻内容本身成为界面。

手势即导航

没有按钮的界面，全靠直觉手势驱动。上下滑动切换新闻，左滑打开列表。

呼吸感

大量留白、宽松行距，让阅读像呼吸一样自然。8pt 网格体系保证视觉节奏。

一致性

全页面统一字体、间距、配色体系。跨页面字号强制对齐，无意外偏差。

配色系统

Color System · theme.json

双模式配色（浅色/暗色），以 theme.json 为唯一真值源。使用 CSS 变量注入，全站统一引用。
