## 1. 技术选型

| 维度 | 选择 | 理由 |
|------|------|------|
| 框架 | 微信原生小程序 | 轻量无依赖，性能最优，API最新 |
| 云服务 | 微信云开发 CloudBase | 免运维、免鉴权、与小程序深度集成 |
| 云函数运行时 | Node.js 18 | 云开发默认推荐版本 |
| 数据库 | 云数据库（NoSQL） | 文档型存储，灵活适配新闻内容结构 |
| 状态管理 | 页面级 data + globalData | 本项目状态简单，无需引入第三方库 |
| 暗色模式 | 微信原生 darkmode + theme.json | 官方方案，自动跟随系统 |

## 4. 数据模型

### 4.1 云数据库集合：news

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| _id | string | 自动 | 文档ID |
| title | string | ✅ | 新闻标题 |
| summary | string | ✅ | 摘要（约500字，用于卡片展示） |
| content | string | ✅ | 完整正文（用于详情页） |
| category | string | ✅ | 分类枚举：recommend/tech/international/sports/life |
| categoryName | string | ✅ | 分类中文名：推荐/科技/国际/体育/生活 |
| source | string | ✅ | 来源名称 |
| publishTime | Date | ✅ | 发布时间 |
| viewCount | number | | 阅读数，默认0 |

### 4.2 索引设计

| 索引名 | 字段 | 方向 | 用途 |
|--------|------|------|------|
| idx_category_time | category + publishTime | 升序+降序 | 按分类分页查询 |
| idx_publishTime | publishTime | 降序 | 全部分类按时间查询 |
| idx_search | title（文本索引） | - | 全文搜索 |

### 4.3 数据库安全规则

```json
{
  "news": {
    ".read": true,
    ".write": false
  }
}
```

所有人可读，仅云函数/控制台可写。

## 5. 云函数设计

### 5.1 getNewsList

**功能**：分页获取新闻列表

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| category | string | 否 | 'all' | 分类筛选，all=全部 |
| pageSize | number | 否 | 10 | 每页条数 |
| pageNum | number | 否 | 1 | 页码 |

**返回**：
```json
{
  "code": 0,
  "data": {
    "list": [{ "id", "title", "summary", "category", "categoryName", "source", "publishTime" }],
    "total": 100,
    "hasMore": true
  }
}
```

### 5.2 getNewsDetail

**功能**：获取单条新闻详情

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| newsId | string | ✅ | 新闻ID |

**返回**：
```json
{
  "code": 0,
  "data": {
    "id", "title", "summary", "content", "category", "categoryName", "source", "publishTime", "viewCount"
  }
}
```

### 5.3 searchNews

**功能**：关键词搜索新闻

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| keyword | string | ✅ | - | 搜索关键词 |
| pageSize | number | 否 | 10 | 每页条数 |
| pageNum | number | 否 | 1 | 页码 |

## 6. 数据流设计

### 6.1 Mock模式（开发阶段）

```
mock/news.js → utils/request.js（isMock=true）
  → getNewsList() 从Mock数组筛选返回
  → getNewsDetail() 从Mock数组查找返回
  → 页面 setData() → WXML渲染
```

### 6.2 生产模式

```
云数据库(news) → 云函数(CloudBase SDK查询)
  → utils/request.js（isMock=false）→ wx.cloud.callFunction()
  → 页面 setData() → WXML渲染
```

### 6.3 模式切换

在 `utils/request.js` 中通过一个开关变量 `USE_MOCK` 控制，开发阶段用 Mock，上线前切为云函数。

## 7. 手势交互技术方案

### 7.1 卡片流滑动

使用微信小程序的 `touchstart` / `touchmove` / `touchend` 事件：

```
touchstart → 记录起始坐标 (startY, startX)
touchmove  → 计算位移差，实时 translate 卡片
touchend   → 判断方向（dy > 阈值 → 切换卡片），动画过渡到目标位置
```

- 切换阈值：`|dy| > 50px`
- 动画时长：350ms cubic-bezier
- 左滑阈值：`dx < -60px && |dx| > |dy|`

### 7.2 侧边栏

使用 CSS `transform: translateX` + `transition` 实现滑入滑出。

### 7.3 详情页转场

使用微信小程序的 `wx.navigateTo` 或自定义 `transition` 动画。

## 8. 暗色模式方案

- `app.json` 中配置 `"darkmode": true` + `"themeLocation": "theme.json"`
- `theme.json` 定义浅色/暗色两套 CSS 变量
- 所有 `.wxss` 使用 `var(--xxx)` 引用变量
- 支持跟随系统自动切换

### CSS 变量定义

## 9. 性能优化策略

| 策略 | 说明 |
|------|------|
| 虚拟卡片 | 仅渲染当前+前一张+后一张卡片（3张），非可见卡片销毁 |
| 分包加载 | 搜索页独立分包，减少主包体积 |
| 数据缓存 | 首页列表数据缓存到 `wx.setStorage`，设置过期时间 |
| 防抖 | 搜索输入 300ms 防抖 |
| 图片 | 本项目几乎无图片，性能天然优势 |

## 10. 安全与合规

- 云数据库权限：news 集合全员可读、仅管理员可写
- 云函数不暴露数据库连接信息
- 新闻内容合规：上线前需确认类目资质
- 用户隐私：不收集用户个人信息
