## 三、🔴 发现 A（重要）——组件样式隔离限制 D-07 S2 迁移写法

### 3.1 问题

D-07 §四·S2 原文：
> `category-wheel.wxss`：media 块 → `.page--dark .wheel-label` + 新增 `.page--light .wheel-label`（浅色值显式声明，防 G-03 复发）

**该写法在微信小程序组件样式隔离（styleIsolation: isolated，默认值）下不生效**：
- `category-wheel.json` 仅 `{"component": true}`，未配置 `styleIsolation` → 默认 **isolated**
- 组件 wxss 的选择器**无法匹配宿主页面根节点的 class**（`.page--dark` 挂在 `pages/home/home.wxml` 根 view 上，组件内部 wxss 看不到它）
- 同理，`app.wxss` 的 `.page--dark` 变量块**可以**作用于组件内部（CSS 变量继承穿透样式隔离），但 `category-wheel.wxss` 内的 `.page--dark .wheel-label` **不能**

### 3.2 正确方案（推荐，零组件代码改动）

**把 `--wheel-*` 全量变量加入 `app.wxss` 的 `.page--dark` / `.page--light` 两个变量块**（色值与 theme.json 对应分支一致），组件内继续 `var(--wheel-*)` 引用即可：

```css
/* app.wxss .page--dark 块追加（值 = theme.json dark 分支 :76-82） */
--wheel-opacity-idle: 0.35;
--wheel-opacity-active: 0.92;
--wheel-text-idle: rgba(255, 255, 255, 0.12);
--wheel-text-selected: rgba(255, 255, 255, 0.5);
--wheel-text-active: rgba(255, 255, 255, 0.45);
--wheel-scale-active: 1.08;
--wheel-bg-selected: rgba(10, 132, 255, 0.10);

/* app.wxss .page--light 块追加（值 = theme.json light 分支 :35-41） */
--wheel-opacity-idle: 0.35;
--wheel-opacity-active: 0.92;
--wheel-text-idle: rgba(0, 0, 0, 0.12);
--wheel-text-selected: rgba(0, 0, 0, 0.5);
--wheel-text-active: rgba(0, 0, 0, 0.45);
--wheel-scale-active: 1.08;
--wheel-bg-selected: rgba(0, 122, 255, 0.06);
```

**原理**：`app.wxss` 是全局样式（非组件样式），其 `.page--dark` 变量块定义在页面根节点 → 组件内部子元素 `var(--wheel-*)` 向上查找变量定义时命中根节点 class 变量 → 手动模式下正确覆盖 theme.json 系统注入值。

### 3.3 对 D-07 的修订建议（PM 知悉）

> D-07 §四·S2 与 §3.2 改造点表中「category-wheel.wxss：media 块 → `.page--dark .wheel-label`」应**改为**：「`app.wxss` `.page--dark`/`.page--light` 变量块**补全 `--wheel-*` 变量**（8 个）；category-wheel.wxss 保持 `var(--wheel-*)` 引用不动」。S2 检查项「category-wheel 含 `.page--dark`/`.page--light` 前缀」相应改为「app.wxss 变量块含 `--wheel-*`」。
> 同理 **S1 变量块补全应包含全仓所有 `var(--xxx)` 变量**（含 `--wheel-*`、`--flash-*`），而非仅现有 `.page--dark` 块内变量。

## 五、🟡 发现 C——`--flash-*` 变量未入 `.page--dark` 块

| 变量 | theme.json light | theme.json dark | `.page--dark` 块 |
|---|---|---|---|
| `--flash-tech` | `#007AFF` | `#60A5FA` | ❌ 缺 |
| `--flash-world` | `#5856D6` | `#818CF8` | ❌ 缺 |
| `--flash-sports` | `#FF9500` | `#FBBF24` | ❌ 缺 |
| `--flash-life` | `#34C759` | `#34D399` | ❌ 缺 |
| `--flash-*-bg` | `rgba(0,122,255,.08)` 等 | `rgba(96,165,250,.12)` 等 | ❌ 缺 |

**影响评估**：`--flash-*` 为分类标识色，深浅差异（如 `#007AFF` vs `#60A5FA`）在深色底上视觉差异**可接受但不理想**（浅色版偏暗、对比度略降）。手动模式下取系统注入值会导致「手动深色 + 系统浅色」时分类色偏暗。

**建议**：随 S1 一并补入 `.page--dark`/`.page--light` 块（工作量 10 行），彻底杜绝手动模式下分类色错位。
