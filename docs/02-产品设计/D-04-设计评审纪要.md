## 三、交互设计定案（A-12b 结论 + PM 闭环）

### 3.1 跨分类衔接交互

| 项 | 结论 |
|------|------|
| 进度指示 | 同分类翻页维持 "3 / 20"；跨分类切换时显示 "1 / 15 · 科技"（分类色 fadeIn 200ms） |
| 衔接动画 | 复用 `out-up/in-up` 350ms；跨分类叠加分类色闪烁提示条 200ms |
| 边界提示 | 末条 Toast "已经是最后一条" + "← 返回首页" 可点击文字；首条 "已经是第一条 · 上滑返回" |
| 网络兜底 | 停在当前 + Toast "网络开小差，下拉重试"（黄色警告，3s） |
| 返回定位 | `_detailReturnState` 扩展为 `{ category, categoryIndex, newsId }`，兼容跨分类索引 |

### 3.2 字体设置

| 项 | 结论 |
|------|------|
| 入口 | **底部半屏面板**（✅ PM 确认：A-12b 建议采纳。侧边栏不应混入设置，半屏不打断浏览流） |
| 档位 | 4 档单选即时生效，无需确认按钮；首入跟随系统，手动调整后记忆 |
| 生效范围 | 全部文字通过 `calc(Xrpx * var(--font-scale))` 引用；图标/导航栏/热区固定 |

### 3.3 收藏 / 分享

| 项 | 结论 |
|------|------|
| 底部操作栏 | 毛玻璃 fixed bottom，100rpx + safe-area，收藏左 / 分享右 |
| 收藏状态机 | 🤍→❤️ heartBeat 300ms，#FF3B30（浅色）/#FF453A（暗色），纯本地 |
| 收藏列表入口 | **侧边栏「❤️ 收藏」Tab**（✅ PM 确认：不建独立页面，控制在 PRD §5.4 范围） |
| 收藏容量 | **200 条上限**（✅ PM 确认：微信 10MB storage 限制下合理；超出提示"收藏已满，请清理后重试"） |
| 分享 | `open-type="share"`，标题截断 30 字，`picUrl` → 分类占位图兜底 |
| 分享到朋友圈 | **本期不做**（✅ PM 确认：PRD 标"可选"，放 P2） |
