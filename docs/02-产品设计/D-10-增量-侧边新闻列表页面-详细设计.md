## 1. 页面定位与场景

| 项 | 说明 |
|----|------|
| 页面 | 首页（`pages/home`）右侧滑出面板 = **侧边新闻列表页面**（slide-panel） |
| 用途 | ① 分类导航（左侧垂直滚轮，切换主卡片流分类）；② 当前分类新闻标题列表（点击定位/跳详情） |
| 打开方式 | 首页卡片流右缘左滑（或入口触发）→ 面板从右侧滑入 |
| 关闭方式 | 点击遮罩（panel-overlay）→ 面板右滑出 + 遮罩淡出 |
| 宽高 | 面板宽 **90%** 屏宽、高 100%（right:0 贴右），圆角由父卡片容器决定，面板自带左侧阴影 |
| 范围边界 | **首页 UI/UX 保持现状不变**，本次仅设计「侧边新闻列表页」（slide-panel）——demo 中首页为真实现状示意，不在本次设计范围内 |

**核心体验目标（owner 17:20 裁定 · v5 稳定架构 17:52 修订）**：
1. **header 固定**：面板顶部标题区（今日新闻 + 副标题）永远可见，不随列表滚动；
2. **仅列表滚动**：内容多时可滑、少时完整显示（不撑高、不出现无意义滚动）；
3. **滚轮固定**：分类滚轮固定在列表左侧，`catch` 触摸独立，不与列表/卡片手势冲突；
4. **状态保留**：当前阅读项在列表中高亮，切分类后仍正确；
5. **⚠️ v5 布局（owner 17:52 裁定）**：v4 的 `flex:1 + height:0` 在真机导致 scroll-view 与 category-wheel 渲染异常（列表空白、滚轮只显部分分类）→ v5 彻底改用 **absolute 定位**（header/body/wheel/scroll 均 absolute，高度由 top/bottom 确定），规避真机渲染问题；历史版本保留 git 可回滚。

## 2. 布局架构（v5 稳定架构 · 结构树）

```
slide-panel（90% 宽 · right:0 · 高 100% · bg-card · z-index 30 · flex column）
├── panel-header（absolute 固定顶部：top:0 left:0 right:0 · z-index 5 · 不随列表滚动）
│   ├── panel-title      「今日新闻」
│   └── panel-subtitle   「当前分类 · N 条」
└── panel-body（absolute 铺满 header 下方：top:180rpx left:0 right:0 bottom:0）
    ├── panel-wheel（category-wheel 组件 · absolute 固定左侧：top:0 left:0 width:128rpx height:100% · z-index 2 · 顶部对齐）
    │   └── wheel-list（translateY 锚定 · 选中项恒在第 2 行）
    │       └── wheel-item × 分类数（72rpx 高 · 文字 24rpx）
    └── panel-scroll（scroll-view scroll-y · absolute 固定右侧：top:0 left:128rpx right:0 bottom:0 height:100%）
        └── panel-list
            ├── panel-item × 新闻数（padding 16rpx 32rpx · margin 0 24rpx）
            │   └── panel-item-title（28rpx/600 · 2 行截断 · current 主题色高亮）
            └── panel-empty（空态「暂无新闻」）
```

> **v5 布局要点**：不依赖 flex/百分比/height:0——header/body/wheel/scroll 全部 absolute，高度由 `top/bottom` 确定；scroll-view 高度完全确定（满足官方「固定高度」要求），规避 v4 真机渲染异常。

**层级（z-index）**：遮罩 `panel-overlay` 29 → 面板 `slide-panel` 30（高于遮罩、低于 dock 菜单等）。

## 7. 分类滚轮组件规范（category-wheel · v5.3-final）

### 7.1 三态视觉
| 状态 | 触发 | 外观 |
|------|------|------|
| **idle 默认** | 非触摸 | 整条 `opacity: 0.35`；未选中文字 `--wheel-text-idle`（12% 黑/白）；选中文字 `--wheel-text-selected-color` 淡蓝 24rpx/500，**无底色、无边框、无线框** |
| **active 触摸** | touchstart | 整条 `opacity: 0.92`；未选中文字 `--wheel-text-active`（45% 黑/白）；选中文字保持淡蓝 24rpx/500 **不加深、不增大**，仅 `scale(1.08)` 温和放大（150ms ease-out） |
| **过渡** | 状态切换 | 进入 active 150ms ease-out；手指离开 300ms 恢复 idle |

### 7.2 锚点与位移
- 选中项**恒在第 2 行**（anchorIndex = 1，顶部恒留 1 个分类名空间）；
- 位移公式：`translateY = (1 − idx) × 72rpx`（**不 clamp**）——首类 idx=0 时列表下移 1 行、顶部留空行不贴顶；次类 idx=1 时顶部显示第 1 个分类名；idx≥2 时上移，选中项恒在第 2 行；
- 可视 **6 项**（6 × 72 = 432rpx），超出隐藏。

### 7.3 手势
| 手势 | 行为 |
|------|------|
| touchstart | 激活态启动；记录起始 Y 与基础位移 |
| touchmove | **连续跟手**（位移随手指，非按格跳变）；实时计算索引 → 触发 `change` → 主卡片流即时切换（乐观更新）；索引变化时 `wx.vibrateShort({type:'light'})` 轻震 |
| touchend | `snap` 到最近分类（300ms `cubic-bezier(.4,0,.2,1)` 缓动回锚点）；越界 bounce 回弹；300ms 恢复 idle |
| 边界 | 首/末项继续滑 → 弹性 bounce（最大 `0.25 × 72 = 18rpx`），不切换分类 |
| 热区 | 整条 `128rpx 宽 × 432rpx 高` + 右扩 **32rpx**；条带空白/文字/行间隙均响应，不限于文字命中 |
| 手势隔离 | 组件内 `catchtouch*` 消费，不冒泡到卡片流 WXS；滚轮拖动不触发卡片翻动 |

## 8. 新闻列表项规范

- **行距收窄**：项高由内容撑起（title 28rpx × line-height 1.45 × ≤2 行），项 padding `16rpx 32rpx`、左右 margin `24rpx`；
- **当前阅读项**（正在阅读/刚点击）：标题 `--primary` 主题色高亮，**无底色、无边框、无圆角**（A 方案）；
- **触摸反馈**：`:active` 背景 `--tag-bg`（200ms 过渡），松手即恢复；
- **截断**：最多 2 行，超出省略号；
- **空态**：`filteredNewsList.length === 0` → 居中「暂无新闻」。

## 9. UX 场景（关键用户流程）

| 场景 | 触发 | 流程 | 反馈 |
|------|------|------|------|
| **S1 打开面板** | 首页卡片流左滑 / 入口 | 遮罩淡入 300ms + 面板右滑入 300ms `cubic-bezier(.4,0,.2,1)` | 动画完成后附加 `.done`（transform:none）保证 iOS 滚动稳定 |
| **S2 滚轮切分类** | 触摸滚轮 | idle→active（opacity .35→.92）→ 拖动连续跟手 → 实时 `change` → 列表刷新（乐观，无 loading）→ 松手 snap 第 2 行 + 轻震 → 300ms 恢复 idle | 震动 `light`；卡片流顶部分类标题 120ms 淡入 → 600ms → 120ms 淡出 |
| **S3 点选新闻** | 点击列表项 | `:active` 背景 --tag-bg → 定位主卡片流该条 / 跳详情 | 当前项标题变主题色 |
| **S4 当前阅读项** | 列表渲染 | current 项标题 `--primary` 高亮（无底色） | 主题色文字 |
| **S5 空态** | 分类无新闻 | 列表区居中「暂无新闻」 | 文字 28rpx secondary |
| **S6 关闭面板** | 点遮罩 | 面板右滑出 + 遮罩淡出（300ms） | — |
| **S7 深浅色** | 系统/手动主题切换 | token 自动跟随（.page--dark/.page--light） | 滚轮选中淡蓝 `#007AFF`（浅）/`#0A84FF`（暗） |

## 10. 动效参数汇总

| 动效 | 时长 | 曲线 |
|------|------|------|
| 面板滑入/滑出 | 300ms | `cubic-bezier(0.4, 0, 0.2, 1)` |
| 遮罩淡入/淡出 | 300ms | `ease` |
| wheel idle↔active | 150ms（激活）/ 300ms（恢复） | `ease-out` |
| wheel snap | 300ms | `cubic-bezier(.4, 0, .2, 1)` |
| wheel 选中放大 | 150ms | `ease-out` |
| 列表项触摸背景 | 200ms | `ease` |
| 切分类标题提示 | 120ms 淡入 → 600ms 停留 → 120ms 淡出 | `ease` |

> 全部 ≤ 500ms，符合交互语言标准 §2。

## 11. 深色模式适配

- 全部颜色走 token，深浅色**自动跟随**（无独立暗色代码路径）；
- 滚轮选中淡蓝：浅 `#007AFF` / 暗 `#0A84FF`（`--wheel-text-selected-color`）；

## 13. FE 开发任务要点（确认后建单）
