> **处理路径**：owner 确认设计 → 提 bug 给 FE 落地（PD 无 wxss 修改权限）

## 一、背景与问题

BUG-20260806-004 将全页面顶部导航栏改为 **fixed 定位 + 与原生胶囊对齐**（`top: menuTop` / `height: menuHeight`），并移除 status-bar 占位块。但**内容区未同步预留导航栏高度**，导致：

| 页面 | 内容容器 | 现状顶部预留 | 问题 |
|---|---|---|---|
| detail（阅读页） | `.content`（scroll-view） | `.detail-body` padding-top 32rpx ≈ 16px | **标题顶到屏幕最上方**（owner 真机反馈）|
| favorites（收藏页） | 列表区 | 无预留（sync-bar/filter-bar 前） | 顶部元素被导航栏遮挡 |
| history（历史页） | `.list-scroll` | padding-top 8rpx | 首条列表项贴/被盖 |
| settings（设置页） | `.scroller` | padding-top 6rpx | 设置项贴/被盖 |
| about（关于页） | `.scroller` | 无预留 | 内容贴/被盖 |
| home（首页） | `.fixed-top-bar`（absolute）+ `.card-body`（垂直居中）| 卡片居中 | **不纳入**——卡片垂直居中布局，无顶置问题 |

> **owner 原话**（2026-08-06 10:59）：「UAT-03 这个有问题，现在新闻的标题都直接顶到屏幕最上方了，我的意思是**保持导航栏**，然后新闻正文部分不用再做分割了，但是新闻标题肯定还是要位于导航栏下面合适的位置的。」

---

## 二、设计目标

1. **保持导航栏**：fixed + 胶囊对齐不动（返回按钮 / 主页按钮 / 标题 / 计数 / 进度条位置均不变）；
2. **正文无分割线**：004 已移除 `.detail-divider`，确认保留（标题/元信息与正文直接衔接）；
3. **标题/列表位于导航栏下方合适位置**：内容起始 = 导航栏底部 + 固定呼吸间距。

---

## 三、统一规则

### 3.1 导航栏占位高度

```
nav 占位高度 = menuTop + menuHeight
```

- `menuTop`：胶囊 top（状态栏下缘 + 系统间隙，运行时 `wx.getMenuButtonBoundingClientRect()` 获取，已有）；
- `menuHeight`：胶囊高度（≈32px，已有）。

### 3.2 内容起始位置公式

页面根节点注入 CSS 变量：

```
--nav-offset: (menuTop + menuHeight)px
```

内容容器顶部间距：

```
padding-top: calc(var(--nav-offset) + 呼吸间距)
```

### 3.3 呼吸间距（页面类型差异）

| 页面类型 | 呼吸间距 | 说明 |
|---|---|---|
| detail（阅读页） | **32rpx**（16px） | 标题与导航栏的呼吸感（与 004 前 detail-body 32rpx 一致）|
| favorites / history（列表页） | **16rpx**（8px） | 列表首项与导航栏间距 |
| settings / about（次级页） | **16rpx**（8px） | 与列表页一致 |

### 3.4 实现要点（给 FE）

1. **各页 `onLoad` 已有 `menuTop` / `menuHeight`**（004 已加）→ 需再注入一个 `navOffset = menuTop + menuHeight`（或直接在根节点 style 算好）；
2. **推荐根节点注入变量**：`style="--nav-offset: {{navOffset}}px"`（与 `--font-scale` 注入同模式），wxss 用 `calc(var(--nav-offset) + N rpx)` —— 变量语义化、可随 theme.json 契约扩展；
3. detail 页 `.content` 用 `padding-top` 而非 `margin-top`（margin 塌陷/背景色透底问题更少）；scroll-view 内部建议放在 `.article` 或 `.detail-body` 上（保证骨架屏/错误态不受影响）；
4. **不改动**：nav-bar 本身（fixed/top/height/按钮布局）、正文排版、底部操作栏、进度条位置。

## 四、各页落地明细（验收对照）

| 页面 | 内容容器 | 修改 | 目标效果 |
|---|---|---|---|
| detail | `.content` / `.detail-body` | `padding-top: calc(var(--nav-offset) + 32rpx)` | 标题位于导航栏下方 16px 呼吸间距 |

| history | `.list-scroll` | `padding-top: calc(var(--nav-offset) + 16rpx)` | 首条列表项不被盖 |
| settings | `.scroller` | `padding-top: calc(var(--nav-offset) + 16rpx)` | 设置项不被盖 |
| about | `.scroller` | `padding-top: calc(var(--nav-offset) + 16rpx)` | 内容不被盖 |

> home 页不纳入（卡片垂直居中布局，`card-body` padding-top 100rpx 且内容居中，无顶置问题）。

## 五、验收标准（AC）

- **AC-D09-01**：detail 页标题位于导航栏下方，与导航栏底部的垂直间距 ≈ 32rpx（16px），不重叠、不贴住；
- **AC-D09-02**：favorites/history/settings/about 首屏顶部元素（列表首项/设置项）完整可见，不被导航栏遮挡；
- **AC-D09-03**：正文区无分割线（004 保留确认），标题→元信息→正文直接衔接；
- **AC-D09-04**：导航栏本身无回归（fixed 对齐胶囊、返回/主页按钮位置、进度条并入 nav 底部）；
- **AC-D09-05**：各页面滚动到底部行为不变（底部操作栏/安全区不受影响）；
- **AC-D09-06**：深浅色模式下表现一致（变量注入与主题无关）。
