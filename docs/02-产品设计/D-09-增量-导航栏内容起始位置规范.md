## 一、背景与问题

BUG-20260806-004 将全页面顶部导航栏改为 **fixed 定位 + 与原生胶囊对齐**（`top: menuTop` / `height: menuHeight`），并移除 status-bar 占位块。但**内容区未同步预留导航栏高度**，导致：

| 页面 | 内容容器 | 现状顶部预留 | 问题 |
|---|---|---|---|
| detail（阅读页） | `.content`（scroll-view） | `.detail-body` padding-top 32rpx ≈ 16px | **标题顶到屏幕最上方**（owner 真机反馈）|
| favorites（收藏页） | 列表区 | 无预留（sync-bar/filter-bar 前） | 顶部元素被导航栏遮挡 |
| history（历史页） | `.list-scroll` | padding-top 8rpx | 首条列表项贴/被盖 |
| settings（设置页） | `.scroller` | padding-top 6rpx | 设置项贴/被盖 |
| about（关于页） | `.scroller` | 无预留 | 内容贴/被盖 |
| home（首页） | `.fixed-top-bar`（absolute）+ `.card-body`（垂直居中）| 卡片居中 | 卡片居中无顶置问题；顶部设置按钮需同步呼吸规范 |

> **owner 原话**（2026-08-06 10:59）：「UAT-03 这个有问题，现在新闻的标题都直接顶到屏幕最上方了，我的意思是**保持导航栏**，然后新闻正文部分不用再做分割了，但是新闻标题肯定还是要位于导航栏下面合适的位置的。」
> **owner 追加**（2026-08-06 11:37）：「1）导航栏也需要和胶囊保持一定呼吸空间，但是返回/主页等按钮依然和胶囊中间对齐；2）进度条不需要底色，完全是和当前页面同色。其他确认。」
> **owner 追加**（2026-08-06 11:38）：「注意这个导航栏与正文的高度位置，也需要作为**系统层级的设计**，把其他页面也做统一设计和调整。记得出详细的设计文件给开发。」

## 二、设计目标（v1.1）

1. **系统级统一**：导航栏（含与胶囊的呼吸关系）+ 内容起始位置，作为全页面通用规范（detail / favorites / history / settings / about / home）；
2. **导航栏与胶囊呼吸空间**：导航条带比胶囊略高（上下对称扩展），视觉不与胶囊贴合；但**返回/主页按钮垂直中心始终锚定胶囊中心**；
3. **进度条同色化**：进度条无底槽色（与当前页面同色），仅保留浅蓝进度线本身；
4. **正文无分割线**：004 已移除 `.detail-divider`，确认保留（标题/元信息与正文直接衔接）；
5. **内容起始位置合适**：内容起始 = 导航栏底部 + 固定呼吸间距。

---

## 三、统一规则（v1.1）

### 3.1 导航栏与胶囊：对齐 + 呼吸空间

```
导航条带 top    = menuTop - 12rpx（上呼吸）
导航条带 height = menuHeight + 24rpx（上下各 12rpx 呼吸）
按钮（返回/主页）垂直中心 = 胶囊垂直中心（top:50% translateY(-50%)，不变）
```

- **对齐锚点**：按钮中心 = 胶囊中心（原有约束，保持不变）；
- **呼吸空间**：导航条带上下各扩展 **12rpx（6px）**，与胶囊形成呼吸感（条带不再与胶囊完全贴合）；
- 因条带对称扩展，条带中心 = 胶囊中心 → 条带内垂直居中的按钮中心**自动等于胶囊中心**，无需额外计算；
- 进度条（仅 detail）位于条带底部 → 落在胶囊下缘下方 12rpx，与胶囊有呼吸间距。

### 3.2 进度条（同色化 · 仅 detail）

- **去掉底槽**：`background: transparent`（或 var(--bg-page)，与当前页面同色）——不再绘制 `var(--divider)` 底色长条；
- **仅保留进度线**：`nav-progress-bar` 3rpx 高、`var(--progress)` 浅蓝，宽度随阅读进度变化；
- 进度条仍在导航条带底部（胶囊下缘下 12rpx）。

### 3.3 导航栏占位高度（内容起始基准）

```
nav 占位高度 = (menuTop - 12rpx) + (menuHeight + 24rpx)
            = menuTop + menuHeight + 12rpx
```

- `menuTop`：胶囊 top（状态栏下缘 + 系统间隙，运行时 `wx.getMenuButtonBoundingClientRect()` 获取，已有）；
- `menuHeight`：胶囊高度（≈32px，已有）。

### 3.4 内容起始位置公式

页面根节点注入 CSS 变量：

```
--nav-offset: (menuTop + menuHeight + 6)px   // 6px = 12rpx 下呼吸
```

内容容器顶部间距：

```
padding-top: calc(var(--nav-offset) + 呼吸间距)
```

### 3.5 呼吸间距（页面类型差异）

| 页面类型 | 呼吸间距 | 说明 |
|---|---|---|
| detail（阅读页） | **32rpx**（16px） | 标题与导航栏的呼吸感（与 004 前 detail-body 32rpx 一致）|
| favorites / history（列表页） | **16rpx**（8px） | 列表首项与导航栏间距 |
| settings / about（次级页） | **16rpx**（8px） | 与列表页一致 |

### 3.6 实现要点（给 FE）

1. **各页 `onLoad` 已有 `menuTop` / `menuHeight`**（004 已加）→ 需再注入 `navOffset = menuTop + menuHeight + 6`（含下呼吸 6px）；
2. **推荐根节点注入变量**：`style="--nav-offset: {{navOffset}}px"`（与 `--font-scale` 注入同模式），wxss 用 `calc(var(--nav-offset) + N rpx)` —— 变量语义化、可随 theme.json 契约扩展；
3. **导航条带统一**：`top: calc({{menuTop}}px - 12rpx); height: calc({{menuHeight}}px + 24rpx)`（或注入 `--nav-top` / `--nav-height` 变量）；条带内按钮保持 `top:50% translateY(-50%)` 即锚定胶囊中心；
4. detail 页 `.content` 用 `padding-top` 而非 `margin-top`（margin 塌陷/背景色透底问题更少）；scroll-view 内部建议放在 `.article` 或 `.detail-body` 上（保证骨架屏/错误态不受影响）；
5. **不改动**：正文排版、底部操作栏、底部滑动提示条、各页面业务内容。

## 四、系统级落地明细（v1.1 · 验收对照）

### 4.1 导航条带（全页面统一）

| 元素 | 规则 |
|---|---|
| 导航条带 | `top: menuTop - 12rpx`；`height: menuHeight + 24rpx`（上下各 12rpx 呼吸）|
| 返回/主页按钮（左） | 条带内 `top:50% translateY(-50%)` → **垂直中心 = 胶囊中心** |
| 标题/计数（中） | 条带内垂直居中 |
| 进度条（仅 detail） | 条带底部，**无底槽**（与页面同色），3rpx 浅蓝进度线 |

### 4.2 内容起始位置（各页）

| 页面 | 内容容器 | 修改 | 目标效果 |
|---|---|---|---|
| detail | `.content` / `.detail-body` | `padding-top: calc(var(--nav-offset) + 32rpx)` | 标题位于导航栏下方 16px 呼吸间距 |
| favorites | 列表区（filter-bar 上方或列表容器）| `padding-top: calc(var(--nav-offset) + 16rpx)` | sync-bar/filter-bar/首条不被盖 |
| history | `.list-scroll` | `padding-top: calc(var(--nav-offset) + 16rpx)` | 首条列表项不被盖 |
| settings | `.scroller` | `padding-top: calc(var(--nav-offset) + 16rpx)` | 设置项不被盖 |
| about | `.scroller` | `padding-top: calc(var(--nav-offset) + 16rpx)` | 内容不被盖 |
| home | `.fixed-top-bar` 呼吸同步（条带 + 设置按钮锚定胶囊中心）| 卡片居中不变 | 设置按钮与胶囊呼吸一致，无内容顶置 |

> home 卡片为垂直居中布局，无顶置问题；仅需同步导航条带呼吸规范（设置按钮锚定胶囊中心）。
