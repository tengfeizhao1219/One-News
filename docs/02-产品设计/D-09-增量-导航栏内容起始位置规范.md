## 一、背景与问题

BUG-20260806-004 将全页面顶部导航栏改为 **fixed 定位 + 与原生胶囊对齐**（`top: menuTop` / `height: menuHeight`），并移除 status-bar 占位块。但**内容区未同步预留导航栏高度**，导致：

| 页面 | 内容容器 | 现状顶部预留 | 问题 |
|---|---|---|---|
| detail（阅读页） | `.content`（scroll-view） | `.detail-body` padding-top 32rpx ≈ 16px | **标题顶到屏幕最上方**（owner 真机反馈）|
| favorites（收藏页） | 列表区 | 无预留（sync-bar/filter-bar 前） | 顶部元素被导航栏遮挡 |
| history（历史页） | `.list-scroll` | padding-top 8rpx | 首条列表项贴/被盖 |
| settings（设置页） | `.scroller` | padding-top 6rpx | 设置项贴/被盖 |
| about（关于页） | `.scroller` | 无预留 | 内容贴/被盖 |
| home（首页） | `.fixed-top-bar`（absolute）+ `.card-body`（垂直居中）| 卡片居中 | 卡片居中无顶置问题；顶部设置按钮需同步呼吸规范 |

> **owner 原话**（2026-08-06 10:59）：「UAT-03 这个有问题，现在新闻的标题都直接顶到屏幕最上方了，我的意思是**保持导航栏**，然后新闻正文部分不用再做分割了，但是新闻标题肯定还是要位于导航栏下面合适的位置的。」
> **owner 追加**（2026-08-06 11:37）：「1）导航栏也需要和胶囊保持一定呼吸空间，但是返回/主页等按钮依然和胶囊中间对齐；2）进度条不需要底色，完全是和当前页面同色。其他确认。」
> **owner 追加**（2026-08-06 11:38）：「注意这个导航栏与正文的高度位置，也需要作为**系统层级的设计**，把其他页面也做统一设计和调整。记得出详细的设计文件给开发。」

## 二、设计目标（v1.1）

1. **系统级统一**：导航栏（含与胶囊的呼吸关系）+ 内容起始位置，作为全页面通用规范（detail / favorites / history / settings / about / home）；
2. **导航栏与胶囊呼吸空间**：导航条带比胶囊略高（上下对称扩展），视觉不与胶囊贴合；但**返回/主页按钮垂直中心始终锚定胶囊中心**；
3. **进度条同色化**：进度条无底槽色（与当前页面同色），仅保留浅蓝进度线本身；
4. **正文无分割线**：004 已移除 `.detail-divider`，确认保留（标题/元信息与正文直接衔接）；
5. **内容起始位置合适**：内容起始 = 导航栏底部 + 固定呼吸间距。

## 三、统一规则（v1.1）

### 3.1 导航栏与胶囊：对齐 + 呼吸空间（v1.2：仅下扩展）

```
导航条带 top    = menuTop                  （无上呼吸，与胶囊顶部对齐）
导航条带 height = menuHeight + 24rpx       （仅向下扩展 24rpx = 12px）
按钮（返回/主页）顶部 = menuTop + menuHeight/2 - 32rpx    → 中心 = 胶囊中心（按钮高 64rpx）
进度条          = 导航条带底部            → 胶囊下缘下 12px（24rpx）
```

- **对齐锚点**：按钮中心 = 胶囊中心（owner 硬约束，保留不变）；
- **呼吸空间**（v1.2）：导航条带**仅向下扩展 12px（24rpx）**——上无呼吸，胶囊与条带顶部对齐；下 12px 进度条与胶囊形成视觉呼吸（v1.1 上下各 6px 在视觉上太近，v1.2 加大）；
- **按钮锚定策略变更**：v1.1 用条带对称扩展（条带中心=胶囊中心 → 按钮 top:50% 不变）；v1.2 用 **explicit 锚定**——按钮 `top = menuTop + menuHeight/2 - 32rpx`（按钮高 64rpx，中心 = 胶囊中心），不依赖条带内居中；
- 进度条（仅 detail）位于条带底部 → 落在胶囊下缘下 12px，与胶囊有清晰呼吸间距。

### 3.2 进度条（同色化 · 仅 detail）

- **去掉底槽**：`background: transparent`（与当前页面同色）——不再绘制 `var(--divider)` 底色长条；
- **仅保留进度线**：`nav-progress-bar` 3rpx 高、`var(--progress)` 浅蓝，宽度随阅读进度变化；
- 进度条位于条带底部 = **胶囊下缘下 12px**（v1.2 加大呼吸）。

### 3.3 导航栏占位高度（v1.2）

```
nav 占位高度 = menuTop + (menuHeight + 24rpx)
            = menuTop + menuHeight + 24rpx
```

- 含条带下呼吸 24rpx（12px）。

### 3.4 内容起始位置公式

页面根节点注入 CSS 变量：

```
--nav-offset: (menuTop + menuHeight + 12)px   // 12px = 24rpx 条带下呼吸
```

内容容器顶部间距：

```
padding-top: calc(var(--nav-offset) + 呼吸间距)
```

### 3.5 呼吸间距（页面类型差异 · v1.2 紧凑）

| 页面类型 | 呼吸间距 | 说明 |
|---|---|---|
| detail（阅读页） | **12rpx**（6px） | 标题与导航栏的紧凑呼吸感（v1.2 从 32rpx 收紧）|
| favorites / history（列表页） | **8rpx**（4px） | 列表首项与导航栏间距（v1.2 从 16rpx 收紧）|
| settings / about（次级页） | **8rpx**（4px） | 与列表页一致 |

### 3.6 实现要点（给 FE）

1. **各页 `onLoad` 已有 `menuTop` / `menuHeight`**（004 已加）→ 需再注入 `navOffset = menuTop + menuHeight + 12`（含 12px 条带下呼吸）；
2. **推荐根节点注入变量**：`style="--nav-offset: {{navOffset}}px"`（与 `--font-scale` 注入同模式），wxss 用 `calc(var(--nav-offset) + N rpx)` —— 变量语义化、可随 theme.json 契约扩展；
3. **导航条带 + 进度条 v1.2**：
   - nav-bar：`top: {{menuTop}}px; height: calc({{menuHeight}}px + 24rpx)`（仅下扩展 24rpx，上无呼吸）；
   - 返回/主页按钮：**explicit 锚定胶囊中心**——`top: calc({{menuTop}}px + {{menuHeight}}px / 2 - 32rpx)`（按钮高 64rpx，中心 = 胶囊中心），**不再依赖条带内 top:50%**；
   - 进度条：`bottom: 0`（条带底部）→ 胶囊下缘下 12px；`background: transparent`（无底槽）。
4. detail 页 `.content` 用 `padding-top` 而非 `margin-top`（margin 塌陷/背景色透底问题更少）；scroll-view 内部建议放在 `.article` 或 `.detail-body` 上（保证骨架屏/错误态不受影响）；
5. **不改动**：正文排版、底部操作栏、底部滑动提示条、各页面业务内容。

## 四、系统级落地明细（v1.2 · 验收对照）

### 4.1 导航条带（全页面统一 · v1.2）

| 元素 | 规则 |
|---|---|
| 导航条带 | `top: menuTop`（无上呼吸）；`height: calc(menuHeight + 24rpx)`（仅下呼吸 24rpx = 12px）|
| 返回/主页按钮（左） | **explicit 锚定胶囊中心**：`top = calc({{menuTop}}px + {{menuHeight}}px / 2 - 32rpx)` → 按钮高 64rpx，中心 = 胶囊中心 |
| 标题/计数（中） | 条带内垂直居中 |
| 进度条（仅 detail） | 条带底部，**无底槽**（与页面同色），3rpx 浅蓝进度线 = 胶囊下 12px |

### 4.2 内容起始位置（各页 · v1.2 紧凑）

| 页面 | 内容容器 | 修改 | 目标效果 |
|---|---|---|---|
| detail | `.content` / `.detail-body` | `padding-top: calc(var(--nav-offset) + 12rpx)` | 标题位于导航栏下方 6px 呼吸间距（紧凑）|
| favorites | 列表区（filter-bar 上方或列表容器）| `padding-top: calc(var(--nav-offset) + 8rpx)` | sync-bar/filter-bar/首条不被盖（紧凑）|
| history | `.list-scroll` | `padding-top: calc(var(--nav-offset) + 8rpx)` | 首条列表项不被盖（紧凑）|
| settings | `.scroller` | `padding-top: calc(var(--nav-offset) + 8rpx)` | 设置项不被盖（紧凑）|
| about | `.scroller` | `padding-top: calc(var(--nav-offset) + 8rpx)` | 内容不被盖（紧凑）|
| home | `.fixed-top-bar` 仅下呼吸同步（设置按钮锚定胶囊中心）| 卡片居中不变 | 设置按钮与胶囊呼吸一致，无内容顶置 |

> home 卡片为垂直居中布局，无顶置问题；仅需同步导航条带呼吸规范（设置按钮锚定胶囊中心）。
