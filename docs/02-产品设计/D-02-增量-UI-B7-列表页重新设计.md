## 2. 设计决策（owner 逐轮拍板）

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 右侧空间（C1） | **滚轮替代导航点** | 滚轮选中项居中本就是位置指示；移除独立 nav-dots；条数进度改顶部细进度条 |
| 分类滚轮位置 | **移入侧边新闻列表页（左侧竖排）** | owner v2：首页暂不需要滚轮展示，放到列表页设计中 |
| 列表项缩略图（C4） | **去除缩略图** | 与浏览记录/收藏列表（owner 已要求去图）保持一致，更极简统一 |
| 列表项元信息 | **仅标题，无来源/时间** | owner v3：节省空间，用户凭兴趣判断是否阅读 |
| 列表页入口 | **左滑手势进入，无按钮** | owner v3：用户滑动即可进入列表页，不需要点击按钮 |

| 分类切换高亮 | **圆角 chip（border + radius）** | owner v3.1：分类切换也用圆角，选中项呈圆角高亮 |
| 分类栏位置（v5） | **顶部锚定（选中项固定容器顶行）** | owner v5：侧边分类整体上移，选中项固定在上方、超界隐藏、滑动滑出，更好操作 |

| 滑动激活态（v5） | **仅 scale(1.15) + 字重 600，无背景/边框/主题色** | owner v5：滑动时不做高亮，用轻微放大表示选择位 |
| 阅读项高亮（v5） | **B 方案：淡色底 + 标题主题色，无边框** | owner v5：当前高亮太显眼，换轻一点 |

| 锚定位置（v5.1） | **选中项固定第二行，上方保留前一个分类名** | owner v5.1：固定位置偏高，上方再保留一个分类名称空间 |

| dock / 面板浮层 | **毛玻璃透明度 .92 → .78** | owner v3.1：当前太重太透，需更通透 |

## 3. 设计规范（精确值）

### 3.1 侧边栏新闻列表页（左滑进入 + 极简列表 + 轻高亮）

| 属性 | 规格 |
|------|------|
| 入口 | **左滑手势直接滑出**（在首页卡片流区域左滑 → 面板跟手位移，滑过 60px 阈值 → 打开；右滑关闭）。**无按钮入口**（owner v3：用户滑动即可，不需点击）。**v5.3-final 移除面板右上角 × 关闭按钮**（owner：右滑关闭即可，不需要关闭按钮） |
| 面板 | 从右滑入，宽 90%，`transform: translateX(100%) → 0`，`300ms cubic-bezier(.4,0,.2,1)`；遮罩 `var(--overlay)` 渐显 |
| 头部 | 「今日新闻」+ 副标题「当前分类 · N 条」 |
| 分类切换 | 列表页**左侧顶部锚定分类栏**（6 分类 + 收藏），同 RQ-15/RQ-15-D v2 交互规范 |
| 列表项 | **仅标题**（14px weight 600，2 行截断），**无来源、时间**（owner v3：节省空间，凭兴趣判断）。**v5.3-final 字号 15px→14px**（owner：字号再小一档） |
| 列表项行距（v5.3） | **行间距收窄**：列表项 `padding: 8px 16px`（原 13px）、项间距 `margin: 0 12px 0`（原 margin-bottom 2px）——每项垂直节省约 12px，可视区同屏多展示 1~2 条（owner v5.3：缩小行间距，节省空间展示更多新闻列表） |
| 高亮（v5.1） | 当前阅读项：**A 方案最轻高亮** —— **仅标题文字 `var(--primary)`** weight 600，**无底色、无边框、无圆角**（owner v5.1：高亮还是太重，只保留字体颜色） |
| 点击 | 定位卡片流到该条并关闭列表页 |

### 3.2 分类切换 · 左侧顶部锚定分类栏（v5 范式 + v5.1/v5.2 细化，替代原居中滚轮）

> **v5 变更**：owner 2026-08-04 指示「选中项固定在上方、超界隐藏、滑动滑出；滑动选择时不做高亮、用轻微放大表示选择位；去掉分类间分割线」。原 RQ-15-D「选中项垂直居中」范式废弃，升级为**顶部锚定列表范式**。
> **v5.1 变更**：owner 2026-08-04 「侧边分类不需要蓝色线框；固定位置偏高，选中分类上方保留一个分类名称空间」→ idle 选中项去线框；选中项固定容器**第二行**（上方显示前一个分类名）。
> **v5.2 变更**：owner 2026-08-04 「选中的分类位置固定，其他分类根据滑动上下滚动；滚动到固定位时有放大效果；字体颜色不需要加深，保持当前选中态颜色；字体也不需要太大」→ 放大回调至 **scale(1.08)**、激活态颜色**保持选中态 `.5` 不加深**、字号**保持 24rpx 不增大**。
> **v5.3-final 变更**：owner 2026-08-04 「选中分类用淡淡的蓝色高亮一下，不让在夜晚模式下看不清；一定要确保当前分类固定在顶部第二行不随滚动移动」→ idle 选中项加 **淡蓝底色 `var(--highlight-bg)`**（浅色 `rgba(0,122,255,.06)` / 暗色 `rgba(10,132,255,.10)`）保证暗色模式可见；**确认固定位为第二行不可移动**。

| 属性 | 规格 |
|------|------|
| 位置 | 列表页内**左侧**，顶部锚定：容器 `top = panel-header 高 + 8rpx`；**不再垂直居中** |
| 可视区 | 高 = 6 × 项高（项高 36px），`overflow: hidden`；**默认 6 分类可视**（推荐/科技/国际/体育/生活/三农），**收藏在底部隐藏，下滑 1 次滑出**（owner v5：超界隐藏、滑动滑出） |
| 内容 | 7 项 = 6 分类 + 收藏；收藏标签为纯文字「收藏」（v4 去除 ❤️ emoji） |
| 分割线 | **删除** `--wheel-divider`（owner v5：选中项已有高亮，无需分割线）；项间距 36px 补偿视觉引导 |
| 固定位（v5.2） | **选中分类位置固定**（第二行锚定，非顶行）：`translateY = max(0, -(curCat-1) × 36px)`；**其他分类围绕固定位上下滚动**（owner v5.2：选中的位置固定，其他分类根据滑动上下滚动） |
| 默认态（idle） | 整体 `opacity .35`；非选中 `rgba(0,0,0,.12)` 10rpx；**选中项字体颜色 `rgba(0,0,0,.5)` + 12rpx weight 500 + 淡蓝底色 `var(--highlight-bg)`**（v5.3-final：淡蓝色高亮保证夜晚可见，浅色 `rgba(0,122,255,.06)` / 暗色 `rgba(10,132,255,.10)`）；无线框 |
| 激活态（active·触摸·v5.2） | `opacity .92`；选中项仅 **`transform: scale(1.08)` 温和放大**（v5.2 回调，原 1.15 太大）；**字体颜色保持选中态 `rgba(0,0,0,.5)` 不加深、字号保持 24rpx 不增大**（v5.2：颜色不需要加深、字体不需要太大）；无背景、无边框；其余项 `opacity .35` |
| 交互 | 上下拖拽实时切分类（不等松手）+ 松手 snap 吸附（第二行锚定）+ `wx.vibrateShort({type:'light'})`；惯性最多跨 3 类后减速；首/末类继续滑 bounce |
| 过渡 | 激活态 `150ms ease-out`（快速跟手）；离开后 300ms 恢复默认态 |

### 3.3 导航点 → 顶部细进度条（替代 nav-dots，解决 C1）

| 属性 | 规格 |
|------|------|
| 位置 | 顶部栏居中，与分类名水平排列 |
| 形态 | 细进度条（`64rpx × 3rpx` 圆角），填充宽度 = `(当前条序号 / 分类内总条数) × 100%` |
| 联动 | 卡片流上滑切下一条 → 进度条实时变化；替代原右侧竖排导航点 |

### 3.4 ⚙ 升级为方案 F dock 菜单（解决 C3）

- ⚙ 浮动按钮（右下角，圆形）单击 → 向上弹出 dock 浮层：浏览记录 / 我的收藏 / 设置 / 扩展位
- 原「字体/暗色设置」收入 dock 菜单内，不再有独立设置按钮
- 浮层容器（dock + 面板）毛玻璃 `blur(20px)`；**透明度 v3.1 由 `.92` 降为 `.78`**（亮/暗双模式同步），更通透不压内容
- Mac dock 栈动效、再点/空白收起（同 UI-B6）

> ⚠️ **theme.json 同步待办**：当前 `theme.json` 中 `--setting-panel-bg` 仍为 `rgba(250,249,247,0.92)` / `rgba(13,13,13,0.92)`。本设计 v3.1 已将其降为 `.78`，落地时须同步更新 `theme.json` 的 `--setting-panel-bg` 与 dock 容器背景，否则真机浮层会偏重。

### 3.5 底部固定滑动提示（v3 新增）

| 属性 | 规格 |
|------|------|
| 位置 | 首页卡片流底部 + 详情页底部，各一条 `position: absolute; bottom: 0` |
| 内容 | ⇅ 符号 + 「上滑阅读下一条」文字（9px，opacity .45） |
| 背景 | 渐变透明→页面底色（`linear-gradient(transparent, var(--bg-card) 40%)`），不遮挡内容 |
| 行为 | 纯提示，不响应点击，不随内容滚动 |

### 3.6 图标统一规范（v4 新增，独立文档）

- 全部图标统一为**描边式（stroke）线性图标**，禁止 emoji、禁止填充式（fill）图标。
- 全局 token：`--icon-stroke: 2`；`fill: none`；`stroke-linecap: round`；`stroke-linejoin: round`。
- 颜色跟随主题 token（亮/暗双模式），不硬编码。
- 完整图标清单、SVG path、尺寸、颜色 token 见 **`D-02-增量-UI-B7-图标规范.md`**，与 `docs/showcase/ui-b7-list-redesign.html` 1:1 一致，供前端直接复用。

### 3.7 空间布局协调（v3 修订）

- 首页：**仅卡片流 + 顶部分类名 + 底部固定提示条 + ⚙ dock 菜单**，无按钮、无滚轮
- 列表页（左滑进入）：左侧滚轮 + 右侧极简标题列表（圆角高亮）
- 右下：⚙ 单一入口（方案 F dock）
- 详情页：正文 + 底部固定提示条
