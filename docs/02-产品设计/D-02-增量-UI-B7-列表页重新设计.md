## 1. 现状问题（owner 指示的调研结论）

| # | 问题 | 说明 |
|----|------|------|
| P1 | 分类切换路径长 | 现状：左滑开面板 → 顶部横向 Tab 找分类 → 点击 → 关闭（4 步），单手拇指够不到顶部 Tab（RQ-15 痛点） |

| P3 | ⚙ 双重角色 | 现状 ⚙ = 设置按钮；方案 F 中 ⚙ = 更多功能 dock 菜单，需统一 |
| P4 | 顶部栏空缺 | `fixed-top-bar` 近乎空白，未承载分类名/进度（RQ-15 已要求顶部显示分类名） |
| P5 | 列表页与滚轮语义未明 | 滚轮切分类时，侧边栏「今日新闻」列表是否实时跟随？列表项缩略图是否去除？ |

## 2. 设计决策（owner 逐轮拍板）

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 右侧空间（C1） | **滚轮替代导航点** | 滚轮选中项居中本就是位置指示；移除独立 nav-dots；条数进度改顶部细进度条 |
| 分类滚轮位置 | **移入侧边新闻列表页（左侧竖排）** | owner v2：首页暂不需要滚轮展示，放到列表页设计中 |
| 列表项缩略图（C4） | **去除缩略图** | 与浏览记录/收藏列表（owner 已要求去图）保持一致，更极简统一 |
| 列表项元信息 | **仅标题，无来源/时间** | owner v3：节省空间，用户凭兴趣判断是否阅读 |
| 列表页入口 | **左滑手势进入，无按钮** | owner v3：用户滑动即可进入列表页，不需要点击按钮 |
| 高亮样式 | **圆角边框（border-radius 10px）** | owner v3：直角太锋利，统一圆角 |
| 分类切换高亮 | **圆角 chip（border + radius）** | owner v3.1：分类切换也用圆角，选中项呈圆角高亮 |
| 滑动提示 | **固定在屏幕底部** | owner v3：首页卡片流和详情页底部各固定一条提示条 |
| dock / 面板浮层 | **毛玻璃透明度 .92 → .78** | owner v3.1：当前太重太透，需更通透 |
| 图标 | **统一描边式（stroke）SVG，去 emoji** | owner v4：图标需设计好、与 demo 完全一致 |

## 3. 设计规范（精确值）

### 3.1 侧边栏新闻列表页（左滑进入 + 极简列表 + 圆角高亮）

| 属性 | 规格 |
|------|------|
| 入口 | **左滑手势直接滑出**（在首页卡片流区域左滑 → 面板跟手位移，滑过 60px 阈值 → 打开；右滑或点 × 关闭）。**无按钮入口**（owner v3：用户滑动即可，不需点击） |
| 面板 | 从右滑入，宽 90%，`transform: translateX(100%) → 0`，`300ms cubic-bezier(.4,0,.2,1)`；遮罩 `var(--overlay)` 渐显 |
| 头部 | 「今日新闻」+ 副标题「当前分类 · N 条」 |
| 分类切换 | 列表页**左侧竖排滚轮**（6 分类 + 收藏），同 RQ-15/RQ-15-D 交互规范 |
| 列表项 | **仅标题**（15px weight 600，2 行截断），**无来源、时间**（owner v3：节省空间，凭兴趣判断） |
| 高亮 | 当前阅读项：**圆角边框** `border-radius: 10px` + `border: 1px solid var(--primary)` + 淡色底 `rgba(0,122,255,.07)`（暗色 `rgba(10,132,255,.1)`），**不用直角 border-left**（owner v3：直角太锋利） |
| 点击 | 定位卡片流到该条并关闭列表页 |

### 3.2 分类切换 · 左侧垂直滚轮（采纳 RQ-15 + RQ-15-D，1:1 还原）

| 属性 | 规格 |
|------|------|
| 位置 | 列表页内**左侧**，竖排，与列表等高；收藏上方 `1px` 分割线 `opacity .2` |
| 内容 | 6 分类（推荐/科技/国际/体育/生活/三农）+ 收藏；收藏标签为纯文字「收藏」（v4 去除 ❤️ emoji） |
| 默认态（idle） | 整体 `opacity .35`；非选中 `rgba(0,0,0,.12)` 10rpx；选中 `rgba(0,0,0,.5)` 12rpx weight 500；选中项固定滚轮垂直居中 |
| 激活态（active·触摸） | `opacity .92`；毛玻璃背景 `rgba(255,255,255,.7)+blur(8px)`（暗色 `rgba(30,30,30,.85)`）；选中项主题色 weight 600 14rpx；选中项上下 `1px` 指示线 |
| 选中项圆角高亮（v3.1） | 选中项呈**圆角 chip**：`border: 1px solid var(--primary)` + `border-radius: var(--radius)`（10px）+ `padding: 0 8px` + 淡色底，与全局圆角语言一致 |
| 交互 | 上下拖拽实时切分类（不等松手）+ 松手 snap 吸附 + `wx.vibrateShort({type:'light'})`；惯性最多跨 3 类后减速；首/末类继续滑 bounce |
| 过渡 | idle↔active `300ms ease-out`；离开后 300ms 恢复默认态 |

### 3.3 导航点 → 顶部细进度条（替代 nav-dots，解决 C1）

| 属性 | 规格 |
|------|------|
| 位置 | 顶部栏居中，与分类名水平排列 |
| 形态 | 细进度条（`64rpx × 3rpx` 圆角），填充宽度 = `(当前条序号 / 分类内总条数) × 100%` |
| 联动 | 卡片流上滑切下一条 → 进度条实时变化；替代原右侧竖排导航点 |

### 3.4 ⚙ 升级为方案 F dock 菜单（解决 C3）

- ⚙ 浮动按钮（右下角，圆形）单击 → 向上弹出 dock 浮层：浏览记录 / 我的收藏 / 设置 / 扩展位
- 原「字体/暗色设置」收入 dock 菜单内，不再有独立设置按钮
- 浮层容器（dock + 面板）毛玻璃 `blur(20px)`；**透明度 v3.1 由 `.92` 降为 `.78`**（亮/暗双模式同步），更通透不压内容
- Mac dock 栈动效、再点/空白收起（同 UI-B6）

> ⚠️ **theme.json 同步待办**：当前 `theme.json` 中 `--setting-panel-bg` 仍为 `rgba(250,249,247,0.92)` / `rgba(13,13,13,0.92)`。本设计 v3.1 已将其降为 `.78`，落地时须同步更新 `theme.json` 的 `--setting-panel-bg` 与 dock 容器背景，否则真机浮层会偏重。

### 3.5 底部固定滑动提示（v3 新增）

| 属性 | 规格 |
|------|------|
| 位置 | 首页卡片流底部 + 详情页底部，各一条 `position: absolute; bottom: 0` |
| 内容 | ⇅ 符号 + 「上滑阅读下一条」文字（9px，opacity .45） |
| 背景 | 渐变透明→页面底色（`linear-gradient(transparent, var(--bg-card) 40%)`），不遮挡内容 |
| 行为 | 纯提示，不响应点击，不随内容滚动 |

### 3.6 图标统一规范（v4 新增，独立文档）

- 全部图标统一为**描边式（stroke）线性图标**，禁止 emoji、禁止填充式（fill）图标。
- 全局 token：`--icon-stroke: 2`；`fill: none`；`stroke-linecap: round`；`stroke-linejoin: round`。
- 颜色跟随主题 token（亮/暗双模式），不硬编码。
- 完整图标清单、SVG path、尺寸、颜色 token 见 **`D-02-增量-UI-B7-图标规范.md`**，与 `docs/showcase/ui-b7-list-redesign.html` 1:1 一致，供前端直接复用。

### 3.7 空间布局协调（v3 修订）

- 首页：**仅卡片流 + 顶部分类名 + 底部固定提示条 + ⚙ dock 菜单**，无按钮、无滚轮
- 列表页（左滑进入）：左侧滚轮 + 右侧极简标题列表（圆角高亮）
- 右下：⚙ 单一入口（方案 F dock）
- 详情页：正文 + 底部固定提示条
