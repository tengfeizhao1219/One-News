## 1. 现状问题（owner 指示的调研结论）

| # | 问题 | 说明 |
|----|------|------|
| P1 | 分类切换路径长 | 现状：左滑开面板 → 顶部横向 Tab 找分类 → 点击 → 关闭（4 步），单手拇指够不到顶部 Tab（RQ-15 痛点） |
| P2 | 右侧空间冲突 | RQ-15 滚轮（右缘 8~96rpx）与现有 nav-dots（right 28rpx 竖排）**直接重叠**，滚轮激活毛玻璃会盖住导航点；二者均为"位置/切换"语义，功能重叠 |
| P3 | ⚙ 双重角色 | 现状 ⚙ = 设置按钮；方案 F 中 ⚙ = 更多功能 dock 菜单，需统一 |
| P4 | 顶部栏空缺 | `fixed-top-bar` 近乎空白，未承载分类名/进度（RQ-15 已要求顶部显示分类名） |
| P5 | 列表页与滚轮语义未明 | 滚轮切分类时，侧边栏「今日新闻」列表是否实时跟随？列表项缩略图是否去除？ |

---

## 2. 设计决策（owner 2026-08-04 逐轮拍板）

| 决策项 | 选择 | 理由 |
|--------|------|------|
| 右侧空间（C1） | **滚轮替代导航点** | 滚轮选中项居中本就是位置指示，滚轮项即导航锚点；移除独立 nav-dots；条数进度改顶部细进度条 |
| 列表项缩略图（C4） | **去除缩略图** | 与浏览记录/收藏列表（owner 已要求去图）保持一致，更极简统一 |
| 列表项元信息 | **仅标题，无来源/时间** | owner 2026-08-04 反馈：节省空间，用户凭兴趣判断是否阅读 |
| 列表页入口 | **左滑手势进入，无按钮** | owner 2026-08-04 反馈：用户滑动即可进入列表页，不需要点击按钮 |
| 高亮样式 | **圆角边框（border-radius 10px）** | owner 2026-08-04 反馈：直角太锋利，统一圆角 |
| 滑动提示 | **固定在屏幕底部** | owner 2026-08-04 反馈：首页卡片流和详情页底部各固定一条提示条 |

## 3. 设计规范（精确值）

### 3.1 分类切换 · 右侧垂直滚轮（采纳 RQ-15 + RQ-15-D，1:1 还原）

| 属性 | 规格 |
|------|------|
| 位置 | 屏幕右侧，距右缘 `8rpx`，宽 `88rpx`，与卡片流等高 |
| 内容 | 6 分类（推荐/科技/国际/体育/生活/三农）+ ❤️收藏；收藏上方 `1px` 分割线 `opacity .2` |
| 默认态（idle） | 整体 `opacity .35`；非选中 `rgba(0,0,0,.12)` 20rpx；选中 `rgba(0,0,0,.5)` 24rpx weight 500；选中项固定滚轮垂直居中 |
| 激活态（active·触摸） | `opacity .9`；毛玻璃背景 `rgba(255,255,255,.7)+blur(8px)`（暗色 `rgba(30,30,30,.85)`）；选中项主题色 `weight 600` 28rpx；选中项上下 `1px` 指示线 |
| 交互 | 上下拖拽实时切分类（不等松手）+ 松手 snap 吸附 + `wx.vibrateShort({type:'light'})`；惯性最多跨 3 类后减速；首/末类继续滑 bounce |
| 过渡 | idle↔active `300ms ease-out`；离开后 300ms 恢复默认态 |
| 标题 | 卡片流顶部居中显示当前分类名（RQ-15-F05），26rpx weight 500 主题色 opacity .7/.8，切换 200ms 淡入 |

### 3.2 导航点 → 顶部细进度条（替代 nav-dots，解决 C1）

| 属性 | 规格 |
|------|------|
| 位置 | 顶部栏右侧，与分类名水平排列 |
| 形态 | 细进度条（`64rpx × 3rpx` 圆角），填充宽度 = `(当前条序号 / 分类内总条数) × 100%` |
| 联动 | 卡片流上滑切下一条 → 进度条实时变化；替代原右侧竖排导航点 |

### 3.3 ⚙ 升级为方案 F dock 菜单（解决 C3）

- ⚙ 浮动按钮（右下角）单击 → 向上弹出 dock 浮层：🕐 浏览记录 / ♥ 我的收藏 / ⚙ 设置 / ＋ 扩展位
- 原「字体/暗色设置」收入 dock 菜单内，不再有独立设置按钮
- 毛玻璃 `blur(20px)`、Mac dock 栈动效、再点/空白收起（同 UI-B6）

### 3.4 侧边栏列表页重设计（v3 修订：左滑进入 + 极简列表 + 圆角高亮）

| 属性 | 规格 |
|------|------|
| 入口 | **左滑手势直接滑出**（在首页卡片流区域左滑 → 面板跟手位移，滑过 60px 阈值 → 打开；右滑或点 × 关闭）。**无按钮入口**（owner：用户滑动即可，不需点击） |
| 头部 | 「今日新闻」+ 副标题「当前分类 · N 条」 |
| 分类切换 | 列表页左侧竖排滚轮（6 分类 + ❤️收藏），同 RQ-15/RQ-15-D 交互规范 |
| 列表项 | **仅标题**（15px weight 600，2 行截断），**无来源、时间**（owner：节省空间，凭兴趣判断） |
| 高亮 | 当前阅读项：**圆角边框** `border-radius: 10px` + `border: 1px solid var(--primary)` + 淡色底 `rgba(0,122,255,.07)`，**不用直角 border-left**（owner：直角太锋利） |
| 点击 | 定位卡片流到该条并关闭列表页 |

### 3.5 底部固定滑动提示（v3 新增）

| 属性 | 规格 |
|------|------|
| 位置 | 首页卡片流底部 + 详情页底部，各一条 `position: absolute; bottom: 0` |
| 内容 | ⇅ 图标 + 「上滑阅读下一条」文字（9px，opacity .45） |
| 背景 | 渐变透明→页面底色（`linear-gradient(transparent, var(--bg-card) 40%)`），不遮挡内容 |
| 行为 | 纯提示，不响应点击，不随内容滚动

### 3.6 空间布局协调（v3 修订）

- 首页：**仅卡片流 + 顶部分类名 + 底部固定提示条 + ⚙ dock 菜单**，无按钮、无滚轮
- 列表页（左滑进入）：左侧滚轮 + 右侧极简标题列表（圆角高亮）
- 右下：⚙ 单一入口（方案 F dock）
- 详情页：正文 + 底部固定提示条
