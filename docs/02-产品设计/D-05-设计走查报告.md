## 二、问题清单

### 🔴 阻断（1 项）

#### #1 🔴 分享占位图有时序竞态：300ms 内分享则无图

- **位置**：`detail.js:366-387` `_pregenPlaceholder()` + `onShareAppMessage:393`
- **现象**：Canvas 预生成有 300ms `setTimeout` 延迟。若用户在页面加载后 300ms 内点击分享，`_placeholderCache === null`，消息卡片无封面图（仅靠 `news.picUrl` 兜底——无图新闻就完全没有）。
- **影响**：快手用户（秒开秒分享）命中率约 5-10%。无封面图的消息卡片视觉品质显著下降，不符合 D-03 §四规范。
- **建议**：将预生成时机提前到 `onLoad` 时同步触发（不等引擎初始化），同时为无缓存情况提供同步兜底：在 `onShareAppMessage` 中若 `picUrl` 和 `_placeholderCache` 均为空，返回一个内置的纯色 dataURL（1×1 分类色像素拉伸，微信可接受）。
- **严重度**：🔴 阻断 — 影响所有无图新闻的分享体验

### 🟡 需修复（3 项）

#### #2 🟡 `.nav-back` 字号未参与 `--font-scale` 缩放

- **位置**：`detail.wxss:109` → `font-size: 30rpx`
- **D-03 / A-12c 要求**：`calc(30rpx * var(--font-scale))`
- **影响**：大字号用户阅读正文时，「← 返回」文字相对于正文明显偏小，视觉比例失调
- **严重度**：🟡 中等 — 不影响功能

#### #3 🟡 `.nav-position` 字号未参与 `--font-scale` 缩放

- **位置**：`detail.wxss:124` → `font-size: 26rpx`
- **D-03 / A-12c 要求**：`calc(26rpx * var(--font-scale))`
- **影响**：同 #2，进度指示在大字号模式下偏小
- **严重度**：🟡 中等 — 同 #2 一并修复即可

#### #4 🟡 底部操作栏点击热区不足 88rpx

- **位置**：`detail.wxss:252` → `padding: 20rpx 0`，图标 44rpx → 热区 = 44 + 20 + 20 = **84rpx**
- **D-03 规格**：≥ 88rpx（微信无障碍建议）
- **影响**：差 4rpx（≈1px），实际可点区域接近但未达标。对拇指操作几乎无感知差异，但规范层面不严谨。
- **建议**：`padding: 22rpx 0` → 热区 = 44 + 22 + 22 = 88rpx ✅
- **严重度**：🟡 中等 — 建议改但不紧急

### 🟢 建议优化（4 项）

#### #5 🟢 首页 3 个非核心文字未参与 `--font-scale`

- **位置**：`.guide-overlay` (26rpx), `.state-message` (28rpx), `.state-retry` (28rpx)
- **A-12c 清单**：列为需要改造的选择器
- **影响**：引导遮罩和错误状态页的大字需求极低（这些是瞬时/低频 UI），不改无实质影响
- **严重度**：🟢 低 — 可改可不改

#### #6 🟢 tier 3 首页截断：card-title 2 行 vs 规范 3 行

- **位置**：`home.wxss:546-551` → `[data-font-scale="3"] .card-title { -webkit-line-clamp: 2 }`
- **D-03 规格**：标题 3 行
- **实际**：前端实现为 2 行——可能是 UX-FIX04 时交互设计师基于真机测试做的判断（tier 3 ×1.5 时 2 行约 117rpx 已足够覆盖大多数标题）
- **严重度**：🟢 低 — 建议确认：若是有意为之，更新 D-03 规范文档记录即可

#### #7 🟢 `app.wxss` 暗色 `!important` 硬编码未清理

- **位置**：`app.wxss:12-42`
- **A-03 自查遗留 V-6**：双机制并存（theme.json 变量 + @media !important）
- `.swipe-hint` 暗色 `#666666` 应改为 `var(--text-secondary)`
- **严重度**：🟢 低 — 已标记，不影响功能，阶段四联调时处理

#### #8 🟢 闪烁条 `margin: 0 auto` 依赖父容器为 flex

- **位置**：`detail.wxss:56` → `.category-flash { margin: 0 auto }`
- **现象**：若父容器（nav-bar）非 flex 布局，`margin: 0 auto` 不会居中
- **实际**：nav-bar 为 `display: flex`，居中正常
- **严重度**：🟢 低 — 当前正常，仅防御性提醒
