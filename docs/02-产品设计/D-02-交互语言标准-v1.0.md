# 一页 One-News 交互语言标准 v1.0

> **定位**：面向「设计师 ↔ 开发者」的交互协作宪法，覆盖手势、动画、反馈、状态、层级、布局六大体系。
> **原则**：极致简化 · 即触即达 · 优雅降级 · 先标准后例外
> **生效范围**：所有现有页面及未来新增页面
> **最后更新**：2025-01-22

---

## §0. 核心设计哲学

| 原则 | 内涵 | 反模式 |
|------|------|--------|
| **少即是多** | 每个页面只做一件事；每个手势只对应一个结果 | 一页多态、手势重载 |
| **即触即达** | 操作 → 反馈 ≤ 300ms；动画不阻塞交互 | 等动画播完才能点 |
| **优雅降级** | 任何数据缺失都不崩 UI；空/错/loading 三态必现 | 白屏、空 `<view>`、静默失败 |
| **先标准后例外** | 新交互先查本标准，标准不覆盖才允许例外 | 每个页面自己发明一套手势 |

## §1. 手势语言 (Gesture Language)

> 一页仅使用 **4 种基础手势**，不允许新增手势类型。

### 1.1 手势词汇表

| 手势 | 触发条件 | 作用域 | 行为 |
|------|----------|--------|------|
| **上滑** (Swipe Up) | dy < -50px, \|dy\| > \|dx\| | 首页卡片区 / 详情正文区 | 切换到下一条内容 |
| **下滑** (Swipe Down) | dy > 50px, \|dy\| > \|dx\| | 首页卡片区 / 详情正文区 | 切换到上一条内容 |
| **左滑** (Swipe Left) | dx < -60px, \|dx\| > \|dy\| | 首页全局 | 呼出侧边栏面板 |
| **点击** (Tap) | touchstart→touchend < 300ms, 位移 < 10px | 全局 | 触发目标元素默认行为 |

### 1.2 手势约束

```
❌ 禁止：
  - 长按（Long Press）→ 一页无长按场景
  - 双指捏合（Pinch）→ 字号通过设置面板调整
  - 右滑关闭（Swipe Right to Close）→ 面板通过点击遮罩关闭
  - 手势重载（同一区域同一手势触发两种行为）
  - 边缘手势（Edge Swipe）→ 微信已有返回手势，不冲突

✅ 允许：
  - 详情页正文区垂直滚动手势（scroll-view 原生）
  - 首页卡片区 WXS 跟手拖拽（已实现）
```

### 1.3 手势冲突解决

```
优先级：垂直滑动 > 水平滑动（当 |dy| > |dx|）
       水平滑动 > 垂直滑动（当 |dx| > |dy|）
       
卡片区：WXS 优先处理（touch.wxs），避免 JS setData 延迟
详情区：touchstart/touchend 在 Page 层处理，scroll-view 滚动不受影响
```

## §2. 动画语言 (Animation Language)

### 2.1 动画参数标准

| 用途 | 时长 | 缓动函数 | CSS 实现 |
|------|------|----------|----------|
| 卡片翻页（切换） | 300ms | cubic-bezier(0.25, 0.1, 0.25, 1.0) | `transition` on transform + opacity |
| 卡片回弹（未达阈值） | 200ms | ease (默认) | `transition` on transform + opacity |
| 面板滑入/滑出 | 300ms | cubic-bezier(0.4, 0, 0.2, 1) | `transition` on transform |
| 遮罩淡入/淡出 | 300ms | ease | `transition` on opacity |
| 闪烁条（跨分类） | 200ms | ease（in→out 循环） | CSS `@keyframes flashPulse` |
| 心形收藏动画 | 300ms | ease-out（缩放回弹） | CSS `@keyframes heartBeat` |
| 分类标签切换 | 250ms | ease | `transition: all` |
| Chip 提示出现/消失 | 300ms | ease | `transition: opacity` |
| 引导遮罩 | 4000ms | ease（含延迟） | CSS `@keyframes fadeInOut` |

### 2.2 动画约束

```
❌ 禁止：
  - 动画时长 > 500ms（用户等待焦虑）
  - 阻塞式动画（动画期间禁用交互）
  - 循环动画（除 loading spinner / 骨架屏 shimmer）
  - 同时播放 3 个以上独立动画

✅ 必须：
  - 所有动画使用 CSS transition/animation，禁止 JS setTimeout 模拟动画
  - 翻页动画期间 WXS 层 `isDragging=false` 确保 transition 生效
  - `prefers-reduced-motion` 用户：动画时长 ≤ 100ms
```

### 2.3 详情页翻页动画时序

```
阶段 1（0ms）：       设置 animClass='out-up'，内容开始上移淡出
阶段 2（220ms）：     引擎加载新内容完成，设置 animClass='in-up'
阶段 3（220+30ms）：  移除 animClass，内容归位，动画锁释放
总时长：~250ms
```

## §3. 反馈语言 (Feedback Language)

### 3.1 反馈词汇表

| 反馈类型 | 触发场景 | 视觉形式 | 持续时长 | 位置 |
|----------|----------|----------|----------|------|
| **Toast 成功** | 操作成功（刷新/收藏/取消收藏） | `wx.showToast` icon:success | 2000ms | 屏幕中上 |
| **Toast 提示** | 信息告知（已到底/已加载N条） | `wx.showToast` icon:none | 2000ms | 屏幕中上 |
| **Toast 加载** | 操作进行中（加载更多/刷新中） | `wx.showToast` icon:loading | 800ms | 屏幕中上 |
| **Toast 错误** | 操作失败 | `wx.showToast` icon:none | 2000ms | 屏幕中上 |
| **边界 Chip** | 到达列表首/尾继续滑动 | 底部 Chip 弹入 | 2000ms 自动消失 | 固定底部 180rpx |
| **跨分类闪烁** | 翻页跨越分类边界 | 4rpx 高色条闪烁 | 200ms | 导航栏下方 |
| **网络兜底** | 网络请求失败 | 黄色半透明 Toast | 3000ms 自动消失 | 固定顶部 120rpx |
| **心形动画** | 收藏成功 | ♡→♥ + 缩放回弹 | 300ms | 底部操作栏原位 |
| **按钮反馈** | 任何可点击元素 :active | opacity 0.6~0.7 / scale 0.9 | 即时（跟随按压） | 原位 |

### 3.2 反馈约束

```
❌ 禁止：
  - 静默操作（无任何反馈的状态变更）
  - 重复弹 Toast（前一个未消失又弹新的）
  - Modal 确认框（一页无破坏性操作，不需要）
  - 震动反馈（wx.vibrateShort）→ 微信小程序谨慎使用

✅ 必须：
  - 每个用户操作都有即时视觉反馈（≤100ms）
  - Toast 文案 ≤ 12 个中文字符
  - 边界 Chip 使用 `clearTimeout` 防抖
```

## §4. 状态语言 (State Language)

### 4.1 页面四态模型

每个数据展示页面/组件必须覆盖以下四种状态：

```
┌──────────────────────────────────────────────┐
│                 页面状态机                      │
│                                              │
│   loading ──→ ready ──→ (用户交互)             │
│      │          │                            │
│      ├──→ error │                            │
│      │          │                            │
│      └──→ empty │                            │
│                                              │
│   error ──→ loading (点击重试)                 │
│   empty ──→ loading (下拉刷新)                 │
└──────────────────────────────────────────────┘
```

### 4.2 各状态设计标准

| 状态 | 首页 | 详情页 | 侧边栏列表 | 收藏列表 | 字体面板 |
|------|------|--------|-----------|---------|---------|
| **loading** | 3 卡片骨架屏（shimmer 1.6s） | wx.showLoading + 遮罩 | —（同步读缓存） | —（同步读缓存） | —（纯本地） |
| **ready** | 卡片流 + 导航点 | 正文 + 翻页按钮 | 新闻列表 | 收藏列表 | 4 档选择器 |
| **error** | ⚠ 图标 + 文案 + 重试按钮 | Toast 兜底 + 降级摘要 | Toast 提示 | Toast 提示 | —（不适用） |
| **empty** | 📄 图标 + 文案 + 刷新按钮 | —（不应出现） | "暂无新闻" | ♡ 图标 + 引导文案 | —（不适用） |

### 4.3 空数据三态规则（UX-IMPROVE02 落地）

| 元素 | 有数据 | 无数据 |
|------|--------|--------|
| 卡片标题 | 显示 | 显示 "暂无标题"（灰色） |
| 详情标题 | 显示标题 | 显示 "无标题"（灰色）（`news.title \|\| '无标题'`，BUG-STD-002 已落地） |
| 卡片摘要 | 显示段落 | 显示 "暂无摘要"（灰色） |
| 分类标签 | 显示分类名 | 隐藏 |
| 来源 | 显示来源名 | 隐藏（有 `wx:if` 条件，DEV-STD-04） |
| 时间 | 显示格式时间 | **隐藏整个 time 节点**（含前导 `·`，DEV-STD-05） |
| 原文链接 | 显示「原文↗」行内入口（ActionSheet：复制链接/分享给朋友，UX-SIMPLIFY07） | 隐藏（无 `sourceUrl` 时不显示） |
| 翻页按钮 | **已移除（简化决策，统一手势上下滑翻页）** | — |
| 进度指示 | 显示 "3/20 · tech" | 隐藏 |
| 分享封面 | Canvas 生成 | 微信默认图标 |
| 导航点 | 显示 | 隐藏（newsList.length === 0） |

### 4.4 状态约束

```
❌ 禁止：
  - 空 `<view>` 渲染（没有任何子节点或文本的容器）
  - 数据缺失导致布局塌陷（如缺少 source 导致 meta 行只剩一个点）
  - 错误状态静默（用户不知道出错了）

✅ 必须：
  - 每个 wx:if 数据展示前检查字段存在性
  - 分隔符 `·` 始终与数据字段绑定（有数据才渲染分隔符+字段）
  - 错误状态提供明确的恢复路径（重试/返回）
```

## §5. 层级语言 (Z-Index Language)

### 5.1 固定元素层级表

```
  ┌─────────────────────────────────────────┐
  │  z=41   字体面板 (font-panel)             │  ← 最高层
  │  z=40   字体面板遮罩                       │
  │  z=30   侧边栏面板 (slide-panel)           │
  │  z=29   侧边栏遮罩 (panel-overlay)         │
  │  z=25   导航点 / 边界Chip / 网络Toast      │
  │  z=20   详情页底部操作栏                    │
  │  z=15   首页固定顶栏 (fixed-top-bar)        │
  │  z=10   状态页容器 (state-container)        │
  │  z=5    骨架屏 (skeleton-stage)            │
  │  z=2    活跃卡片 (.card.active)            │
  │  z=1    非活跃卡片 (.card.above/below)      │
  └─────────────────────────────────────────┘
```

### 5.2 固定元素空间分配

```
┌─────────────────────────────────────────────┐
│ 状态栏 (statusBarHeight + 6px)               │
├─────────────────────────────────────────────┤
│ 顶栏 (64rpx)  ← z=15                        │
│                                             │
│         卡片舞台 (全屏)  ← z=1~2              │
│                                             │
│         导航点 (右侧)  ← z=25                │
│                                             │
│         边界Chip  ← z=25                     │
│         bottom: 180rpx                       │
│                                             │
├─────────────────────────────────────────────┤
│ 底部操作栏 (100rpx + safe-area) ← z=20       │
└─────────────────────────────────────────────┘
```

### 5.3 层级约束

```
❌ 禁止：
  - 新元素 z-index 使用 999/9999 等随意值
  - 两个固定元素 bottom 值重叠（如 网络Toast 与 底部操作栏 同区域）
  - 不同层级元素使用相同 z-index

✅ 必须：
  - 新增固定元素时，在本节表格中登记
  - 固定元素 bottom 值 = 下方元素总高度 + 安全间距（≥ 20rpx）
  - 详情页 content 的 padding-bottom = 底部操作栏高度(100rpx) + 安全间距（翻页按钮已按简化决策移除，不再计入）
```

### 5.4 关键间距计算（详情页）

```
翻页按钮：已按产品简化决策整体移除（UX-SIMPLIFY 批次 + PM 裁定口径），不再占用 z=18 / bottom 空间。

content padding-bottom = 底部操作栏高度(100rpx + safe-area-bottom) + 安全间距(48rpx)
                       = calc(100rpx + env(safe-area-inset-bottom) + 48rpx)
                       → 与前端 FE-B4 实现一致（清开当前 100rpx 操作栏 + 余量，无无谓大留白）
```

## §6. 布局语言 (Layout Language)

### 6.1 页面结构模板

```
┌─────────────────────────────────┐
│  .page (100vh, flex column)     │
│  ┌─────────────────────────────┐│
│  │ 状态栏占位 (flex-shrink:0)   ││
│  ├─────────────────────────────┤│
│  │ 导航栏 (flex-shrink:0)       ││
│  ├─────────────────────────────┤│
│  │                             ││
│  │ 内容区 (flex:1, overflow-y)  ││
│  │                             ││
│  ├─────────────────────────────┤│
│  │ 底部操作栏 (flex-shrink:0)   ││
│  └─────────────────────────────┘│
└─────────────────────────────────┘
```

### 6.2 间距系统（基于 8rpx 单位）

| Token | 值 | 用途 |
|-------|-----|------|
| `space-xs` | 4rpx | 图标与文字间距、进度指示内部 |
| `space-sm` | 8rpx | 收藏元信息行内间距 |
| `space-md` | 16rpx | 卡片 meta 行 gap、面板内边距 |
| `space-lg` | 24rpx | 档位行 gap、摘要段间距 |
| `space-xl` | 32rpx | 面板标题下间距 |
| `space-2xl` | 40rpx | 卡片标题下间距 |
| `space-3xl` | 48rpx | 卡片左右内边距、正文段间距 |
| `space-4xl` | 64rpx | 卡片 body 左右内边距 |

### 6.3 触控热区标准

```
最小触控目标：44px × 44px（微信无障碍建议）
实际实现：    ≥ 88rpx 高度（44px @2x）

示例：
  - 字体面板档位行：88rpx 高度 ✅
  - 底部操作栏按钮：padding 22rpx + icon 44rpx = 88rpx ✅
  - 顶栏按钮：56rpx × 56rpx ✅
  - 侧边栏列表项：padding 28rpx × 2 = 56rpx + title 高度 ✅
```

### 6.4 字体缩放适配

```
--font-scale 变量：1 / 1.15 / 1.3 / 1.5（对应 4 档）

参与缩放的元素（使用 calc(基准 × var(--font-scale))）：
  ✅ 标题、正文、摘要
  ✅ 元信息（分类标签、来源、时间）
  ✅ 导航文字、按钮文字
  ✅ 提示文字（swipe-hint、guide-overlay）

不参与缩放的元素：
  ❌ 图标/emoji（固定尺寸）
  ❌ 面板圆角、间距、padding
  ❌ 分割线、阴影
  ❌ 导航点尺寸

超大档位（tier 3）截断保护：
  [data-font-scale="3"] .card-title { -webkit-line-clamp: 2 }
  [data-font-scale="3"] .summary-p   { -webkit-line-clamp: 4 }
  [data-font-scale="3"] .detail-title { -webkit-line-clamp: 3 }
  [data-font-scale="3"] .text-p       { -webkit-line-clamp: 6 }
  [data-font-scale="3"] .detail-meta  { white-space: nowrap; overflow: hidden; text-overflow: ellipsis }
```

## §7. 组件交互标准

### 7.1 字体面板 (font-panel)

| 属性 | 规范 |
|------|------|
| 出现方式 | 底部半屏滑入（max-height: 55vh） |
| 关闭方式 | ① 点击遮罩 ② 无操作 3s 自动关闭 ③ 触摸面板内部重置 3s 计时器 |
| 选中行为 | 即时生效，无确认按钮 |
| 持久化 | `wx.setStorageSync('fontScale')` + `fromSystem` 标记 |
| 首入行为 | 跟随微信系统字体设置（fontSizeSetting） |
| z-index | 面板 41 / 遮罩 40 |

### 7.2 侧边栏 (slide-panel)

| 属性 | 规范 |
|------|------|
| 出现方式 | 右滑入（82% 宽度，transform translateX） |
| 关闭方式 | ① 点击遮罩 ② 点击列表项（选择后自动关闭） |
| 分类切换 | 切换不关闭面板，仅刷新列表数据 |
| 收藏 Tab | 独立逻辑，从 localCache 读取，展示相对时间 |
| z-index | 面板 30 / 遮罩 29 |

### 7.3 底部操作栏 (detail-bottom-bar)

| 属性 | 规范 |
|------|------|
| 布局 | 固定底部，flex row，两等分（收藏 + 分享） |
| 收藏 | ♡ ↔ ♥ 切换，heartBeat 300ms 动画，localCache 持久化，200 条上限 |
| 分享 | button open-type="share"，触发 onShareAppMessage |
| 背景 | 毛玻璃效果（backdrop-filter: blur(20px)） |
| z-index | 20 |
| 高度 | 100rpx + safe-area-inset-bottom |

### 7.4 分享卡片 (share-card)

| 属性 | 规范 |
|------|------|
| 类型 | 隐藏 Canvas（type="2d"），400×300 |
| 预生成 | onLoad 时 `_pregenPlaceholder(category)`，150ms 延迟，缓存至 `_placeholderCache` |
| 兜底 | Canvas 未就绪 → 微信默认图标 |
| 标题 | "一页 \| " 前缀 + emoji 安全截断（Array.from，≤30 字符） |
| 路径 | `/pages/detail/detail?id=xxx&index=N&category=xxx` |

## §8. 数据流与缓存标准

### 8.1 缓存策略（localCache B-06）

| 缓存键 | TTL | 用途 |
|--------|-----|------|
| `newsList:{category}` | 10 分钟 | 侧边栏分类列表、引擎分类预拉 |
| `newsDetail:{id}` | 30 分钟 | 详情正文 |
| `favorites` | 永不过期 | 收藏列表（上限 200 条） |
| `fontScale` | 永不过期 | 字体档位记忆 |

### 8.2 请求策略

```
首页加载：getNewsList({ category, pageNum:1, pageSize:10 })
         → 骨架屏 → ready/error/empty

详情引擎：并行拉取 7 分类首页 → 合并 → 定位入口 → 加载详情
         → wx.showLoading → 回调 onDetailReady → wx.hideLoading
         → 失败降级：单条 getNewsDetail

翻页预取：当前索引 ±2 窗口静默预取详情
边界加载：到达末尾上滑 → getNewsList({ pageNum+1 }) → 合并到列表尾
边界刷新：到达开头下滑 → getNewsList({ pageNum:1 }) → 替换列表
```

背景：纯黑 #000000（OLED 省电）

次要文字：#999999
分割线：深灰 #1C1C1E
毛玻璃面板：rgba(13,13,13,0.92)

## §11. 验收清单 (Design QA Checklist)

> 每次设计交付 / 开发完成后对照检查。

### 手势
- [ ] 所有手势符合 §1.1 词汇表，无新增手势类型
- [ ] 手势冲突按 §1.3 优先级正确处理
- [ ] 卡片区使用 WXS 触摸处理（非 JS setData）

### 动画
- [ ] 所有动画时长符合 §2.1 标准
- [ ] 无阻塞式动画
- [ ] `prefers-reduced-motion` 降级已测试

### 反馈
- [ ] 每个操作 ≤ 100ms 内有视觉反馈
- [ ] Toast 文案 ≤ 12 字符
- [ ] 无静默状态变更

### 状态
- [ ] 所有数据展示区覆盖 loading / ready / error / empty 四态
- [ ] 空数据时无布局塌陷（分隔符跟随数据隐藏）
- [ ] 错误状态有恢复路径

### 层级
- [ ] 所有 z-index 值在 §5.1 表格范围内
- [ ] 固定元素 bottom 值无重叠
- [ ] content padding-bottom 足够展示所有固定元素下方的正文

### 布局
- [ ] 间距使用 8rpx 倍数
- [ ] 触控目标 ≥ 88rpx（44px）
- [ ] 字体缩放 calc() 正确应用于所有文本元素
- [ ] tier 3 截断保护已生效

### 暗色模式
- [ ] @media (prefers-color-scheme: dark) 覆盖完整
- [ ] 分享占位图正确使用暗色配色
- [ ] 毛玻璃面板暗色背景生效
