## 1. 设计目标

- **极简主页**：首页卡片流不堆放任何功能入口图标，所有二级功能统一从右下角 ⚙ 浮动按钮进入。
- **一键回首页**：所有非首页页面（详情页 / 浏览记录页 / 收藏列表页）导航栏固定提供 🏠 返回主页图标，无需逐层回退。
- **双入口分工清晰**：⚙（首页「出去看更多」）与 🏠（二级页「回首页」）互不冲突。

---

## 2. 设计规范（精确值）

### 2.1 返回主页图标（UI-18）

| 属性 | 规格 |
|------|------|
| 图标 | 🏠 房屋 SVG / iconfont |
| 尺寸 | 图标 44rpx × 44rpx（原型 22px），点击区 56rpx × 56rpx（原型 28px，满足微信最小可点击区） |
| 颜色 | 日间 `#333333` / 暗色 `#E0E0E0`（与导航栏文字一致） |
| hover/active | opacity 0.6 |
| 位置 | 导航栏**左侧**，与微信系统返回按钮相邻（系统返回在左边缘，主页图标在其右侧约 40rpx 处） |
| 固定方式 | `position: fixed`，位于导航栏区域内，不受页面滚动影响；`z-index: 100` |
| 行为 | 点击 `wx.reLaunch({ url: '/pages/home/home' })` 清除导航栈；防抖 300ms；失败降级 `wx.navigateBack` |

### 2.2 导航栏布局（UI-19 / UI-20 / UI-21）

| 页面 | 左侧 | 居中 |
|------|------|------|
| 详情页（UI-19） | 🏠 主页图标 | 进度指示 `1/20 · 科技`（分类名随当前分类变化），与图标间距 ≥ 16rpx 互不遮挡 |
| 浏览记录页（UI-20） | 🏠 主页图标 | 页面标题「浏览记录」 |
| 收藏列表页（UI-21） | 🏠 主页图标 | 页面标题「我的收藏」 |

> 导航栏高度 44rpx（原型 44px）+ 状态栏 44rpx；居中标题用绝对定位 `left:0;right:0;text-align:center`，图标用 `z-index` 置于其上且 `pointer-events:none` 不挡点击。

### 2.3 更多功能 dock 菜单（UI-07 / UI-08 / UI-09，方案 F）

| 属性 | 规格 |
|------|------|
| 触发 | 首页右下角 ⚙ 浮动按钮（96rpx 圆形，保留现有 3D 浮动动效） |
| 弹出方向 | **向上**（从 ⚙ 位置向上展开，不遮挡卡片流） |
| 容器 | 浮层（非整页），毛玻璃 `backdrop-filter: blur(20px)`，圆角 14px，阴影 `0 8px 24px rgba(0,0,0,.25)` |
| 菜单项 | 图标（28rpx 圆角容器）+ 文字标签；点击区 ≥ 88rpx；日间/暗色双套色值 |
| 结构 | 自下而上：🕐 浏览记录 → ♥ 我的收藏 → ⚙ 设置 → ＋ 扩展位（预留 1~2 个） |
| 动效 | Mac dock 栈：点击 ⚙ 后菜单项依次向上展开（轻微缩放 + 位移，stagger ~40ms），非整屏切换 |
| 收起 | 再次点击 ⚙ 或点击空白遮罩（`rgba(0,0,0,.18)`） |
| 跳转 | 🕐 → `pages/history/history`；♥ → `pages/favorites/favorites`；⚙ → 字体/暗色设置面板；＋ → 占位 |
| z-index | 菜单高于卡片流（原型 58），低于系统导航栏 |

## 3. 暗色模式

- 所有色值通过 CSS 变量驱动，跟随 `theme.json` 全局暗色变量实时切换。
- 主页图标 `#333`→`#E0E0E0`；毛玻璃背景在暗色下用 `rgba(13,13,13,.55)`。
