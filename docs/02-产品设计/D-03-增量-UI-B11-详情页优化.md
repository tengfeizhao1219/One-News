# D-03-增量 · UI-B11 详情页优化设计

> **编号**：UI-B11 | **角色**：产品设计师 | **日期**：2026-08-05
> **原型来源**：https://tengfeizhao1219.github.io/One-News/showcase/detail-redesign.html
> **状态**：✅ 以交互原型库为唯一权威依据

---

## 1. 概述

针对详情页「无阅读进度条、滑动提示常驻、收藏态不显眼」3 项轻量优化：

| 问题 | 现状 | 优化 |
|------|------|------|
| 无阅读进度条 | 仅 nav 文字「3/7」 | 顶部 3px 进度细条，随滚动实时更新 |
| 滑动提示常驻 | 一直显示「上滑阅读下一条」 | 3.5s 自动淡出 或 首次滚动即消失 |
| 收藏态不显眼 | 仅图标变色，label 仍「收藏」 | label→「已收藏」+ 按钮微高亮 + 图标填充 + 心跳动画 |

## 3. 精确规格

### 3.1 阅读进度条

| 属性 | 值 |
|------|-----|
| 高度 | `3px`（原型为 3px，非 2px） |
| 背景 | `var(--divider)` |
| 进度条颜色 | `var(--progress)` — `rgba(0,122,255,0.55)` |
| 宽度计算 | `scrollTop / (scrollHeight - clientHeight) × 100%` |
| 更新方式 | `onContentScroll` 实时更新，`transition: width 0.08s linear` |
| 可见条件 | 仅 `ready` 态显示，错误/加载态不显示 |
| 位置 | nav 正下方，`flex-shrink: 0` |

### 3.2 滑动提示

| 属性 | 值 |
|------|-----|
| 位置 | `position: absolute; bottom: calc(64px + env(safe-area-inset-bottom))` |
| 布局 | 居中，`gap: 6px`，图标 ↑ + 文字「上滑阅读下一条」 |
| 字号 | `11px`，`letter-spacing: 3px` |
| 颜色 | `var(--text-secondary)`，`opacity: 0.55` |
| 交互 | `pointer-events: none` |
| 消失逻辑 | 进入 3.5s 后淡出（`transition: opacity 0.4s`）**或** 首次滚动 > 10px 即消失 |
| 消失后 | 不占像素、不接收事件 |

### 3.3 底部操作栏

| 属性 | 值 |
|------|-----|
| 高度 | `calc(64px + env(safe-area-inset-bottom))` |
| 背景 | `var(--bottom-bar-bg)` = `rgba(250,249,247,0.55)` |
| 毛玻璃 | `backdrop-filter: blur(20px)` |
| 顶部分割 | `1px solid var(--divider)` |
| 布局 | `display: flex`，两按钮均分 |
| 按钮排列 | `flex-direction: column; align-items: center; gap: 3px` |
| 图标 | `22px`，`line-height: 1` |
| 文字 | `calc(12px * var(--fsm))`，`var(--text-secondary)` |
| 按压 | `transform: scale(0.92)`，`transition: 0.12s` |

### 3.4 收藏按钮状态机

```
初始态（未收藏）：
  ♡ 空心，var(--text-secondary)，label「收藏」

→ 点击收藏：
  乐观更新 → ♥ 实心，#FF3B30，label「已收藏」
  按钮底：var(--color-favorite-tint) 微高亮
  动画：heartBeat（scale 1→1.3→0.9→1，300ms ease-out）
  Toast：「已加入收藏」

→ 再次点击（取消）：
  ♡ 空心，恢复 var(--text-secondary)，label「收藏」
  Toast：「已取消收藏」
```

### 3.5 已收藏态视觉

```css
.bottom-bar-btn.faved {
  background: var(--color-favorite-tint);   /* rgba(255,59,48,0.10) */
}
.bottom-bar-btn.faved .icon { color: var(--color-favorite); }    /* #FF3B30 */
.bottom-bar-btn.faved .label { color: var(--color-favorite); font-weight: 600; }
```

### 3.6 分享按钮

| 状态 | 图标 | 行为 |
|------|------|------|
| 默认 | ↗ | `open-type="share"` 拉起微信转发面板 |
| 按压 | scale(0.92) | 150ms ease |

## 5. 交互边界

1. 进度条仅在 `ready` 态渲染，错误/加载态不显示
2. 滑动提示消失后不再占用像素与事件
3. 收藏态切换乐观更新，翻页/滚动不受影响
4. 翻页动画与进度更新不冲突
5. 收藏成功顶部 Toast「已加入收藏」；异步双写不阻塞阅读

---

## 6. 验收清单

| 验收项 | 标准 |
|--------|------|
| 进度条随滚动平滑更新 | 不卡顿，`transition: width 0.08s linear` |
| 滑动提示 3.5s 或首次滚动消失 | `opacity: 0`，`transition: 0.4s` |
| 已收藏态 label→「已收藏」 | 三要素一致：label + 背景 + 图标 |
| 收藏心跳动画 | `heartBeat` 300ms ease-out |
| 暗色模式进度条与提示色正确 | 所有 token 生效 |
| Toast 反馈 | 「已加入收藏」/「已取消收藏」1600ms |
