## 一、设计总则

「一页」的设计遵循 **"少即是多"** 原则。每一个像素的存在都必须有充分的理由。

### 核心设计原则

1. **内容即界面** — 去掉一切装饰性UI元素，让新闻内容本身成为界面
2. **手势即导航** — 没有按钮的界面，全靠直觉手势驱动
3. **呼吸感** — 大量留白、宽松行距，让阅读像呼吸一样自然
4. **一致性** — 三个视图使用统一的间距、字体、配色体系

## 二、组件规范

### 2.1 全屏新闻卡片（SwipeCard）

```
┌─────────────────────────────────┐
│                                 │
│  ┌───────────────────────────┐  │
│  │       [图片/渐变区]        │  │  ← 高度: 350rpx(有图) / 200rpx(无图)
│  └───────────────────────────┘  │
│                                 │
│  [32rpx padding-horizontal]     │
│                                 │
│  新闻标题                        │  ← 36rpx Bold
│  (最多2行，超出省略)              │
│                                 │
│  [16rpx gap]                    │
│                                 │
│  新闻摘要正文...                 │  ← 28rpx Regular, 行高1.8
│  (最多500字，自然分段)           │
│                                 │
│  [24rpx gap]                    │
│                                 │
│  [分类标签] 来源 · 时间          │  ← 22rpx
│                                 │
│  [32rpx padding-bottom]         │
└─────────────────────────────────┘
```

**状态：**
- 默认：正常显示
- 切换中：当前卡片向上移出，新卡片从下方进入
- 加载中：骨架屏占位

### 2.2 分类胶囊标签（CategoryTag）

```
┌──────────────┐
│  🔵 科技      │  ← 22rpx, 半透明背景
└──────────────┘     padding: 4rpx 16rpx
                     border-radius: 20rpx
                     背景: 分类色 + 15%透明度
                     文字: 分类色
```

### 2.3 列表项（ListItem）

```
┌─────────────────────────────────┐
│ ┌──────────┐                    │
│ │          │  新闻标题           │  ← 28rpx Bold, 最多2行

  高度: 140rpx, 左右padding: 24rpx
```

### 2.5 底部操作栏（BottomBar）

```
┌─────────────────────────────────┐
│     🤍 收藏    │    ↗️ 分享       │  ← 均分, 图标36rpx, 文字20rpx

  背景: 毛玻璃 rgba(255,255,255,0.72)
```

```
│  ├─ 卡片顶部留白: 48rpx               │

│  页面级间距                           │

│  └─ 安全区底部: env(safe-area-inset)  │
│                                      │
└──────────────────────────────────────┘
```

## 四、动效参数表

| 动效名称 | 属性 | 起始值 | 结束值 | 时长 | 缓动 |
|---------|------|--------|--------|------|------|
| 卡片上滑切换 | translateY | 0 | -100% | 350ms | ease-in-out |
| 卡片从下进入 | translateY | 100% | 0 | 350ms | ease-in-out |
| 切换时透明度 | opacity | 1 | 0.2 | 350ms | ease |
| 列表滑入 | translateX | 100% | 0 | 300ms | ease-out |
| 列表滑出 | translateX | 0 | 100% | 250ms | ease-in |
| 遮罩淡入 | opacity | 0 | 0.4 | 300ms | ease |
| 遮罩淡出 | opacity | 0.4 | 0 | 250ms | ease |
| 卡片点击 | scale | 1 | 0.97 | 150ms | ease |
| 骨架屏闪烁 | background-position | -200% | 200% | 1.5s | linear(循环) |
| 收藏心形 | scale | 1 | 1.3→1 | 300ms | ease-out |

## 五、暗色模式适配方案

### 5.1 技术方案

使用微信原生 `darkmode` + `theme.json`：

```json
// app.json
{
  "darkmode": true,
  "themeLocation": "theme.json"
}
```

```json
// theme.json
{
  "light": {
    "bgColor": "#F2F2F7",
    "cardBg": "#FFFFFF",
    "textPrimary": "#1A1A1A",
    "textSecondary": "#8E8E93",
    "textTertiary": "#C7C7CC",
    "dividerColor": "#E5E5EA",
    "glassBg": "rgba(255,255,255,0.72)",
    "overlayColor": "rgba(0,0,0,0.4)",
    "skeletonBase": "#E5E5EA",
    "skeletonShine": "#F2F2F7"
  },
  "dark": {
    "bgColor": "#000000",
    "cardBg": "#1C1C1E",
    "textPrimary": "#F2F2F7",
    "textSecondary": "#8E8E93",
    "textTertiary": "#545458",
    "dividerColor": "#38383A",
    "glassBg": "rgba(28,28,30,0.85)",
    "overlayColor": "rgba(0,0,0,0.7)",
    "skeletonBase": "#38383A",
    "skeletonShine": "#1C1C1E"
  }
}
```

### 5.2 WXSS 使用方式

```css
/* 使用 CSS 变量 */
.page {
  background-color: var(--bgColor);
}

/* 或使用媒体查询 */
@media (prefers-color-scheme: dark) {
  .card-gradient {
    background: linear-gradient(to top, #000000, transparent);
  }
}
```
