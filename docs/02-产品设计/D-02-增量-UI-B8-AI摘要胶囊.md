## 2. 视觉方案对比与推荐

> PM 建单时转述的参考视觉为「蓝紫渐变底 + 白色文字」。经与 C4/C5/C6 比对，该视觉在本产品体系内存在冲突，故提供三方案供 owner 一眼裁定。

| | **A-1 主题色轻胶囊** ⭐ 推荐 | A-2 中性灰胶囊 | A-3 蓝紫渐变（PM 原议） |
|---|---|---|---|
| 日间底色 | `rgba(0,122,255,0.12)` | `#EEECE8` | `linear-gradient(135deg,#007AFF,#5856D6)` |
| 日间字色 | `#007AFF` | `#7A7A7A` | `#FFFFFF` |
| 暗色底色 | `rgba(10,132,255,0.18)` | `#1C1C1E` | `linear-gradient(135deg,#0A84FF,#818CF8)` |
| 暗色字色 | `#0A84FF` | `#999999` | `#FFFFFF` |
| 复用现有 token | ✅ `--primary-subtle` / `--primary` | ✅ `--tag-bg` / `--tag-text` | ❌ 需新增 2 个渐变 token |
| 与分类标签区分度 | ✅ 色相区分，语义不混 | ❌ 与 `category-tag` 几乎同款，易混淆 | ✅ 强区分 |
| 视觉重量 | 轻（标注感） | 极轻（易被忽略） | **重（压过标题）** |
| 与 C5/C6 一致性 | ✅ | ✅ | ❌ 冲突 |

### 推荐 A-1 的理由

1. **零新增色**：`--primary-subtle` / `--primary` 已在 `theme.json` 存在且已有使用先例，不扩张色板。
2. **守住层级秩序**：胶囊是「元信息标注」，不应重于「内容」。A-3 白字渐变的视觉重量高于 `card-title`，会造成**标注抢过新闻标题**——与 owner 在 UI-B7 v5.1 的取向（连高亮底色都嫌重）方向相反。
3. **与分类标签语义分层**：`category-tag` 用中性灰（客观分类），AI 胶囊用主题蓝（系统能力标识），色相区分而非重量区分。
4. **暗色安全**：`rgba` 底色在纯黑 `#000000` 背景上不产生灰块边缘，渐变则会在 OLED 纯黑上形成明显色斑。

> **若 owner 仍偏好醒目**：建议选 A-3 但**去掉渐变、改纯色** `#5856D6` + 白字（保留醒目度，避免引入渐变体系）。此为 A-3′，可一并裁定。

## 3. 设计规范（精确值 · FS 直接落地）

### 3.1 结构与位置

**方案 A = 内联于摘要首段行首**（非独立成行）。

理由：建单验收项要求「胶囊**不撑高卡片**、不挤标题、摘要正常排版」。独立成行会增加卡片高度约 60rpx；内联于首段行首，胶囊高度（≤41.4rpx）小于正文行高（59.2rpx），**卡片高度零增加**，且视觉上仍位于「摘要区左上角」，满足 owner 方案 A 语义。

```
┌─────────────────────────────┐
│ 新闻标题                     │  card-title
│ [分类] 来源 · 时间            │  card-meta
│                             │
│ [AI 摘要] 正文第一段文字从这里 │  ← 胶囊内联于首段行首
│ 开始，自然换行后左对齐……      │
│                             │
│ 第二段正文……                 │  ← 后续段落无胶囊
└─────────────────────────────┘
```

### 3.2 胶囊参数（A-1 推荐方案）

| 属性 | 值 | 说明 |
|---|---|---|
| 文案 | `AI 摘要` | **AI 与「摘要」间保留半角空格**（中英混排规范）；沿用 owner 原文措辞 |
| 字号 | `calc(22rpx * var(--font-scale-meta, 1))` | 守 C1 基准 22rpx + 继承 C2 封顶跟涨（最大 25.3rpx） |
| 字重 | `500` | 与 `category-tag` 一致 |
| 字体族 | 继承 page 默认无衬线（**不继承摘要区衬线**） | 标注属 UI 层，与衬线正文形成"系统 vs 内容"区分 |
| 字色（日/暗） | `var(--primary)` → `#007AFF` / `#0A84FF` | |
| 底色（日/暗） | `var(--primary-subtle)` → `rgba(0,122,255,0.12)` / `rgba(10,132,255,0.18)` | |
| 圆角 | `16rpx` | 与 `category-tag` 一致 |
| 内边距 | `3rpx 14rpx` | 与 `category-tag` 一致 |
| 行高 | `1.4` | 锁定胶囊自身高度，不受正文 1.85 影响 |
| 字距 | `0` | 22rpx 小字加字距会松散 |
| 边框 | **无** | |
| 阴影 | **无** | |
| 透明度 | `1`（底色透明度已含在 rgba 内） | |
| 显示方式 | `display: inline-block` | |
| 垂直对齐 | `vertical-align: middle` | |
| 右外边距 | `12rpx` | 与首段文字的间隔 |
| 上下外边距 | `0` | 防止撑开行盒 |
| 动效 | **无**（静态标识） | 若后续需入场动画，仅允许 `opacity 0→1 / 120ms / ease-out`，不得加位移或缩放 |
| 可点击 | **否** | 纯视觉提示，不绑定 `bindtap`，不加 `hover-class`；点击穿透至卡片原有 `onCardTap` |

### 3.3 参考实现（WXML）

```xml
<!-- 摘要 -->
<view class="card-summary">
  <block wx:for="{{item.summaryParagraphs}}" wx:key="*this" wx:for-index="pIdx">
    <view class="summary-p">
      <text wx:if="{{pIdx === 0 && item.isAiSummary}}" class="ai-chip">AI 摘要</text>{{item}}
    </view>
  </block>
</view>
```

> ⚠️ `<text class="ai-chip">` 与 `{{item}}` 之间**不得有换行或空格**，否则渲染出多余空白。

### 3.4 参考实现（WXSS）

```css
/* UI-B8：AI 摘要标识胶囊（内联于摘要首段行首，不撑高卡片） */
.ai-chip {
  display: inline-block;
  vertical-align: middle;
  margin: 0 12rpx 0 0;
  padding: 3rpx 14rpx;
  border-radius: 16rpx;
  /* 守 owner 元信息 22rpx 红线 + 继承 UX-FIX-F12 封顶跟涨 */
  font-size: calc(22rpx * var(--font-scale-meta, 1));
  font-weight: 500;
  line-height: 1.4;
  letter-spacing: 0;
  /* 不继承摘要区衬线字体，标注属 UI 层 */
  font-family: -apple-system, BlinkMacSystemFont, "PingFang SC", sans-serif;
  color: var(--primary);
  background-color: var(--primary-subtle);
}
```

> **无需改动 `theme.json`**：`--primary` / `--primary-subtle` 日暗两态均已存在。

### 3.5 高度安全性验算（证明不撑高卡片）

| 场景 | 胶囊高度 | 正文行高 | 结论 |
|---|---|---|---|
| 默认（scale=1, meta=1） | 22×1.4 + 3×2 = **36.8rpx** | 32×1.85 = **59.2rpx** | ✅ 余 22.4rpx |
| 极端（scale=1, meta=1.15） | 25.3×1.4 + 6 = **41.4rpx** | **59.2rpx** | ✅ 余 17.8rpx |
| 大字（scale=1.5, meta=1.15） | **41.4rpx** | 48×1.85 = **88.8rpx** | ✅ 余 47.4rpx |

**任意组合下胶囊高度均 < 正文行高 → 卡片高度零增加。**
