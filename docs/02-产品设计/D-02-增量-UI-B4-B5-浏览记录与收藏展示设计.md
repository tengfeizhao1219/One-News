## 2. UI-B4 浏览记录页（UI-01~08）

| 编号 | 设计项 | 规格 |
|------|--------|------|
| UI-01 | 页面框架 | 导航栏标题「浏览记录」+ 列表 / 空态 / 加载态三态齐备；入口经 ⚙ dock 菜单进入 |
| UI-02 | 列表项布局 | 缩略图 52rpx + 标题（2 行截断，28rpx 主文字色）+ 次行「来源 · 相对时间」（22rpx 次级色）；分隔线遵循 D-03 列表规范 |
| UI-03 | 相对时间 | 今天 → `HH:mm`；昨天 → `昨天`；2~7 天 → `N 天前`；>7 天不展示 |
| UI-04 | 空态 | 🕘 图标（64rpx）+ 文案「暂无浏览记录」+ 引导按钮「去首页看看」（跳首页） |
| UI-05 | 加载态 | 骨架屏 3~5 条占位（亮/暗各一套，脉冲动画） |
| UI-06 | 回看交互 | 点列表项 → 跳详情并定位该新闻；返回回原位置（记录页保持滚动位置） |
| UI-07 | 按压态 | 浅色遮罩反馈，热区 ≥ 88rpx |
| UI-08 | 暗色适配 | 亮/暗两套走查，对比度 ≥ 4.5:1，色值走 theme.json 变量 |

## 3. UI-B5 收藏云同步展示（UI-11~17）

| 编号 | 设计项 | 规格 |
|------|--------|------|
| UI-11 | 合并中进度 | 列表打开时顶部细进度条（云端合并 ≤2s），合并完成静默，无强提示 |
| UI-12 | 空态 | 「暂无收藏」 |
| UI-13 | 待同步角标 | 离线收藏未上云条目：右下角「☁️ 待同步」角标（12 号字，次级色），点按重试 |
| UI-14 | 同步失败 | 整页顶部轻提示条「收藏同步失败，点击重试」（非阻断式） |
| UI-15 | 收藏反馈 | 成功 ♥ 心跳动画；取消恢复 ♡；**云端失败** toast「已收藏（待同步）」 |
| UI-16 | 分享反馈 | 点击分享调起转发卡片（onShareAppMessage 不变），无额外 UI |
| UI-17 | 失效兜底 | 回看已被清理（>7 天）新闻 → 详情 error 态「新闻详情暂不可用，请返回重试」 |
