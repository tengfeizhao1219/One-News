# D-02-增量 · UI-B10 收藏页优化设计

> **编号**：UI-B10 | **角色**：产品设计师 | **日期**：2026-08-05
> **原型来源**：https://tengfeizhao1219.github.io/One-News/showcase/favorites-redesign.html
> **状态**：✅ 以交互原型库为唯一权威依据

---

## 1. 概述

针对收藏页「纯文字行、无分类标签、无删除入口、无计数、无筛选」5 项短板：

| 问题 | 优化 |
|------|------|
| 纯文字行 | 卡片化：标题 + 分类标签 + 来源·时间（**无缩略图**，owner 决策） |
| 无分类标签 | 分类色文字标签（`--flash-*`）做视觉区分 |
| 无删除入口 | 长按列表项 → ActionSheet「取消收藏」 |
| 无计数 | nav 右侧「共 N 条」，随筛选联动 |
| 无筛选 | nav 下横滑胶囊（全部 + 各分类），纯前端 filter |

## 3. 精确规格

### 3.1 导航栏

| 属性 | 值 |
|------|-----|
| 布局 | `display: flex; align-items: center; gap: 6px; padding: 6px 14px 10px` |
| 返回图标 | ⌂，`22px`，`color: var(--primary)` |
| 标题 | 「我的收藏」，`17px`，`font-weight: 600`，`color: var(--text-primary)` |
| 计数 | `position: absolute; right: 14px`，「共 N 条」，`12px`，`color: var(--text-secondary)` |

### 3.2 分类筛选胶囊

| 属性 | 值 |
|------|-----|
| 容器 | `display: flex; gap: 8px; padding: 0 16px 12px; overflow-x: auto` |
| 胶囊默认 | `font-size: 13px; padding: 6px 14px; border-radius: 16px; background: var(--tag-bg); color: var(--tag-text)` |
| 胶囊选中 | `background: var(--primary); color: #fff` |
| 过渡 | `transition: all 0.15s` |
| 联动 | 选中全部→计数=N，选中分类→计数=该类数 |

### 3.3 收藏卡片

| 属性 | 值 |
|------|-----|
| 布局 | `display: flex; gap: 12px; padding: 13px 0; border-bottom: 1px solid var(--divider)` |
| 缩略图 | **无**（owner 决策） |
| 标题 | `font-size: calc(16px * var(--fs)); color: var(--text-primary); line-height: 1.4`，`-webkit-line-clamp: 2` |
| 元信息行 | `margin-top: 8px; display: flex; gap: 8px; font-size: calc(12px * var(--fsm)); color: var(--text-secondary)` |
| 分类标签 | `padding: 1px 8px; border-radius: 8px; background: var(--tag-bg); font-size: 11px; font-weight: 500` |
| 分类色 | `.c-tech { color: var(--flash-tech) }` `.c-world { color: var(--flash-world) }` 等 |
| 按压反馈 | `opacity: 0.2s transition`（长按触发 ActionSheet） |

### 3.4 分类色彩标识

| 分类 | CSS class | 浅色文字色 | 暗色文字色 |
|------|-----------|-----------|-----------|
| 科技 | `.c-tech` | `#007AFF` | `#60A5FA` |
| 世界 | `.c-world` | `#5856D6` | `#818CF8` |
| 体育 | `.c-sports` | `#FF9500` | `#FBBF24` |
| 生活 | `.c-life` | `#34C759` | `#34D399` |

### 3.5 长按删除交互

```
长按列表项（500ms）→ ActionSheet 弹出

┌──────────────────────────────────┐
│          取消收藏                 │ ← color: var(--color-favorite)
│  ────────────────                │ ← 8px 间距
│          取消                     │ ← color: var(--text-secondary)
└──────────────────────────────────┘

ActionSheet 规格：
- 遮罩：var(--overlay)，点击关闭
- 面板：var(--bg-card)，border-radius: 16px 16px 0 0
- 入场动画：translateY(100%) → 0，0.25s
- 删除后：本地 localCache.favorites 立即移除 + 云端双写
- 乐观更新：先移除再渲染，失败回滚
```

### 3.6 空态

**总空态（无任何收藏）**：
```
┌──────────────────────────────────┐
│                                  │
│             📑                   │ ← 46px，opacity 0.4
│                                  │
│      还没有收藏任何新闻            │ ← 15px var(--text-secondary)
│    收藏后这里会按分类整理          │ ← line-height 1.6
│                                  │
│      ┌──────────────────┐        │
│      │    去首页看看      │        │ ← 14px var(--primary)
│      └──────────────────┘        │   背景 var(--primary-subtle)
│                                  │   圆角 20px
└──────────────────────────────────┘
```

**筛选空态（某分类下无收藏）**：
```
┌──────────────────────────────────┐
│             🔍                   │
│      该分类下暂无收藏              │
└──────────────────────────────────┘
```

## 4. 暗色模式

所有色值通过 CSS 变量驱动，无需额外适配代码。重点验证：分类色文字、空态图标、ActionSheet 面板。

---

## 5. 交互边界

1. 筛选只改视图、不动底层 list 数组
2. 取消收藏走异步双写，列表乐观更新
3. 计数实时准确且随筛选联动
4. 长按删除有二次确认（ActionSheet）
5. 空态/筛选空态文案区分
6. 不依赖 thumbUrl

---

## 6. 验收清单

| 验收项 | 标准 |
|--------|------|
| 卡片与首页四要素一致（标题/分类/来源/时间） | 视觉统一 |
| 计数实时准确且随筛选联动 | 全部=N / 某类=该类数 |
| 长按删除有二次确认 | ActionSheet 弹出 |
| 空态文案正确 | 总空态 vs 筛选空态 |
| 暗色模式全部 token 生效 | 分类色、背景、文字 |
| 列表乐观更新 | 删除即时响应，失败回滚 |
