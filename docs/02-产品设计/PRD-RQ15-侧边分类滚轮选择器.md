## 1. 背景与目标

### 1.1 用户痛点

当前首页分类切换路径：

```
左滑打开面板 → 在顶部横向 Tab 中找到目标分类 → 点击 → 关闭面板
```

> 四步操作，且横向 Tab 在 iPhone 上单手拇指几乎够不到。用户反馈"从顶部切换不方便"。

### 1.2 目标

- 分类切换从 **4 步减少到 1 步**（拇指直接拨动滚轮）
- 切换过程**无跳转、无面板开合**，流畅连续
- 滚轮始终可见但不侵扰卡片阅读

### 1.3 用户决策记录

| 决策项 | 用户选择 | 日期 |

| 滚轮可见模式 | **始终可见（半透明驻留）** | 2026-07-31 |
| 分类标题显示 | **卡片流顶部显示当前分类名** | 2026-07-31 |
| 震动反馈 | **每 snap 一次触发 `wx.vibrateShort`** | 2026-07-31 |

## 4. 功能详细设计

### 4.1 F-RQ15-01 滚轮组件 · 布局与分类

**核心行为（EARS）**

- **WHILE** 首页卡片流渲染完毕 **THE SYSTEM SHALL** 在屏幕右侧渲染分类滚轮组件，与卡片流区域等高，宽度 88rpx，距卡片流右边缘 8rpx。
- **THE SYSTEM SHALL** 按以下顺序排列分类：推荐、科技、国际、体育、生活、三农、科学、❤️收藏。「❤️收藏」上方以 1px 分割线（opacity 0.2）与其他分类隔开。
- **WHEN** 当前选中非「❤️收藏」**THEN THE SYSTEM SHALL** 卡片流展示该分类新闻；**WHEN** 选中「❤️收藏」**THEN THE SYSTEM SHALL** 展示收藏列表视图。

> 分类数据源不变，沿用 `constants.js` 中 `CATEGORIES`。

---

### 4.2 F-RQ15-02 默认态 · 半透明驻留

| 属性 | 浅色模式 | 暗色模式 |
|------|---------|---------|
| 滚轮整体 opacity | 0.35 | 0.35 |
| 非选中分类文字 | `rgba(0,0,0,0.12)`，字号 20rpx | `rgba(255,255,255,0.12)`，字号 20rpx |
| 当前选中分类 | `rgba(0,0,0,0.5)`，字号 24rpx，font-weight 500 | `rgba(255,255,255,0.5)`，字号 24rpx |
| 选中位置 | 固定在滚轮垂直居中位置 | 同 |
| 滚轮背景 | 透明 | 透明 |
| 中心指示线 | 无 | 无 |

**核心行为（EARS）**

- **WHILE** 用户未触摸滚轮 **THE SYSTEM SHALL** 维持半透明状态，不遮挡卡片内容。

---

### 4.3 F-RQ15-03 触摸态 · 激活高亮

| 触发 | 手指触碰滚轮区域 |
|------|------|
| 滚轮整体 opacity | 0.9 |
| 非选中分类文字 | `rgba(0,0,0,0.45)`，字号 22rpx / 暗色 `rgba(255,255,255,0.45)` |
| 当前选中分类 | `var(--primary)` 主题色，字号 28rpx，font-weight 600 |
| 滚轮背景 | `rgba(255,255,255,0.7)` + `backdrop-filter: blur(8px)` / 暗色 `rgba(30,30,30,0.85)` |
| 中心指示线 | 选中项上下各 1px solid，`rgba(0,0,0,0.15)` / 暗色 `rgba(255,255,255,0.15)` |
| 激活过渡 | 300ms ease-out |

**核心行为（EARS）**

- **WHEN** 用户手指触碰滚轮区域 **THEN THE SYSTEM SHALL** 300ms 内过渡到激活高亮态。
- **IF** 用户手指离开滚轮 **THEN THE SYSTEM SHALL** 300ms 后恢复默认半透明态。
- **WHILE** 用户手指在滚轮上持续停留但不滑动 **THE SYSTEM SHALL** 保持激活态。

---

### 4.4 F-RQ15-04 滚轮交互 · 滑动 & 吸附 & 震动

**核心行为（EARS）**

- **WHEN** 用户在滚轮区域上下拖动 **THEN THE SYSTEM SHALL** 实时更新选中分类（`bindtouchmove` → 实时读取当前 Y 偏移 → 映射到对应分类索引），**不等松手**即切换主卡片流。
- **WHEN** 用户松手 **THEN THE SYSTEM SHALL** snap 吸附到最近分类（`scroll-snap-type: y mandatory`），并触发 `wx.vibrateShort({ type: 'light' })`。
- **WHERE** 快速滑动有惯性 **THE SYSTEM SHALL** 限制单次惯性最多跨 3 个分类后减速停止（防止一滑到底）。
- **IF** 已处于第一个分类（推荐）继续向上滑 **THEN THE SYSTEM SHALL** 展示轻微弹跳效果（`bounce`），不切换。同理末端分类向下不切换。
- **THE SYSTEM SHALL** 不阻断卡片流的 WXS 手势——滚轮 `touchstart/touchmove/touchend` 事件在滚轮区域内消费，不向上冒泡。

**吸附映射逻辑**：
```
滚轮总高度 / 9（8 分类 + 收藏） = 每个分类占位高度
当前滚动偏移 / 每个占位高度 → 四舍五入取整 → 对应分类索引
```

---

### 4.5 F-RQ15-05 卡片流顶部分类标题

**核心行为（EARS）**

- **WHEN** 滚轮选中分类变更 **THEN THE SYSTEM SHALL** 在卡片流顶部居中显示当前分类中文名，如「科技」。
- **WHEN** 选中「❤️收藏」**THEN THE SYSTEM SHALL** 标题显示为「我的收藏」。
- **WHILE** 标题显示 **THE SYSTEM SHALL** 采用以下样式：
  - 字号 26rpx，font-weight 500
  - 颜色：当前主题色 opacity 0.7（浅色）/ opacity 0.8（暗色）
  - 与卡片流顶部间距 12rpx，居中
  - 切换时有 200ms 淡入淡出过渡

---

### 4.6 F-RQ15-06 侧边栏简化

**核心行为（EARS）**

- **WHERE** 滚轮组件上线 **THE SYSTEM SHALL** 从侧边栏面板中移除 `panel-tabs`（横向分类 Tab）。
- **THE SYSTEM SHALL** 保留侧边栏的新闻列表（`panel-list`）和收藏列表功能，用户仍可通过侧边栏浏览和跳转具体新闻。

## 6. 验收标准

| 编号 | 验收项 |
|------|--------|
| AC-RQ15-01 | **WHEN** 首页加载 **THEN** 右侧出现半透明分类滚轮，选中分类居中 |
| AC-RQ15-02 | **WHEN** 手指触碰滚轮 **THEN** 300ms 内激活高亮（背景毛玻璃 + 选中项主题色加粗 + 指示线） |
| AC-RQ15-03 | **WHEN** 手指离开滚轮 **THEN** 300ms 后恢复半透明默认态 |
| AC-RQ15-04 | **WHEN** 上下滑动滚轮 **THEN** 卡片流即时切换分类；松手 snap 吸附 + 震动 |
| AC-RQ15-05 | **IF** 快速滑动 **THEN** 惯性最多跨 3 个分类后停止 |
| AC-RQ15-06 | **IF** 首个/末个分类继续滑 **THEN** bounce 弹跳，不切换 |
| AC-RQ15-07 | **WHEN** 选中「❤️收藏」**THEN** 展示收藏列表，标题「我的收藏」 |
| AC-RQ15-08 | **WHILE** 滚轮正常运作 **THEN** 卡片左右滑动手势不冲突 |
| AC-RQ15-09 | **WHEN** 暗色模式 **THEN** 滚轮文字色和背景色适配暗色 |
| AC-RQ15-10 | **WHERE** 滚轮上线 **THEN** 侧边栏面板中不再显示分类 Tab |

## 7. 技术实现提示

> 产品侧建议，技术负责人可在 T-03 细化。

| 项目 | 建议 |
|------|------|
| 组件方式 | 新建 `components/category-wheel/` 独立组件，`home.wxml` 引用 |
| 吸附实现 | 优先用 CSS `scroll-snap-type: y mandatory` + `scroll-snap-align: center`，需兼容基础库 3.0.0+ |
| 手势隔离 | 滚轮区域设置 `catchtouchmove`（阻止事件冒泡到卡片 WXS），或 JS 层判断触摸起始坐标 |
| 实时切换 | `bindtouchmove` 中计算当前选中索引，与上次不同的才 `setData` 更新分类（防抖去重） |
| 震动 API | `wx.vibrateShort({ type: 'light' })`，基础库 2.13.0+。无权限要求 |
| 与现有分类逻辑 | 不改变 `home.js` 中 `loadNews`/`onCategoryChange` 核心逻辑，仅新增触发入口 |
