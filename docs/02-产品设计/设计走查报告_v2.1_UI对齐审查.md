```
┌─────────────────────────────────────┐

│                                     │
│  ┌─ 预览 ────────────────────────┐  │
│  │  ┌─────────────────────┐      │  │
│  │  │  新闻标题示例...     │      │  │
│  │  │  来源 · 时间         │      │  │
│  │  └─────────────────────┘      │  │

│                                     │
```

**样式参数**：

| 元素 | 参数 |
|------|------|

### §3.2 分类选择器修订规格

```
┌──────────┬──────────────────────────┐
│ 今日新闻 │  新闻列表内容区域         │
│ 全部·15条│                          │
├──────────┤                          │
│ 全部     │  1. 马斯克称 SpaceX...   │ ← 顶部对齐
│ 科技     │  2. SpaceX首份财报...    │
│ 国际     │  3. 特斯拉财报电话...    │
│ 科学探索 │  ...                      │
│ 社会     │                          │
│ 财经     │   ← 整列可滑动           │
│ 体育     │                          │
│ 娱乐     │                          │
│ 更多...  │                          │
└──────────┴──────────────────────────┘
 ↑                                  ↑
分类列宽 72px                       内容区
```

**关键修订**：

| 属性 | 旧值（错误） | 新值（正确） |
|------|-------------|-------------|
| **选中高亮方式** | 背景色块填充 | **文字颜色淡淡高亮** |
| **选中文字色** | 同未选中 | `--color-primary-light: #FF7849`（opacity 0.6 感） |
| **未选中文字色** | `#999` | `--color-text-secondary: #999` |
| **滑动热区** | 文字宽度 (~40px) | **整列宽度 (72px)** |
| **分类起始位置** | 有顶部间距 | **紧贴 "今日新闻" 标题下方，顶对齐** |
| **分类列宽** | 不固定 | 固定 `72px` |
| **分类项高度** | 不固定 | 固定 `50px` |
| **分类字体** | 15px | 14px / Regular |

**选中态高亮 CSS**：
```css
/* ❌ 旧：背景高亮 */
.category-item.active {
  background-color: rgba(255, 120, 73, 0.08);
  border-radius: 8px;
}

/* ✅ 新：文字淡淡高亮 */
.category-item.active {
  color: #FF7849;              /* 品牌色，但视觉上"淡淡的" */
  font-weight: 500;            /* 仅加粗一点点，不用 Medium */
}
.category-item {
  color: #999;                 /* 未选中：浅灰 */
}
```

**场景**：切换分类时显示 "已切换到「科技」"

```
┌──────────────────────────┐
│                          │
│   ✅ 已切换到「科技」     │  ← 浅色圆角背景
```

| 内边距 | `8px 20px` |

| 显示位置 | 页面居中偏上（距顶部 40%） |
| 动画 | fade-in 200ms → 停留 1200ms → fade-out 200ms |
| 最大宽度 | `70%` |

### §3.5 收藏按钮状态机规格

```
┌─────────────────────────────────────────┐
│                                         │
│   状态转换图:                            │
│                                         │
│   [空心灰] ──点击──▶ [实心红]            │
│    ♥ #999        ♥ #FF4D4F             │
│       ▲               │                 │
│       └──再次点击─────┘                 │
│                                         │
└─────────────────────────────────────────┘
```

| 状态 | 图标 | 颜色 | 尺寸 |
|------|------|------|------|
| **未收藏（默认）** | `heart-o` 空心 | `#999` (`--color-icon-default`) | 20px |
| **已收藏（激活）** | `heart` 实心 | `#FF4D4F` (`--color-danger`) | 20px |
| **点击动画** | scale(1.2) → scale(1.0) | 200ms ease-out | — |

**CSS Token**：
```css
:root {
  --icon-favorite-default: #999;
  --icon-favorite-active: #FF4D4F;
  --icon-action-size: 20px;      /* 收藏/分享统一切小 */
  --action-transition: all 200ms ease-out;
}
```
