## 1. 产品概述

### 1.1 产品理念

> **"一页？打开就看。"**

「一页」是一款完全以**极致用户体验**和**高质量新闻资讯**为核心的微信小程序。

核心设计哲学：**像刷短视频一样刷新闻**。

- 🚫 零商业化
- 🎯 内容为王（每篇精编至500字）
- 📱 打开即看，无需选择
- ⬆️⬇️ 上下滑动切换新闻
- 👈 左滑唤出列表
- 🎨 沉浸式全屏阅读

### 1.2 核心交互模型（参考抖音/快手）

```
用户打开小程序
      │
      ▼
┌──────────────────────────┐
│                          │
│     全屏新闻卡片 #1       │  ← 大图/纯色背景
│     [新闻标题]            │     + 标题
│     [~500字摘要]          │     + 摘要正文
│                          │
│                          │
├──────────────────────────┤
│  上滑 ↓                  │
│                          │
│     全屏新闻卡片 #2       │
│     [新闻标题]            │
│     [~500字摘要]          │
│                          │
├──────────────────────────┤
│  上滑 ↓                  │
│                          │
│     全屏新闻卡片 #3       │
│     ...                  │
└──────────────────────────┘

交互：
  ⬆️⬇️ 上下滑动 = 切换新闻（主交互）
  👈 左滑 = 唤出新闻列表侧边栏
  👆 点击卡片 = 进入详情页（可选）
```

### 1.3 一句话描述

> 打开即看，上下滑动刷新闻，3分钟了解世界。

## 3. 用户交互流程

### 3.1 核心路径

```
                     ┌──────────────┐
                     │   打开小程序   │
                     └──────┬───────┘
                            │
                     ┌──────▼───────┐
                     │  全屏卡片 #1   │  ← 直接进入，无需选择
                     │  (大图+标题    │
                     │   +500字摘要) │
                     └──┬───┬───┬──┘
                        │   │   │
            ┌───────────┘   │   └───────────┐
            │               │               │
     ┌──────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
     │  上滑/下滑   │ │  左滑手势    │ │  点击卡片    │
     │  切换新闻    │ │  唤出列表    │ │  进入详情    │
     │ (主交互)     │ │  (辅助交互)  │ │  (深度阅读)  │
     └──────┬──────┘ └──────┬──────┘ └──────┬──────┘
            │               │               │
     ┌──────▼──────┐ ┌──────▼──────┐ ┌──────▼──────┐
     │  全屏卡片 #2 │ │  侧边栏列表  │ │  新闻详情页  │
     │  全屏卡片 #3 │ │  ·分类Tab   │ │  ·完整正文   │
     │  全屏卡片 #4 │ │  ·新闻列表  │ │  ·配图      │
     │    ...      │ │  ·点击跳转  │ │  ·相关推荐   │
     └─────────────┘ └─────────────┘ └─────────────┘
```

### 3.2 手势交互矩阵

| 手势 | 触发 | 效果 | 优先级 |
|------|------|------|:---:|
| ⬆️ 上滑 | 手指从下往上 | 切换到下一条新闻（卡片过渡动画） | **主交互** |
| ⬇️ 下滑 | 手指从上往下 | 切换到上一条新闻 | **主交互** |

> **手势方向（用户最终确认，2026-08-03）**：上滑→下一条、下滑→上一条。实现见 `pages/detail/detail.js`（commit `299d3f9`「翻页方向最终修正」；此前 `9c85e52` 曾尝试反向映射，真机验证后改回并确认此为标准，**以本注记与代码实况为准**）。**翻页按钮已删除**（commit `b698c98`，owner 多次明确不需要），仅保留手势翻页。
| 👈 左滑 | 手指从右往左 | 从右侧滑入新闻列表侧边栏 | 辅助 |
| 👉 右滑(列表打开时) | 手指从左往右 | 关闭列表侧边栏 | 辅助 |
| 👆 点击卡片 | 点击任意位置 | 跳转新闻详情页 | 深度阅读 |
| 👆 点击分类Tab | 点击列表中的Tab | 切换列表分类 | 辅助 |

### 3.3 动画过渡

| 场景 | 动画 |
|------|------|
| 上滑 → 下一条 | 旧内容向上滑出（`out-up`），新内容从底部滑入（`in-up`），一屏高度 |
| 下滑 → 上一条 | 旧内容向下滑出（`out-down`），新内容从顶部滑入（`in-down`），一屏高度 |
| 唤出列表 | 列表从右侧滑入，覆盖80%宽度，左侧留20%可点击关闭 |
| 关闭列表 | 列表向右滑出 |
| 进入详情 | 卡片放大过渡到详情页 |

## 4. 页面清单

### 4.1 MVP 页面（仅 3 个页面）

| 页面 | 路由 | 说明 |
|------|------|------|
| 沉浸式新闻流 | `pages/index/index` | **主页面**，全屏卡片上下滑动 |
| 新闻详情页 | `pages/detail/detail` | 点击卡片后进入 |
| 侧边栏列表 | 内嵌于首页 | 左滑唤出，非独立页面 |

### 4.2 无 TabBar

- ❌ 不需要底部TabBar
- ❌ 不需要顶部复杂导航
- ✅ 打开即看，手势驱动一切

## 6. MVP 范围定义

### MVP 包含
```
✅ 全屏新闻卡片流（F01-F02）
✅ 左滑列表 + 分类筛选（F03-F04）
✅ 新闻详情页（F05）
✅ 下拉刷新（F06）
✅ 暗色模式（F07）
✅ 分享 + 骨架屏 + 相关推荐（F08-F10）
```

### MVP 页面
```
仅 3 个视图：
  1. 全屏卡片流（主视图）
  2. 侧边栏列表（左滑唤出）
  3. 新闻详情页（点击进入）
```

### MVP 不包含
```
❌ TabBar 导航
❌ 首页分类选择页
❌ 复杂的多级菜单
```
