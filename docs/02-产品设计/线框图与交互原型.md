```

## 二、视图一：全屏新闻卡片流（主视图）

### 2.1 布局结构

```
┌──────────────────────────────────┐
│                                  │  ← 状态栏区域(透明)
│                                  │
│  ┌────────────────────────────┐  │
│  │                            │  │
│  │                            │  │
│  │       [新闻配图区域]         │  │  ← 有图：图片占上部约50%面积
│  │       或                    │  │     无图：分类渐变背景占上部30%
│  │       [渐变背景区域]         │  │

│  ├────────────────────────────┤  │
│  │                            │  │
│  │  [32rpx padding]           │  │
│  │                            │  │

│  │  一行或两行                 │  │     左对齐
│  │                            │  │
│  │  [16rpx gap]               │  │
│  │                            │  │
│  │  新闻摘要正文。控制在500字    │  │  ← 28rpx Regular, #1A1A1A
│  │  以内，精炼概括核心内容。    │  │     行高1.8，段间距16rpx
│  │                            │  │     左对齐
│  │  可以分为2-3个自然段，       │  │
│  │  每段2-4行。               │  │
│  │                            │  │
│  │  让用户在3分钟内即可了解     │  │
│  │  新闻事件的全貌。           │  │
│  │                            │  │
│  │  [24rpx gap]               │  │
│  │                            │  │
│  │  ┌──────────────────────┐  │  │
│  │  │ 🔵 科技               │  │  │  ← 分类胶囊标签
│  │  └──────────────────────┘  │  │      22rpx，半透明底色
│  │  新华社 · 3小时前          │  │  ← 来源+时间，22rpx, #8E8E93
│  │                            │  │
│  └────────────────────────────┘  │
│                                  │
│  ┌────────────────────────────┐  │
│  │  上滑阅读下一条 ↑           │  │  ← 首屏显示操作提示(20rpx)
│  └────────────────────────────┘  │     3秒后自动消失
│                                  │
└──────────────────────────────────┘
```

### 2.2 有图模式 vs 无图模式

**有图模式**（约70%的新闻）：
- 图片占卡片上部约50%面积（约350rpx高度）
- 图片下方为标题+摘要
- 图片底部有轻微渐变遮罩（从透明到白色，过渡自然）

**无图模式**（约30%的新闻）：
- 上部使用分类对应渐变背景（约200rpx高度）
- 渐变中央显示分类图标（可选）
- 下方同样为标题+摘要

### 2.3 上下滑动交互

```
┌──────────────────────────────────┐
│                                  │
│        卡片 #0（已滑出）          │  ← translateY: -100%
│                                  │      opacity: 0
│ ═══════════════════════════════ │
│                                  │
│        卡片 #1（当前可见）        │  ← translateY: 0
│         [标题+摘要]              │      opacity: 1
│                                  │
│ ═══════════════════════════════ │
│                                  │
│        卡片 #2（即将进入）        │  ← translateY: 100%
│         [标题+摘要]              │      opacity: 0
│                                  │
└──────────────────────────────────┘

触发：手指从下往上滑动 > 50rpx
动画：当前卡片上滑消失 + 下一张卡片从底部滑入
时长：350ms
缓动：cubic-bezier(0.25, 0.46, 0.45, 0.94)
```

### 2.4 下拉刷新

```
┌──────────────────────────────────┐
│         ↻ 正在加载最新新闻        │  ← 顶部下拉超过80rpx触发
│                                  │     加载动画(旋转指示器)
│        卡片 #1（保持）            │
│                                  │
└──────────────────────────────────┘

触发：在第一条卡片位置继续下拉 > 80rpx
反馈：顶部出现加载指示器 → 刷新数据 → 自动回弹
```

### 2.5 首屏引导（首次使用）

```
┌──────────────────────────────────┐

│         [卡片内容正常显示]        │

│  │     👆 上滑看下一条          │  │  ← 半透明毛玻璃提示卡片
│  │     👈 左滑查看今日列表      │  │     显示3秒后自动消失
│  │     👆 点击阅读全文          │  │     之后不再显示
│  └────────────────────────────┘  │
│                                  │
└──────────────────────────────────┘

## 三、视图二：侧边栏新闻列表（左滑唤出）

### 3.1 布局结构

```
┌──────────────────────────────────┐
│                                  │

│  │ ████████ 状态栏 █████│        │  ← 状态栏
│  │                      │        │
│  │ 📋 今日新闻    ✕ 关闭│        │  ← 列表标题栏(48rpx高)
│  │                      │        │
│  │ [推荐][科技][国际]     │        │  ← 分类Tab(可选，横向滚动)
│  │ [体育][生活]          │        │     选中态: 加粗+分类色下划线
│  │                      │        │
│  │ ┌──────────────────┐ │        │
│  │ │ ┌──────┐         │ │        │  ← 新闻列表项
│  │ │ │      │ 新闻标题 │ │        │     左图(120rpx宽)
│  │ │ │ 小图 │ 来源·时间│ │        │     右文(标题+来源时间)
│  │ │ │      │         │ │        │     点击→详情页
│  │ │ └──────┘         │ │        │
│  │ └──────────────────┘ │        │
│  │ ┌──────────────────┐ │        │
│  │ │ ┌──────┐         │ │        │
│  │ │ │      │ 新闻标题 │ │        │
│  │ │ │ 小图 │ 来源·时间│ │        │
│  │ │ └──────┘         │ │        │
│  │ └──────────────────┘ │        │
│  │        ...           │        │
│  │                      │        │
│  └──────────────────────┘        │
│                                  │
│  ← 点击此处关闭列表              │  ← 左侧20%透明区域
│                                  │     点击即关闭
└──────────────────────────────────┘
```

### 3.2 列表项规格

| 属性 | 值 |
|------|------|
| 高度 | 140rpx |
| 图片尺寸 | 120×90rpx, 圆角8rpx |
| 标题字号 | 28rpx, 最多2行 |
| 来源时间 | 22rpx, #8E8E93 |
| 间距 | 上下16rpx, 左右24rpx |
| 分割线 | 1rpx, #E5E5EA, 左边距120+16rpx |

### 3.3 滑入/滑出动画

```
滑入：
  列表: translateX(100%) → translateX(0)
  遮罩: opacity(0) → opacity(0.4)
  时长: 300ms

滑出：
  列表: translateX(0) → translateX(100%)
  遮罩: opacity(0.4) → opacity(0)
  时长: 250ms

触发条件：
  滑入：手指从右边缘向左滑动 > 60rpx
  滑出：点击左侧遮罩区 / 点击关闭按钮 / 向右滑动
```

## 五、暗色模式适配

所有三个视图均支持暗色模式，关键适配点：

| 元素 | 浅色 | 暗色 |
|------|------|------|
| 页面底色 | `#F5F3F0`（暖灰，v2.0） | `#000000` |
| 卡片/面板背景 | `#FAF9F7`（暖白，v2.0） | `#0D0D0D`（v2.0） |
| 主文字 | `#1C1C1E` | `#FFFFFF`（v2.0） |
| 有图卡片遮罩 | `rgba(0,0,0,0)→rgba(250,249,247,1)` | `rgba(0,0,0,0)→rgba(0,0,0,1)` |
| 列表遮罩 | `rgba(0,0,0,0.25)`（v2.0） | `rgba(0,0,0,0.7)` |
| 毛玻璃 | `rgba(250,249,247,0.85)`（v2.0） | `rgba(13,13,13,0.92)`（v2.0） |

切换方式：使用微信原生 `darkmode` + `theme.json` + CSS变量，跟随系统自动切换。
