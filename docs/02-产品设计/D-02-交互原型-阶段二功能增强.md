### 2.2 进度指示状态矩阵

| 场景 | 显示内容 | 动画 |
|------|---------|------|
| 同分类翻页（非末条） | `"4 / 20"` | 数字即时更新（150ms），无分类名 |
| 跨分类切换（方案 A） | `"1 / 15 · 国际"` | 数字 + 分类名 fadeIn 200ms，分类名用分类强调色 |
| 跨分类切换（方案 B） | `"加载中…"` → `"1 / 15 · 国际"` | spinner 300ms → fadeIn 替换 |
| 全部分类最后一条 | `"20 / 20 · 科技"`（保持当前） | 不变，底部弹出边界提示 |
| 下滑到第一条 | `"1 / 20"` | 不变，底部弹出边界提示 |
| 单分类无数据 | `"—"` | 不显示数字 |

### 2.3 跨分类切换动画时序

```
时间轴（ms）：
0        150      350      500      700
│─────────│────────│────────│────────│
│         │        │        │        │
├─ 手势触发（dy < -70, dt < 500）
│
├─ 150ms：positionText 即时更新 + 分类色闪烁条出现
│          ┌──┐ ← 闪烁条（宽40rpx, 高4rpx, 分类色）
│          └──┘   中心淡入淡出，200ms 后消失
│
├─ 0→350ms：out-up 离场动画
│  当前内容 translateY: 0 → -100%, opacity: 1 → 0
│
├─ 220ms：内容切换触发（setTimeout 220ms）
│  loadDetailByIndex(newGlobalIndex)
│
├─ 350→700ms：in-up 入场动画
│  新内容 translateY: 100% → 0, opacity: 0 → 1
│
└─ 700ms：动画完成，_animating = false
```

### 2.6 方案 A vs 方案 B 交互差异（方案 A 已定案 ✅，方案 B 留档备查）

| 维度 | 方案 A（全量预拉） | 方案 B（按需拉取） |
|------|-------------------|-------------------|
| 进入详情时 | 加载全分类合并列表（可能略慢） | 加载当前分类列表（快） |
| 跨分类翻页 | 无感知，即时切换 | 短暂 loading（≤ 500ms） |
| 进度指示 | 始终可显示全局位置 | 跨分类时先显示"加载中…" |
| 网络依赖 | 首屏决定一切 | 每次跨分类需联网 |
| 离线体验 | 全量已缓存，离线可读 | 未拉取的分类离线不可用 |
| 加载态 | 无 | 正文区居中 spinner（复用首页骨架风格） |

**方案 B 特有加载态**：
```
┌──────────────────────────────────┐
│  ← 返回          加载中…          │
├──────────────────────────────────┤
│                                  │
│            ⟳                     │  ← 居中 spinner
│                                  │     复用首页骨架风格
│                                  │     超时 3s → 网络兜底
│                                  │
└──────────────────────────────────┘
```

### 2.7 网络不可用兜底

```
触发条件：跨分类翻页时 wx.getNetworkType() === 'none' 且目标分类本地无缓存

┌──────────────────────────────────┐
│  ← 返回       20 / 20 · 科技     │
├──────────────────────────────────┤
│                                  │
│    [当前最后一条正文保持显示]      │  ← 停在当前，不跳空白
│                                  │
│  ┌────────────────────────────┐  │
│  │  🟡 网络开小差，下拉重试     │  │  ← 黄色警告 toast（3s 自动消失）
│  └────────────────────────────┘  │     下拉手势 → 重新触发翻页
│                                  │
└──────────────────────────────────┘
```

- 颜色：黄色警告调 `#F59E0B`，区别于红色错误态
- 消失：3s 自动消失
- 重试：用户在详情页区域下拉（dy > 80）重新触发翻页逻辑

### 2.8 阅读位置回写（跨分类兼容）

```js
// detail.js goBack() 扩展
goBack() {
  app.globalData._detailReturnState = {
    category: this.data.category,           // 最终停靠的分类
    categoryIndex: this._globalIndex,       // 🆕 全分类合并列表中的位置
    newsId: this.data.news.id,
  }
  wx.navigateBack()
}
```

首页 `onShow` 读取 `_detailReturnState`：
- 侧边栏定位到 `category` 对应的 Tab
- 若 `category` 为侧边栏中已有分类 → 高亮对应 Tab
- 若用户从「❤️ 收藏」Tab 进入 → 回到收藏 Tab

### 3.1 用户流程

```
┌──────────────────────────────────────────────┐
│                                              │
│  首页顶部栏                                    │
│  ┌──────────────────────────────────┐         │
│  │  R (刷新)               ⚙️ (设置) │         │
│  └──────────────────────────────────┘         │
│         │                                     │
│         │ 点击 ⚙️                              │
│         ▼                                     │
│  ┌──────────────────────────────────┐         │
│  │         字体大小                  │         │
│  │                                  │         │
│  │  ○ 标准  预览文字效果预览文字      │         │
│  │  ● 大    预览文字效果预览文字      │  ← 当前选中高亮
│  │  ○ 特大  预览文字效果预览文字      │         │
│  │  ○ 超大  预览文字效果预览文字      │         │
│  │                                  │         │
│  │  ──────────────────────────────  │         │
│  │  关于 · 反馈                     │         │
│  └──────────────────────────────────┘         │
│     ↑ 底部半屏面板（毛玻璃，300ms slideUp）      │
│     ↑ 选中即生效，无需确认按钮                   │
│     ↑ 点击遮罩或 3s 无操作 → slideDown 关闭      │
└──────────────────────────────────────────────┘
```

### 3.2 首入跟随系统逻辑

```
首次启动
    │
    ▼
wx.getSystemInfoSync().fontSizeSetting
    │
    ├── 标准(16px 级) → fontScale = 0 (标准, ×1.0)
    ├── 大(18px 级)   → fontScale = 1 (大,   ×1.15)
    ├── 特大(20px 级) → fontScale = 2 (特大, ×1.3)
    └── 超大(24px+)   → fontScale = 3 (超大, ×1.5)
    │
    ▼
wx.setStorageSync('fontScale', tier)
wx.setStorageSync('fontScaleFromSystem', true)
    │
    ▼
用户手动调整后 → wx.setStorageSync('fontScaleFromSystem', false)
              → 不再跟随系统
```

### 3.3 档位切换即时生效机制

```
用户点击档位
    │
    ├─ 1. 面板内预览文字：实时缩放（面板自身不参与全局缩放）
    │
    ├─ 2. wx.setStorageSync('fontScale', tier)  // 持久化
    │
    ├─ 3. app.globalData.fontScale = tier        // 广播
    │
    ├─ 4. 首页卡片文字：通过 CSS 变量 --font-scale 实时响应
    │     详情页正文：onShow 时读取 globalData 同步
    │     侧边栏列表：同上
    │
    └─ 5. 过渡动画：transition: font-size 150ms ease（无闪烁）
```

### 3.4 全局生效范围

| 页面/区域 | 受字号缩放影响 ✅ | 不受影响（固定尺寸）❌ |
|-----------|:----------------:|:---------------------:|
| 首页卡片 | 标题、摘要、元信息、滑动提示文字 | 卡片容器、分类标签尺寸、导航点 |
| 侧边栏 | 面板标题、Tab 文字、列表标题、来源时间 | 面板宽度、Tab 间距、分割线 |
| 详情页 | 标题、正文、元信息、翻页按钮文字、边界提示文字 | 状态栏、导航栏高度、底部操作栏图标/高度 |
| 底部操作栏 | 按钮文字（收藏/分享） | 按钮图标、栏高度 100rpx、点击热区 ≥ 88rpx |
| 设置面板 | 预览文字（跟随选中档位） | 面板自身容器、档位选项 label、按钮 |

```
│                                  │
└──────────────────────────────────┘
```

### 4.5 收藏边界场景

| 场景 | 处理 |
|------|------|
| 重复收藏同一新闻 | `favorites.find(f => f.id === news.id)` 幂等保护，已收藏则忽略 |
| 存储写失败 | `wx.setStorageSync` 抛异常 → toast "收藏失败，请稍后重试"，按钮保持未收藏态 |
| 容量达上限（200 条） | 添加前检查 `favorites.length >= 200` → toast "收藏已满，请清理后重试" |
| 弱网环境 | 收藏是纯本地操作，不受网络影响，正常执行 |
| 新闻被删除（原数据不可用） | 收藏列表仍显示标题/来源（本地有缓存），点击尝试加载 → 失败则 toast "原文已不可用" |
| 侧边栏 Tab 过多 | 分类 Tab 横向滚动，❤️ 收藏始终在最右侧 |

## 六、全局交互规范

### 6.1 字号 CSS 变量体系

```css
/* theme.json 或全局 wxss */
page {
  --font-scale: 1.0;           /* 默认标准，由 JS 动态设置 */

  /* 首页卡片 */
  --font-size-title: calc(36rpx * var(--font-scale));
  --font-size-body: calc(28rpx * var(--font-scale));
  --font-size-meta: calc(22rpx * var(--font-scale));

  /* 详情页 */
  --font-size-detail-title: calc(32rpx * var(--font-scale));
  --font-size-detail-body: calc(30rpx * var(--font-scale));
}

/* 档位映射 */
/* tier 0 (标准): --font-scale: 1.0   */
/* tier 1 (大):   --font-scale: 1.15  */
/* tier 2 (特大): --font-scale: 1.3   */
/* tier 3 (超大): --font-scale: 1.5   */
```

### 6.2 暗色模式交互行为

| 行为 | 规范 |
|------|------|
| 模式切换 | 跟随系统 `prefers-color-scheme`（`theme.json` + `darkmode: true`），不提供手动切换 |
| 设置面板 | `.setting-panel` 背景跟随 `var(--bg-card)`，毛玻璃与主页一致 |
| 底部操作栏 | 暗色下背景 `rgba(13,13,13,0.9)`（A-12c §3.1.4），已收藏红色 `#FF453A` |
| 首屏引导 | 暗色模式下文字白色 + 半透明黑色底，与浅色模式视觉权重一致 |

### 6.3 与 WXS 手势的兼容

- WXS（touch.wxs）纯 ES5 红线不变：无 `try/catch/let/const/箭头函数/模板字符串`
- 底部操作栏的 tap 事件层级：按钮 `z-index: 20`，不影响卡片流 `bindtap`
- 现有 `touch.wxs` 无 `return false`，已合规
- 详情页跨分类手势与首页卡片流手势互不干扰（不同页面实例）

### 6.4 字号全局影响的交互约束

- **不缩放**的固定元素：导航栏高度、操作栏高度、图标尺寸、点击热区 ≥ 88rpx
- **被缩放**的内容元素：所有文字字号通过 `calc(Xrpx * var(--font-scale))` 引用
- 超大字号（tier 3, ×1.5）下的**截断保护**：
  - 标题限 3 行 `-webkit-line-clamp: 3`
  - 摘要限 6 行
  - 元信息不换行 `white-space: nowrap`

## 十一、数据展示三态降级规范（UX-IMPROVE02 · 2026-07-31 补充）

> **来源**：阶段五截图审查发现元信息时间缺失时出现多余分隔符（BUG-006），根因为 D-02 未定义空数据降级规则。本规范覆盖详情页全部数据展示区域。

### 通用原则

每个数据展示区域必须定义三种状态：

| 状态 | 符号 | 含义 | 处理原则 |
|------|:---:|------|---------|
| **正常** | ✅ | 数据完整 | 按线框图标准渲染 |
| **空** | ⚪ | 字段缺失（null/undefined/""） | 隐藏该字段及关联装饰元素（分隔符、图标、前缀） |
| **异常** | 🔴 | 数据存在但格式错误（如时间戳无效） | 隐藏该字段 + 记录 console.warn（不阻塞页面） |

### 详情页逐元素三态表

| 区域 | 元素 | 正常 | 空 | 异常 |
|------|------|------|-----|------|
| **元信息** | 来源 | 显示 `news.source` | 隐藏整行 | — |
| | 分隔符 `·` | 仅当**来源和时间均存在**时显示 | 隐藏 | 隐藏 |
| | 时间 | 显示 `news.time` | 隐藏（不显示分隔符） | 隐藏 + console.warn |
| | 分类标签 | 显示 `news.categoryName` | 隐藏（不阻塞） | 隐藏 |
| **标题** | `news.title` | 显示 | 显示 "无标题"（兜底） | 显示原始值 |
| **正文** | `paragraphs` | 正常分段渲染 | 显示 "暂无正文内容" | 显示原始值 |
| **来源链接** | `news.sourceUrl` | 显示 "📎 查看原文" | 隐藏整行 | 隐藏 |
| **分享标题** | `onShareAppMessage` | 正常截断 | 使用 "一页 · 新闻速览" | 同空 |
| **分享封面** | `news.picUrl` | 用图 | 用分类占位图 | 同空 |
| **进度指示** | `positionText` | 显示 | 隐藏 | 隐藏 |
| **翻页按钮** | 上/下一篇 | 显示 | 隐藏（单条时） | 隐藏 |

### 实现规范

```xml
<!-- 元信息示例（修复 BUG-006） -->
<view class="detail-meta">
  <view class="category-tag" wx:if="{{news.categoryName}}">{{news.categoryName}}</view>

  <text wx:if="{{news.source && news.time}}">·</text>
  <text wx:if="{{news.time}}">{{news.time}}</text>

```
