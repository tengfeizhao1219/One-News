## 二、D-02-1：跨分类衔接交互设计

> 输入：PRD §5.1（EARS 规范 + 方案 A/B）+ 评审议题 D-02-1（4 项）

### 2.1 进度指示升级

| 维度 | 当前 | 目标 |
|------|------|------|
| 同分类翻页 | `positionText = "3 / 20"` | **保持不变** |
| 跨分类切换 | 不存在 | `"1 / 15 · 科技"`（追加分类名） |
| 位置 | 顶部导航栏右侧（`nav-position`，已存在） | 复用，居中 |

**交互规格**：
- 翻页动画开始时，`positionText` 即时更新（不等动画结束），避免用户感知延迟
- 跨分类切换时，分类名以 `fadeIn 200ms` 出现，使用**分类强调色**（与首页分类标签色一致）以示区分
- 同分类内翻页时仅更新数字，无分类名显示
- **方案 A（全量预拉）**：可直接计算全局总数和位置；**方案 B（按需拉取）**：跨分类时短暂显示 `"加载中…"` 再替换

### 2.2 衔接动画

**决策**：同分类与跨分类**共用**现有 `out-up/in-up`（350ms, `cubic-bezier(0.25, 0.46, 0.45, 0.94)`）——不引入差异化动效，降低认知成本。

**唯一增强**：跨分类切换时，在顶部 `nav-position` 处叠加 200ms 的**分类色闪烁提示条**（宽 40rpx, 高 4rpx, 中心淡入淡出），告知用户"进入了新分类"。

```
┌──────────────────────────────────┐
│  ← 返回                    位置  │
│                           ┌──┐   │  ← 分类色闪烁条（200ms）
│  科技 · 1 / 15            └──┘   │
├──────────────────────────────────┤
│         [正文内容]                │
```

**方案 B 特有**：跨分类拉取下一分类数据时，正文区展示居中 `loading` spinner（复用首页骨架风格），时长 ≤ 500ms；超时 → 网络兜底（见 §2.4）。

### 2.3 边界提示

| 场景 | 触发 | 提示 | 样式 | 消失 |
|------|------|------|------|------|
| 全部分类最后一条 | 上滑 | "已经是最后一条" | 底部居中 chip（复用 `edge-tip`），深色半透明 | 2s 自动消失 |
| 分类末尾（方案 B） | 上滑 + 加载中 | "正在加载下一分类…" | 同上，带 spinner | 加载完成后消失 |
| 全部分类第一条 | 下滑 | "已经是第一条 · 上滑返回" | 同上（已有实现） | 2s 自动消失 |

**增强建议**："已经是最后一条" 增加 **"← 返回首页"** 可点击文字，`bindtap="goBack"`，减少用户操作摩擦。

### 2.4 网络不可用兜底

<!-- EARS: IF 网络不可用且目标分类本地无缓存 THEN 展示兜底 -->
- 触发：跨分类翻页时 `wx.getNetworkType()` 无网络 + 本地无缓存
- 行为：
  1. 停在当前内容，不跳空白
  2. 底部弹出 toast：🟡「网络开小差，下拉重试」（3s 自动消失）
  3. 下拉手势重新触发翻页逻辑（复用首页下拉刷新机制）
- 样式：黄色警告色调，区别于红色错误态

### 2.5 阅读位置回写兼容

`detail.js` 已在 `goBack()` 中写入 `_detailReturnState = { category, readingIndex }`。

**跨分类兼容**：当用户经历跨分类翻页后返回首页，需记录**最终停靠的分类 + 索引**。在方案 A 下，`_detailReturnState` 扩展为：
```js
_detailReturnState = {
  category: currentCategory,
  categoryIndex: currentGlobalIndex,  // 在全分类合并列表中的位置
  newsId: currentNewsId
}
```
首页 `onShow` 读取后：在侧边栏定位到对应分类 tab，高亮对应条目（已在 home.wxml `panelCurrentIndex` 机制中存在，需确认能消费 `categoryIndex`）。

## 三、D-02-2：字体设置入口与交互

> 输入：PRD §5.3（EARS）+ 评审议题 D-02-2（3 项）+ A-12c §二（字号档位/变量方案）

### 3.1 入口位置：底部半屏设置面板

**决策**：在首页顶部栏右侧新增 **⚙️ 设置图标**（替代原"搜索"占位），点击 → 底部半屏面板，而非嵌入侧边栏。

理由：
- 侧边栏定位是"今日新闻列表"，混入设置会弱化其核心职能
- 设置是低频操作，底部半屏不遮挡主内容、不打断浏览流
- 视觉设计师验证：A-12c 确认按钮样式与暗色兼容，半屏面板可复用毛玻璃风格

```
首页顶部栏：
┌──────────────────────────────────┐
│  R (刷新)               ⚙️ (设置) │
└──────────────────────────────────┘

点击 ⚙️ → 底部面板滑入（300ms）：
┌──────────────────────────────────┐
│         字体大小                  │
│                                  │
│  ○ 标准    （预览文字效果）        │
│  ● 大      （预览文字效果）        │
│  ○ 特大    （预览文字效果）        │
│  ○ 超大    （预览文字效果）        │
│                                  │
│  ──────────────────────────────  │
│  关于 · 反馈                     │
└──────────────────────────────────┘
```

### 3.2 档位切换交互流

| 步骤 | 交互 | 反馈 |
|------|------|------|
| 1. 点击 ⚙️ | 底部面板 `slideUp 300ms` | 毛玻璃背景 + 当前选中档位高亮 |
| 2. 选择档位 | `tap` 单选，即时生效 | 预览文字实时缩放 + `radio` 切换动画 150ms |
| 3. 确认 | 无需确认按钮，选中即保存 | `wx.setStorageSync('fontScale', tier)` |
| 4. 关闭 | 点击遮罩 / 3s 无操作 → `slideDown 250ms` | — |

**即时生效机制**（无白屏/闪烁）：
- 面板内预览文字跟随选中档位实时缩放（面板本身不参与全局字号，防止递归放大）
- 关闭面板后，通过 `getApp().globalData.fontScale = tier` 广播，首页/详情页 `onShow` 同步
- 页面切换时字号平滑过渡：`transition: font-size 150ms ease`（配合 A-12c 的 `calc()` 方案）

### 3.3 首入跟随系统

```
首次启动 → wx.getSystemInfoSync().fontSizeSetting
         → 映射规则：
            标准(16px级) → 0 (标准)
            大(18px级)   → 1 (大)
            特大(20px级) → 2 (特大)
            超大(24px+)  → 3 (超大)
         → 写入 storage，标记 fromSystem=true
         → 后续用户手动调整后，标记 fromSystem=false，不再跟随
```

### 3.4 全局生效范围

| 页面/组件 | 受影响元素 | 不受影响元素（固定尺寸） |
|-----------|-----------|------------------------|
| 首页卡片 | 标题、摘要、元信息、滑动提示 | 卡片容器、分类标签尺寸、导航点 |
| 侧边栏 | 面板标题、Tab 文字、列表标题 | 面板宽度、Tab 间距、分割线 |
| 详情页 | 标题、正文、元信息、翻页按钮文字 | 状态栏、导航栏、底部操作栏图标 |
| 底部操作栏 | 按钮文字 | 按钮图标、栏高度、点击热区 |

**与暗色模式共存**：`--font-scale` 与 `--bg-*` / `--text-*` 变量独立，无冲突。

## 四、D-02-3：收藏 / 分享按钮布局

> 输入：PRD §5.4（收藏 EARS）/ §5.5（分享 EARS）+ 评审议题 D-02-3（3 项）+ A-12c §三（按钮视觉规格）

### 4.1 底部操作栏交互布局

遵循 A-12c 视觉规格，交互补充如下：

```
┌──────────────────────────────────┐
│         [正文内容区]              │
│  （scroll-view 底部预留           │
│   padding-bottom: 100rpx +        │
│   safe-area，防止按钮遮挡）       │
├──────────────────────────────────┤
│                                  │
│     🤍 收藏      │      ↗️ 分享   │
│                                  │
└──────────────────────────────────┘
  ↑ 毛玻璃 fixed bottom
  ↑ 点击热区 ≥ 88rpx（图标 44rpx × 2）
  ↑ 栏高 100rpx + env(safe-area-inset-bottom)
```

**页面布局兼容**：现有 `detail.wxml` 的 `<scroll-view class="content">` 需加 `padding-bottom: calc(100rpx + env(safe-area-inset-bottom))`，确保正文最后一行不被遮挡。

### 4.2 收藏按钮交互状态机

```
                    ┌─────────────────┐
     tap            │   未收藏(默认)    │
  ┌───────────────→ │  🤍 空心 · 灰色  │ ←──────────────┐
  │                 └────────┬────────┘                │
  │                          │ tap                      │
  │                          ▼                          │
  │                 ┌─────────────────┐                │
  │                 │   添加收藏       │                │
  │                 │  storage.set()   │                │
  │                 │  heartBeat 300ms │                │
  │                 └────────┬────────┘                │
  │                          │                          │
  │                          ▼                          │
  │                 ┌─────────────────┐     tap        │
  │                 │   已收藏         │ ──────────────→│
  │                 │  ❤️ 实心 · 红色  │  storage.del() │
  │                 │  #FF3B30        │  150ms ease    │
  │                 └─────────────────┘                │
  └────────────────────────────────────────────────────┘
```

**边界处理**：
- **存储满**：`wx.setStorageSync` 抛异常 → toast "收藏失败，请稍后重试"，按钮保持未收藏态
- **重复收藏判断**：`favorites.find(f => f.id === news.id)`，幂等保护
- **容量上限**：建议 200 条上限（对齐微信小程序 10MB storage），超出提示"收藏已满，请清理后重试"
- **弱网**：收藏是纯本地操作，不受网络影响

### 4.3 分享按钮交互流

```
点击 ↗️ → 微信原生转发面板（open-type="share"）
             │
             ├─ 发送给朋友 → onShareAppMessage 触发
             │     └─ 卡片预览: 标题 + 摘要 + 封面图
             │
             └─ 分享到朋友圈（P2 可选）
                   └─ onShareTimeline
```

**`onShareAppMessage` 配置**：

```js
return {
  title: truncate(news.title, 30),          // 微信推荐 ≤ 30 字
  path: `/pages/detail/detail?id=${news.id}&index=${idx}&category=${news.category}`,
  imageUrl: news.picUrl || getCategoryPlaceholder(news.category),  // 有图用图，无图用占位
}
```

- 分享语截断保护：取 `news.title` 前 30 字符（中文）+ 省略号
- 分享占位图引用 A-12c §四 的 5 分类主题色占位卡（400×300）
- 不自定义分享面板样式（微信 API 限制）
- 分享成功/取消：微信原生反馈，应用内不做额外 toast

### 4.4 收藏列表入口

**决策**：在首页侧边栏分类 Tab 最右侧新增 **「我的收藏」** Tab。

```
侧边栏分类 Tab 区（横向滚动）：
┌──────────────────────────────────────────────┐
│ 推荐 │ 科技 │ 国际 │ 体育 │ 生活 │ ❤️ 收藏   │
└──────────────────────────────────────────────┘
```

| 状态 | 内容 |
|------|------|
| 有收藏 | 列表项按 `addedAt` 倒序排列，复用 `panel-item` 样式，标题 + 来源时间 |
| 无收藏 | 空态：「还没有收藏任何新闻」+ 引导文字「浏览新闻时点击 ❤️ 即可收藏」 |
| 点击收藏项 | `navigateTo detail`（同现有 `onPanelItemTap`），支持跨分类阅读 |
| 左滑删除 | P2 优化项，不本期 |

**与现有侧边栏的集成**：
- `categories` 数组扩展一项 `{ id: '__favorites__', name: '❤️ 收藏' }`
- `onCategoryChange('__favorites__')` → `filteredNewsList = favorites`（从 storage 读取）
- 收藏列表不参与 `panelCurrentIndex` 高亮联动（收藏项与首页卡片流非同源）

## 五、跨模块交互一致性

### 5.1 与首页 WXS 手势的协调

- WXS（touch.wxs）纯 ES5 红线不变：无 `try/catch/let/const/箭头函数/模板字符串`
- 底部操作栏的 tap 事件层级：按钮 `z-index: 20`，不影响卡片流 `bindtap`（现有 `touch.wxs` 无 `return false`，已合规）
- 详情页跨分类手势与首页卡片流手势**互不干扰**（不同页面 `Page` 实例）

### 5.2 暗色模式交互行为

| 行为 | 规范 |
|------|------|
| 模式切换 | 跟随系统 `prefers-color-scheme`（`theme.json` + `darkmode: true`），**不提供手动切换** |
| 设置面板 | `.setting-panel` 背景跟随 `var(--bg-card)`，毛玻璃与主页一致 |
| 底部操作栏 | 暗色下背景 `rgba(13,13,13,0.9)`（引用 A-12c §3.1.4），已收藏红色 `#FF453A` |
| 首屏引导 | 暗色模式下文字白色 + 半透明黑色底，与浅色模式视觉权重一致 |

### 5.3 字号全局影响的交互约束

- **不缩放**的固定元素：导航栏高度、操作栏高度、图标尺寸、点击热区 ≥ 88rpx
- **被缩放**的内容元素：所有文字字号通过 `calc(Xrpx * var(--font-scale))` 引用
- 超大字号（tier 3, ×1.5）下的**截断保护**：标题限 3 行 `-webkit-line-clamp: 3`；摘要限 6 行；元信息不换行 `white-space: nowrap`
