## 一、配色方案修正（对齐 theme.json 真值）

> **背景**：v1.0 规范中的配色值与 `theme.json`（唯一真值源）存在多处不一致。A-03 自查已记录为遗留项 V-1~V-3。本次以 `theme.json` 为准，修订规范文档。

### 1.1 浅色模式修正

| 用途 | v1.0 规范值 | theme.json 真值 | 变更 |
|------|------------|-----------------|:--:|
| 页面底色 | `#F2F2F7` | `#F5F3F0` | 暖灰替代冷灰 |
| 卡片背景 | `#FFFFFF` | `#FAF9F7` | 暖白替代纯白 |
| 主文字 | `#1A1A1A` | `#1C1C1E` | 微调 |
| 辅助文字 | `#8E8E93` | `#A0A0A0` | 微调 |
| 分割线 | `#E5E5EA` | `#E8E6E1` | 暖色分割 |
| 毛玻璃背景 | `rgba(255,255,255,0.72)` | 不适用（已废弃） | 改为 `--bottom-bar-bg` / `--setting-panel-bg` |
| 遮罩层 | `rgba(0,0,0,0.4)` | `rgba(0,0,0,0.25)` | 更轻遮罩 |

### 1.2 暗色模式修正

| 用途 | v1.0 规范值 | theme.json 真值 | 变更 |
|------|------------|-----------------|:--:|
| 卡片背景 | `#1C1C1E` | `#0D0D0D` | 更深黑 |

## 二、字体层级修正（对齐真机实际值）

> **背景**：v1.0 规范中的字号（36/28rpx 等）已在真机调试中全面放大（+4~16rpx）。A-03 自查已记录为遗留项 V-2。本次以实际 wxss 值为准，并叠加 `--font-scale` 变量系统。

### 2.1 字体层级表（v2.0）

| 层级 | 实际值（wxss） | v1.0 规范值 | 变更 | 行高 | 缩放 |
|------|:------------:|:----------:|:----:|------|:---:|
| 首页卡片标题 | **52rpx** | 36rpx | +16 | 1.35 | ✅ `calc()` |
| 首页卡片摘要 | **32rpx** | 28rpx | +4 | 1.9 | ✅ `calc()` |
| 首页卡片元信息 | **24rpx** | 22rpx | +2 | 1.5 | ✅ `calc()` |
| 首页滑动提示 | **22rpx** | 20rpx | +2 | 1.5 | ✅ `calc()` |
| 侧边栏标题 | **34rpx** | — | — | 1.4 | ✅ `calc()` |
| 侧边栏 Tab | **26rpx** | — | — | 1.5 | ✅ `calc()` |
| 侧边栏列表标题 | **30rpx** | 28rpx | +2 | 1.45 | ✅ `calc()` |
| 详情页标题 | **48rpx** | 40rpx | +8 | 1.45 | ✅ `calc()` |
| 详情页正文 | **34rpx** | 30rpx | +4 | 2.2 | ✅ `calc()` |
| 详情页元信息 | **26rpx** | — | — | 1.5 | ✅ `calc()` |
| 底部操作栏文字 | **24rpx** | — | — | 1.5 | ✅ `calc()` |
| 设置面板标题 | **34rpx** | — | — | 1.4 | ❌ 固定 |
| 设置面板选项 | **28rpx**（按档位缩放） | — | — | 1.5 | ✅ 按档位 |

### 2.2 `--font-scale` 四档

| 档位 | 名称 | 乘数 | 首页标题实际 | 首页摘要实际 | 对标系统 |
|------|------|:---:|:----------:|:----------:|------|
| 0 | 标准 | 1.0 | 52rpx | 32rpx | 16px 级 |
| 1 | 大 | 1.15 | 59.8rpx | 36.8rpx | 18px 级 |
| 2 | 特大 | 1.3 | 67.6rpx | 41.6rpx | 20px 级 |
| 3 | 超大 | 1.5 | 78rpx | 48rpx | 24px+ 级 |

### 2.3 超大字号截断保护

| 元素 | 限制 | 方式 |
|------|------|------|
| 首页标题 | 3 行 | `-webkit-line-clamp: 3` |
| 首页摘要 | 6 行 | `max-height: 55vh; overflow: hidden` |
| 元信息 | 不换行 | `white-space: nowrap` |
| 侧边栏列表标题 | 2 行 | `-webkit-line-clamp: 2` |

## 三、组件规范新增（阶段二）

### 3.1 底部操作栏（BottomBar）— 新增

```
┌──────────────────────────────────────────┐
│                                          │
│     ♡ 收藏           │        ↗ 分享      │
│                                          │
└──────────────────────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 高度 | `100rpx` + `env(safe-area-inset-bottom)` |
| 背景 | 毛玻璃（见 §1.3 `--bottom-bar-bg`） |
| 布局 | flex 均分两列 |
| 图标 | 44rpx，热区 ≥ 88rpx |
| 文字 | `calc(24rpx * var(--font-scale))` |
| 收藏已选色 | `#FF3B30`（浅色）/ `#FF453A`（暗色） |
| 收藏动效 | heartBeat：scale(1)→1.25→0.95→1，300ms |

> 完整规格见 `D-03-视觉设计-阶段二视觉稿.md` §二。

### 3.2 字号设置半屏面板 — 新增

```
┌──────────────────────────────────┐
│         字体大小                  │
│                                  │
│  ○ 标准  预览文字效果预览文字      │
│  ● 大    预览文字效果预览文字      │
│  ○ 特大  预览文字效果预览文字      │
│  ○ 超大  预览文字效果预览文字      │
│                                  │
│  ──────────────────────────────  │
│  关于 · 反馈                     │
└──────────────────────────────────┘
```

| 属性 | 值 |
|------|-----|
| 入场 | slideUp 300ms ease-out |
| 圆角 | 左上+右上 24rpx |
| 背景 | 毛玻璃（见 §1.3 `--setting-panel-bg`） |
| 行高 | 88rpx / 档位行 |
| 选中态 | `var(--tag-bg)` 半透明底色 |

> 完整规格见 `D-03-视觉设计-阶段二视觉稿.md` §三。

### 3.3 分享占位图 — 新增

| 属性 | 值 |
|------|-----|
| 尺寸 | 400×300px |
| 生成方式 | Canvas 客户端动态生成 |
| 背景 | 分类纯色（8 分类各一色） |
| 内容 | 居中「一页」36px Bold + 「· 分类名 ·」20px |

> 完整规格见 `D-03-视觉设计-阶段二视觉稿.md` §四。

### 3.4 侧边栏「❤️ 收藏」Tab — 新增

- 复用现有 `.panel-tab` 样式
- 位于分类 Tab 行最右侧
- 列表项复用 `.panel-item`
- 空态：📭 图标 + 引导文字

### 3.5 跨分类视觉元素 — 新增

| 元素 | 说明 |
|------|------|
| 进度指示升级 | 跨分类时追加「· 分类名」，分类强调色 fadeIn 200ms |
| 分类色闪烁条 | 40rpx×4rpx，分类色，200ms fadeInOut |
| 边界提示 Chip | 深色半透明胶囊，2s 自动消失 |
| 网络兜底 Toast | 黄色警告 `#F59E0B`/`#FBBF24`，3s 消失 |
