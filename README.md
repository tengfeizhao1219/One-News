# 一页 One News · 微信小程序

> 极简沉浸式新闻阅读 —— 打开即读，零推荐、零追踪、零打扰。

「一页」是一款微信小程序，帮你用更少的时间看懂当下：没有花哨的推荐流，只有精选分类、每小时更新的时事，配上 AI 帮你读、帮你深挖、帮你盯住后续。

## ✨ 它能做什么

- **一页 · 极简阅读**：打开即读，无推荐、无追踪；每条带 AI 摘要与解读，几秒抓住要点，重要的再深一层讲透。
- **深度挖掘**：读到想了解更多？按一下深挖，AI 汇聚多角度信息，把来龙去脉讲清楚。
- **AI 情报官**：每日划重点 —— 「原文解读」还原事实，复杂专业文配「大白话」，外加「AI 预测」与「落到你这里」，把资讯翻译成与你有关的下一步。
- **我的关注**：长按一个话题，替你盯住「后来怎么样了」——只在有真进展时才提醒，不打扰。
- **分享即达**：资讯与情报都支持发给朋友、分享到朋友圈，朋友打开就是一张完整单页。

## 🧭 一点点探索提示

更多能力藏在细节里：试试**长按正文、左右滑动、点开「发生了什么」**……简单，但有惊喜。
