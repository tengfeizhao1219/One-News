## 快速开始

### 1. 环境准备
- [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)（最新稳定版）
- 已注册的微信小程序 AppID
- 开通云开发环境

### 2. 导入项目
1. 打开微信开发者工具
2. 选择「导入项目」
3. 目录选择本项目的根目录
4. 填入你的 AppID
5. 点击「确定」

### 3. 配置云开发
1. 在开发者工具中点击「云开发」按钮
2. 开通云开发环境（选择按量付费或免费额度）
3. 复制环境 ID
4. 在 `app.js` 中初始化云开发：
```js
wx.cloud.init({
  env: '你的环境ID',
  traceUser: true
})
```

### 4. 部署云函数
1. 在开发者工具中，右键 `cloudfunctions/getNewsList`
2. 选择「上传并部署：云端安装依赖」
3. 同样操作 `getNewsDetail` 和 `searchNews`

### 5. 导入数据
在云开发控制台 → 数据库 → 创建集合 `news`，导入 Mock 数据（参考 `mock/news.js` 的数据格式）。

### 6. 切换到生产模式
修改 `utils/constants.js`：
```js
const USE_MOCK = false  // 改为 false 使用云函数
```

### 7. 预览与发布
- 点击「预览」在手机上测试
- 确认无误后点击「上传」提交代码
- 在小程序后台提交审核

## 交互说明

| 手势 | 功能 |
|------|------|
| ↑ 上滑 | 切换到下一条新闻 |
| ↓ 下滑 | 切换到上一条新闻 |
| ← 左滑 | 呼出新闻列表面板 |
| 顶部下拉 / 列表开头继续下滑 | 刷新当前分类（见下方「刷新逻辑」）|
| 点击卡片 | 进入详情页 |
| 详情页返回 | 回到卡片流 |

### 刷新逻辑（2026-08-20 决策）

- 下拉刷新与「列表开头继续下滑」手势，**只从云数据库 `news_cache` 重新读取已入库、已展示给前端的数据并重新渲染**，不触发 `newsFetcher` 抓取新数据，也不轮询增量接口。
- 新内容由**整点定时 `newsFetcher` 流水线自动抓取入库**；用户在两次定时之间的下拉刷新只是重新拉取当前库内数据（提示「已刷新」），抓取到的增量会在下一个整点入库后、于下次刷新可见。
- 这是一次对早期「真刷不假报」方案（2026-08-10 FS-CF3）的**回退**：刷新职责从「前端触发抓取」收回到「前端只读库、抓取交给定时流水线」。代码见 `pages/home/home.js` 的 `_refreshFromDb`。
