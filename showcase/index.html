「一页 One-News」是一套内容优先、极致简化的新闻阅读设计系统。本页用真实的设计 Token 与可交互组件，呈现其手势、动画、反馈、状态、层级、布局六大体系 —— 即触即达，优雅降级。

交互语言标准 v1.0 · 审计基线 main@cd7cd1a · 全系统 25 项交互走查
01

少即是多

每页只做一件事；每个手势只对应一个结果，拒绝一页多态。

02

即触即达

操作→反馈 ≤300ms；动画不阻塞交互，绝不「等动画播完才能点」。

03

优雅降级

任何数据缺失都不崩 UI；空 / 错 / loading 三态必现。

04

先标准后例外

新交互先查本标准，标准不覆盖才允许例外，杜绝每页自创手势。

可交互预览

切换下方标签查看首页卡片流、详情阅读、侧边栏与分类滚轮。所有视觉与动效均来自本设计系统的真实 Token。

交互语言六体系

节选自《交互语言标准 v1.0》，完整规范见项目文档。

手势 §1

  • 上滑 下一条
  • 下滑 上一条
  • 左滑 呼出侧栏
  • 点击 默认行为
  • 仅 4 种，禁长按/捏合

动画 §2

  • 翻页 300ms ease
  • 回弹 200ms
  • 面板 300ms
  • 禁 >500ms / 阻塞

反馈 §3

  • Toast ≤12 字 / 2000ms
  • 心形 300ms 回弹
  • 网络兜底 3s
  • 每操作必即时反馈

状态 §4

  • loading / ready
  • error / empty
  • 空数据三态规则
  • 禁静默失败

层级 §5

  • 字体面板 z41 最高
  • 侧栏 30 / 遮罩 29
  • 操作栏 20
  • 禁 999 随意值

布局 §6

  • 8rpx 间距基准
  • 触控 ≥88rpx
  • 字体 4 档缩放
  • 超大档截断保护

走查发现（摘要）

全系统 25 项交互走查结论与优先修改建议，完整报告见 D-02-增量-全系统交互走查.md。

P0

--primary 悬空引用

标准与 RQ-15-D 多处引用 var(--primary)，但 theme.json 未定义，真机可能回退失效。

归属：视觉设计师 / 前端开发 · 补 --primary（浅 #007AFF / 暗 #0A84FF）
P0

「R」刷新语义 ≠ 下拉刷新

「R」调云函数强制拉新；下拉刷新仅重读列表。S4 简化不可零损合并，须让下拉也触发 refreshNews。

归属：PM（PD-B4 裁定 S4）/ 前端开发
P0

顶栏按钮触控热区不足

56rpx < 88rpx 下限，且 D-02 §6.3 示例自相矛盾。补足热区并修订标准。

归属：交互设计师（修标准）/ 前端开发
P1

§3 边界反馈标准漂移

标准写「边界 Chip 2000ms」，代码已改用 Toast。二选一固化并同步 D-02。

归属：交互设计师（修标准 §3/§10）
P1

配色暖白 vs 中性灰

theme.json #F5F3F0 暖白 与 D-02 §9 中性 #F2F2F7 并存，需产品/视觉定调。

归属：视觉设计师 / 产品经理
P2

首启手势引导缺口

引导遮罩已移除，swipe-hint 成唯一引导。建议 S2 图标化 + 一次性 coachmark。

归属：交互设计师 / 前端开发
